# Нагрузочные скрипты (место по ADR-028 ред. 3)

Переехали из `9-tests/Load/` (@TE удалил их там коммитом `a67bf6ab`, содержимое сохранено
в истории; восстановлено @DO из `a67bf6ab^`):

- `load.js` — сценарий k6 (soak, TE-011) — 1246 байт;
- `load.ps1` — запуск/обвязка — 1759 байт;
- `NOTES-from-tests.md` — исходный README из `9-tests/Load/` (полезные заметки, не теряем).

Почему здесь, а не в `9-tests`: по ADR-028 ред. 3 в `9-tests/**` допустимы **только браузерные
E2E** (маркер `front-e2e.md` + Playwright). Нагрузка — это **измерение контура**, а не
проверка поведения сервиса и не фронтовой тест; её место рядом с другими измерениями
(`tools/latency.py`, `7-deploy/runbooks/latency.md`).

Гейт `tools/check_front_e2e.py` это проверяет: посторонний исполняемый каталог в `9-tests`
(например `Load` с `*.js` без Playwright) → `::error::` и rc=1.

## Запуск

```bash
# k6 (если установлен)
k6 run 7-deploy/load/load.js --env BASE_URL=http://127.0.0.1:8080

# обвязка
pwsh 7-deploy/load/load.ps1 -BaseUrl http://127.0.0.1:8080
```

Результаты прогонов — в `9-tests/reports/` (общая папка отчётов остаётся там).
