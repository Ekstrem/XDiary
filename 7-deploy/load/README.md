# Нагрузочные скрипты (место по ADR-028 ред. 3)

Сюда переезжают нагрузочные скрипты из `9-tests/Load/` (`load.js`, `load.ps1`).

Почему: по ADR-028 в `9-tests/**` допустимы **только браузерные E2E** (маркер `front-e2e.md`
+ Playwright). Нагрузка — это **измерение контура**, а не проверка поведения сервиса и не
фронтовой тест; её место рядом с другими измерениями (`tools/latency.py`).

Гейт `tools/check_front_e2e.py` теперь ловит постороннее в `9-tests`:
`::error::9-tests/Load: нагрузочные скрипты (N исполняемых) — место 7-deploy/load по ADR-028`.

Перенос делает владелец файлов (@TE): `git mv 9-tests/Load 7-deploy/load` (файлы внутри
`7-deploy/load/`), затем `python tools/check_front_e2e.py` → rc=0.

Как запускать (после переноса) — цель нагрузочного прогона против dev/прода:

```bash
node 7-deploy/load/load.js --base-url http://127.0.0.1:8080 --repeat 50
```

Результаты — в `9-tests/reports/` (общая папка отчётов остаётся там).
