# Ранбук: замер латентности «шлюз vs напрямую» (T9, DO-060)

Зачем: «15 секунд неприемлемо» — это ощущение, а не цифра. Бюджет (T9): интерактивные
операции **p95 ≤ 1000 мс**, накладные шлюза **≤ 100 мс**.

## Как мерить

```bash
# через шлюз (с хоста прода/дева шлюз опубликован на 127.0.0.1:8080)
python3 tools/latency.py --walk --registry openapi --repeat 3 --check \
    --gateway http://127.0.0.1:8080
```

**«Напрямую» — только изнутри сети.** CNI-адрес контейнера (`10.89.x.x`) **с хоста недоступен**,
а в runtime-образах нет `curl`/`wget`. Поэтому берём helper-контейнер в сети `xdiary`:

```bash
podman pull -q docker.io/curlimages/curl:8.10.1

# ВАЖНО: ОДИН контейнер и цикл ВНУТРИ него.
# Запуск отдельного контейнера на каждый запрос добавляет ~6 мс старта —
# в первом замере это дало «отрицательные накладные» (-2…-5 мс), то есть мусор.
podman run --rm --network xdiary docker.io/curlimages/curl:8.10.1 sh -c \
  'for i in $(seq 10); do curl -s -o /dev/null -w "%{time_total}\n" \
   http://client:8080/api/v1/clients; done'
```

## Замер (prod, 2026-11-13, @DO, `origin/main` = фактическая ревизия образа `client`)

| Операция | gw p50 | gw p95 | direct p50 | direct p95 | накладные |
|---|---|---|---|---|---|
| `GET /api/v1/clients` | 2.5 | 136.5 | 0.3 | 32.1 | **+2.2** |
| `GET /api/v1/clients/me` | 2.4 | 3.9 | 0.3 | 7.9 | **+2.1** |
| `GET /api/v1/journal/records` | 4.2 | 189.7 | 0.3 | 7.7 | **+4.0** |

Миллисекунды. Накладные шлюза **2–4 мс** — внутри бюджета 100 мс. p95 шлюза даёт всплески
(136–190 мс) на части прогонов; это не накладные, а холодные/первый-запрос-эффекты —
для бюджета p95 1000 мс запас большой, но при появлении жалоб начинать с этого.

## Грабли

1. Мерить «напрямую» с хоста нельзя — увидишь отказ, а не замер.
2. `podman run` на каждый запрос искажает результат стартом контейнера.
3. Реестр `openapi/index.json` покрывает **2 сервиса из 12** (`client`, `analytics`, ревизии
   от 2026-11-09) — замер по нему про Client, а не про весь API. Полный обход — когда @BE
   догонит реестр; разрыв виден гейтом `tools/check_api_index.py` (79 операций по 12 BC).
