# Ранбук: изоляция тестов (ADR-028)

Правило: **тест, который нельзя собрать и прогнать вместе с компонентом, — не тест компонента.**
Критерий не «где папка», а «чей жизненный цикл».

| Что | Где | Почему |
|---|---|---|
| Домен/агрегат/БД/API одного сервиса, ожидания потребителя | `6-msa/BC-<X>/src/<X>.Tests` | собирается и бежит вместе с сервисом |
| Межсервисные black-box сценарии | **нет такой папки** (ред. 3): сценарий живёт у потребителя, двойник провайдера — в его тестах | общая папка не собирается ни с одним сервисом |
| Фронтовые E2E (браузер) | `9-tests/**` + маркер `front-e2e.md` | нужен фронт |
| Гейты/скрипты | рядом со своим кодом | — |

**Запрещено (ред. 3 ADR-028, `AGENTS.md` §1):** общие тестовые папки — `6-msa/E2E`,
`6-msa/ApiTests`, `Contract.<A>_<B>`. Любая из них не собирается с одним сервисом. Контракт = ожидание потребителя (у потребителя, с HTTP-двойником провайдера)
+ проверка провайдера у провайдера.

## Гейты (машинные)

```bash
python tools/check_test_isolation.py   # б, в, д из комплаенса ADR-028
python tools/check_front_e2e.py        # г: в 9-tests только с front-e2e.md + браузер
```

- **б** — тест в `6-msa/**` не ссылается `ProjectReference` на чужой `BC-*`;
- **в** — `6-msa/E2E` не подключён к сервису (иначе изолированная сборка — фикция);
- **д** — общих тестовых папок нет: `6-msa/E2E`, `6-msa/ApiTests`, `Contract.<A>_<B>`;
- **г** — в `9-tests/**` у каждого проекта маркер `front-e2e.md` **и** браузерная зависимость.

## Пункт «а» — прогонный, не статический

`dotnet test 6-msa/BC-<X>` должен проходить **без** других сервисов. Парсингом это не
проверить: нужен реальный запуск в чистом окружении. Делается отдельной CI-джобой
(после переноса тестов @TE) — по одному сервису за прогон, без поднятия соседей.

## Гейты идут независимо (`if: always()`)

До 2026-11-14 шаги `ci-guards` были последовательными: первое падение (`Check chat format`,
метки времени вне `00–23`) **уводило все последующие шаги в `skipped`**, и гейты ADR-028 не
выполнялись вообще. Прогон `39c68431`: `check-chat` — failure, «Изоляция тестов» и
«В 9-tests только браузерные E2E» — **skipped**.

Лечение: `if: always()` на шагах AWAIT, api-index, изоляция, front-e2e, шлюз, NUL.
Проверка на прогоне **`5263d949`**:

| Шаг | Результат |
|---|---|
| Check chat format | failure (метки `24–30`) |
| Регистр выданных решений (AWAIT) | success |
| Реестр API ↔ код | success |
| Изоляция тестов — ADR-028 | **failure** — 3×(б), по факту |
| В 9-tests только браузерные E2E | **success** |
| Внешняя поверхность = только шлюз | success |
| NUL/маркеры | success |

Вывод: «красный шаг выше» больше не маскирует вердикты остальных. Любой новый гейт в этом
джобе добавлять с `if: always()` — иначе он повторит ту же ошибку.
