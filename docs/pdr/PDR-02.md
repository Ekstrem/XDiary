## Варианты, которые рассматривались

всё на @TL (было) | домен по папке | домен + запрет саморевью (выбрано)

## Решение и детали

- **Статус:** принято (07.11), уточнено (07.11: саморевью = автор задачи).
- **Решение:** ревьюер определяется доменом; если автор задачи совпадает с ревьюером —
  проверяет `@TL` (для архитектурных `@AR`).
- **Почему:** один TL как единственный ревьюер 148 задач — горлышко, которое не улучшалось
  ни на одной итерации. Первая версия правила («ревьюер = папка») дала **12 ложных
  срабатываний**: для `devops/`-задач корректный ревьюер как раз `@TL`, а не `@DO`.
- **Минусы:** нужно дисциплинировать поле `Проверяет:`; метрика «ревью не автором» стала
  проверяемой только после переделки формулировки.
- **Доказательство:** `status_lint` предупреждает о саморевью; метрика `31/31`.
