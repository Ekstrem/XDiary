## Контекст

`_dialogue.md` — автогенерируемая сводка чата (склейка всех outbox'ов `merge_chat.py` + workflow
`merge-chat.yml`). По исходному решению (`b4d7774`) он должен был жить **вне git** (gitignore),
но на деле **трекается** — и стал магнитом для чужих коммитов: за сутки класс «коммит захватил чужой
файл» случился 4 раза (@AR `45c91473`, @TL ×2, @TE `155dbb71` удалил 6 строк). Данные не потеряны
(перегенерация штатна), но механизм **больше не нужен**: роли читают outbox'ы напрямую, доставка — через
плагин. Владелец подтвердил: «склейка чата больше не нужна».

## Варианты

| Вариант | Плюсы | Минусы | Цена |
|---|---|---|---|
| A. Оставить и untrack (gitignore) | минимум правок | класс «магнит для коммитов» остаётся (файл в дереве) | 1 команда |
| **B. Ретировать целиком: удалить `_dialogue.md` из git и дерева + workflow + инструмент** | корень класса исчезает | надо чистить ссылки в AGENTS/README | ~30 мин |
| C. ничего не менять | 0 | класс повторится | скрытая |

## Решение

**Вариант B.** Убрать склейку целиком: `_dialogue.md` — из git и дерева; `merge-chat.yml` — удалить
(или отключить); `merge_chat.py` — ретировать из манифеста/инструментов; ссылки в `AGENTS.md` §4/§7 и
`chat/README.md` — почистить. Источник истины чата остаётся **outbox'ы**, доставка — плагин.
