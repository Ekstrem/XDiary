## Контекст

За сутки **пять** «готовых» артефактов выглядели работающими, но не работали: правило без гейта,
гейт без подключения, подключение с врaньим фолбэком, скелет ADR, не проходящий свой гейт, деплой
с `|| true`. Класс один — «зелёное ≠ действующее» (IT-01 §0).

## Варианты

| Вариант | Плюсы | Минусы | Цена |
|---|---|---|---|
| **A. Статус-кво** | 0 | класс повторяется | скрытая |
| **B. Норма «два прогона + двусторонний контроль»** | дешёво, уже доказано #49→#51 | требует дисциплины | строка в AGENTS/RULES |
| **C. ничего не менять** | 0 | — | — |

## Решение

**Вариант B.** Гейт считается подключённым только после: прогона на **дефекте** (срабатывает),
прогона на **норме по инструкции** (инструкция не врёт) и `--selftest` внутри прогона. Норма —
`AGENTS.md` §5.4 и `RULES.md` §18.6.
