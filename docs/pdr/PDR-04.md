## Варианты, которые рассматривались

один `smoke` на всё (было) | `smoke-api`+`smoke-front` по diff (выбрано) | без гейта

## Решение и детали

- **Статус:** принято (07.11, после DO-035).
- **Решение:** гейт выбирается по природе изменения (`6-msa/**`,`7-deploy/**` → API;
  `8-front/**` → front); ручной обход запрещён; гейт, который блокирует не то, что
  деплоится, — дефект гейта.
- **Почему:** единый `smoke` связывал фронт и бэк: фронтовый баг FE-027 остановил доставку
  образа `clients` с `TelegramOtpSender`, и единственным выходом остался ручной `podman pull`.
- **Минусы:** два гейта дороже по минутам; нужно поддерживать `diff`-логику.
- **Доказательство:** `14306ca` (`smoke-api`/`smoke-front`), §5.4 `AGENTS.md`.
