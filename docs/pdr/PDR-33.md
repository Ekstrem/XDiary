## Контекст

2026-11-12 вскрыл два класса: (1) **ложная атрибуция** — 4 случая за день (`→ @LM` прочитан как автор,
метки `22:30/23:10` придуманы по памяти, «повторы `08:40/09:10`» не подтвердились); (2) **ложный блокер**
`untracked would be overwritten` из-за чужих/мёртвых worktree. Оба — **не симптом-заплатки** (не маскируют
архитектурный дефект), а дисциплины процесса.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| A. оставить как есть | 0 | классы повторятся |
| **B. принять обе нормы в AGENTS** | классы закрываются | +2 строки |
| C. ничего не менять | 0 | — |

## Решение

**Вариант B.** `AGENTS.md` §3 — «цитата дословная + команда проверки»; §5.3 — «worktree-диагностика + prunable».
