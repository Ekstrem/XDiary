# PDR-23. Метрика «Ответ @LM» считается по git-времени, а не по штампам чата

| Поле | Значение |
|---|---|
| **Статус** | принято |
| **Владелец** | @LM (дашборд `health.py`) |
| **Согласования** | владелец 2026-11-09: «бери всё, что улучшает по метрикам процесс» |
| **Дата** | 2026-11-09 |
| **Заменяет** | — |

## Контекст

Дашборд показывал «Ответ @LM, медиана = **4605 мин**» — это **артефакт шкалы чата** (штампы 11-07/08
против машинных 11-02), а не регресс скорости. Метрика нарушала своё же правило «называй источник»
(D-13). После правки — **112 мин, n=173** (честно, по committer-time через `git blame`).

## Варианты

| Вариант | Плюсы | Минусы | Цена |
|---|---|---|---|
| **A. Оставить штампы чата** | 0 | 4605 мин — ложный красный | — |
| **B. `git blame` → committer-time** | настоящая стена часов | медленнее (блейм по файлам чата) | ~30 мин |
| **C. ничего не менять** | 0 | — | — |

## Решение

**Вариант B.** `metric_lm_sla` в `health.py` берёт время коммита каждой строки через
`git blame --line-porcelain`; нет git/блейма — честное «нет данных», а не ложное число. Заодно
«Прогоны, дошедшие до шагов» при отсутствии данных показывают ⚪, а не 🟢.

### Протокол

| Роль | Принял | Отклонил | Воздержался |
|---|---|---|---|
| @LM | ✅ 2026-11-09 | | |
| @TL | ✅ 2026-11-09 (07:00) | | |
| владелец | ✅ 2026-11-09 («решай сам, общайся с командой») | | |

### Обязательства

| Что | Ответственный | Как проверяется |
|---|---|---|
| `health.py`: `metric_lm_sla` по git-времени | @LM | `py_compile` + прогон (112 мин, n=173) |
| «дошедшие до шагов» = ⚪ без данных | @LM | строка в HEALTH |
| PAT для данных «дошедших» | @DO | метрика станет числом |

### Комплаенс

| Что | Значение |
|---|---|
| Где источник правды | `LoopMaker/tools/health.py` |
| Когда пересматриваем | при сдвиге `chat_time.shift_hours` или переезде на другую шкалу |
| Кто проверяет | @LM |
| Что делаем при расхождении | метрика помечается «нет данных», не зелёным |

## Критерий приёмки и метрика

- гейт: `python tools/health.py --no-ci` возвращает 0, строка «Ответ @LM» — число, а не 4605;
- метрика: LM-ответ виден в реальных минутах; дата проверки — следующий прогон дашборда.
