## Проблема

Три ветки `hold/lm-*` были собраны на **старой базе**. Выглядели готовыми, но каждая тащила
`tools/chat_lint.py` с `-125 / -125 / -80` строк: мерж **откатил бы** актуальные фиксы
(TZ-опора, `--next-stamp` от максимума по чату) — то есть «готовая работа» отменила бы чужие
исправления, и это заметили только потому, что @TL сверил **содержимое**, а не название.

## Предложение

Перед просьбой о мерже ветка пересобирается от текущего `main`:

```
git switch -c hold/<role>-rebase origin/main
# перенести только свои файлы; проверить: git diff --stat origin/main..origin/hold/<role>-rebase
```

**Критерий:** diff содержит **только добавления**; любое удаление чужих строк — стоп и разбор.
Проверка дешевле «diff review»: одна команда перед просьбой.

## Цена

Одна операция на ветку; при конфликте — ручной перенос (минуты). Плюс: исключает класс
«ветка откатила чужой фикс», который сейчас ловится только вниманием координатора.

## Как проверить

- в запросе на мерж есть `diff --stat` ветки против `main`, где deletions = 0 (для чужих файлов);
- число случаев «мерж откатил чужой фикс» = 0.

## Что мешает принять как норму

Решение владельца: новые правила не вводим. Пока применяется как практика — @LM пересобрал
ветку именно так (`hold/lm-rebase2-2156`), @TL смержил без конфликтов.

## Тот же класс: инструмент отказывает до опасного шага (факт 00:05)

Повреждение `.git/rebase-merge` **без `head-name`** создавал не git, а `git_sync.py`:
путь `rebase --autostash` на грязном дереве. @DO поставил предохранитель **до** `fetch`/`rebase`
(untracked без `-u` → код 1 и список файлов), добавил тест `tools/test_git_sync.py` и шаг
в `ci-guards.yml`.

**Проверено по коду:** предохранитель — `tools/git_sync.py:97–104`, `fetch` — строка 129,
`rebase` — 133. Значит опасный путь **недостижим**: инструмент отказывает раньше, чем ломает
`.git/`.

**Почему это в одном черновике с D-08:** «ветку собирай от текущего `main`» и «инструмент отказывает
до опасного шага» — один класс: **не доводи до состояния, из которого надо восстанавливаться**.
Разница только в том, кто отказывает: автор (перед просьбой о мерже) или инструмент (перед
`rebase`). Первое — дисциплина, второе — предохранитель, и второе надёжнее.
