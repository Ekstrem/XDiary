# AGENTS.md — 8-front (PWA)

Хозяин папки: **FrontEnd**. Все остальные — только чтение.

- Это прод: `pages.yml` публикует именно `8-front/`. `app/` — легаси, не правим.
- Контракты берём из `03-ddd/*/03-command-api.md` и `04-query-api.md`; шлюз — `6-msa/ApiGateway`.
- Если контракта в артефактах нет — не выдумываем API в одиночку: пишем `→ @TL` и
  `→ @AR` в `5-tech-backlog/chat/fe.md` (так появились BE-014 и правка `03-ddd/BC-Privacy`).
- Деплой (`pages.yml`, окружения) — зона DevOps: нужна правка — задача `DO-xxx`.
- **Версия обязательна:** при любом изменении `8-front/`, которое должно дойти до
  пользователя (код/багфикс), бампаем **`APP_VERSION` в `js/app.js` И `CACHE` в `sw.js`**
  в паре (напр. `0.29` ↔ `xdiary-v29`). Иначе Service Worker отдаёт старый
  закэшированный `app.js`/`api.js` — фикс не доезжает до пользователя (реальный
  случай 01–02.11: `0.28`/`v28` держался после FE-005…FE-010).
- Дизайн без просьбы не переделываем (правило пользователя: сначала пристёгиваем API).
- Первый шаг по задаче — `Статус: В работе` в `5-tech-backlog/front-end/` и строка
  `→ @TL` в `chat/fe.md`. Ход не заканчиваем обещанием без tool call — см.
  `XDiary/AGENTS.md` §3.
