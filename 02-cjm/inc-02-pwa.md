# CJM — Инкремент 2: PWA и приватность

**Персона:** пользователь · **Цель:** установить приложение на телефон, пользоваться офлайн и защитить доступ.

## Этап 1. Установка PWA
- **Действия:** открывает URL в Chrome, нажимает «Добавить на главный экран», подтверждает.
- **Мысли / вопросы:** «Это настоящее приложение? Будет значок как у обычного?»
- **Эмоции:** 😊 / 😐
- **Точка контакта:** Chrome, баннер установки, домашний экран.
- **Боли:** не видит баннер, не понимает, что PWA можно установить, значок «не как приложение».
- **Возможности:** явная подсказка «Установить приложение», качественная иконка, манифест с полноэкранным режимом и правильной ориентацией.

## Этап 2. Работа офлайн
- **Действия:** открывает приложение без сети.
- **Мысли / вопросы:** «Заработает ли? Данные на месте?»
- **Эмоции:** 😊 (если работает) / 😟 (белый экран).
- **Точка контакта:** приложение, service worker, IndexedDB.
- **Боли:** не всё закэшировано, приложение не грузится офлайн.
- **Возможности:** precache всех ресурсов, офлайн-фолбэк, данные только локально.

## Этап 3. Установка PIN
- **Действия:** в настройках задаёт PIN (и повторяет для подтверждения).
- **Мысли / вопросы:** «Защитит ли это данные? Что если забуду PIN?»
- **Эмоции:** 😐
- **Точка контакта:** экран «Приватность / Безопасность».
- **Боли:** нет подтверждения, забыл PIN — нет пути восстановления.
- **Возможности:** подтверждение ввода, подсказка по восстановлению (экспорт/бэкап), хранение только хеша.

## Этап 4. Вход по PIN
- **Действия:** открывает приложение, вводит PIN.
- **Мысли / вопросы:** «Быстро ли разблокируется?»
- **Эмоции:** 😊 (быстро) / 😟 (если тормозит или спрашивает при каждом открытии).
- **Точка контакта:** экран блокировки.
- **Боли:** PIN спрашивается слишком часто, нет биометрии.
- **Возможности:** запоминать разблокировку на короткий таймаут, (TOBE) биометрия через WebAuthn/Android.

## Этап 5. Обновление приложения
- **Действия:** выходит новая версия, service worker обновляется.
- **Мысли / вопросы:** «Когда появится обновление? Надо ли что-то делать?»
- **Эмоции:** 😐
- **Точка контакта:** service worker, тост «Новая версия».
- **Боли:** пользователь не видит обновление, застрял на старой версии.
- **Возможности:** автообновление + кнопка «Обновить сейчас».

## Итог
- **Критерии успеха:** приложение устанавливается за ≤ 3 тапа; офлайн-открытие без белого экрана; данные недоступны без PIN.
