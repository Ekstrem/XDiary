# CJM — Инкремент 3: Garmin — соматика

**Персона:** пользователь · **Цель:** импортировать соматические данные Garmin и связать их с записями.

## Этап 1. Подключение источника Garmin
- **Действия:** в настройках выбирает источник (OAuth Garmin Health / импорт файла из Garmin Connect).
- **Мысли / вопросы:** «Безопасно ли? Какие данные уйдут наружу?»
- **Эмоции:** 😐 / 😟 (приватность).
- **Точка контакта:** экран «Garmin», системный OAuth-диалог или выбор файла.
- **Боли:** сложный OAuth, нужен партнёрский доступ Garmin, страх утечки.
- **Возможности:** на MVP — ручной импорт FIT/CSV (без партнёрского доступа), чёткое объяснение, какие данные забираем.

## Этап 2. Импорт данных
- **Действия:** выбирает период, запускает импорт, видит прогресс.
- **Мысли / вопросы:** «Долго ли? Все ли данные подтянутся?»
- **Эмоции:** 😐
- **Точка контакта:** экран импорта, прогресс-бар.
- **Боли:** неполный импорт, ошибки формата, большие файлы тормозят.
- **Возможности:** инкрементальный импорт, понятные ошибки, кэш импортированного.

## Этап 3. Сопоставление с записью
- **Действия:** открывает запись, видит пульс/стресс/Body Battery вокруг времени акта.
- **Мысли / вопросы:** «Что происходило с телом в этот момент?»
- **Эмоции:** 😊 (инсайт).
- **Точка контакта:** карточка записи, график соматики.
- **Боли:** нет данных в нужном окне времени, график нечитаемый.
- **Возможности:** автоматическая привязка по времени ±N минут, зум по окну, подсветка пиков.

## Этап 4. Просмотр корреляций сон / восстановление
- **Действия:** сравнивает качество сна/восстановления с активностью.
- **Мысли / вопросы:** «Влияет ли сон на желание?»
- **Эмоции:** 😊
- **Точка контакта:** сводка на записи / мини-отчёт.
- **Боли:** нет агрегации, приходится смотреть вручную.
- **Возможности:** сведение сна/восстановления за день к каждой записи (полный дашборд — в инкременте 6).

## Итог
- **Критерии успеха:** соматика за нужное окно привязана к записи; импорт не теряет данные; пользователь понимает, что именно импортируется.
