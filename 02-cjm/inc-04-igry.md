# CJM — Инкремент 4: Каталог секс-игр

**Персона:** пользователь (пара) · **Цель:** найти подходящую игру, запустить её и зафиксировать результат.

## Этап 1. Открытие каталога
- **Действия:** открывает раздел «Игры».
- **Мысли / вопросы:** «Что тут есть? С чего начать?»
- **Эмоции:** 😊
- **Точка контакта:** экран каталога.
- **Боли:** пустой каталог, непонятная навигация.
- **Возможности:** стартовый набор игр, карточки с уровнем/длительностью/участниками.

## Этап 2. Фильтрация и поиск
- **Действия:** фильтрует по участникам, уровню, длительности, нужным аксессуарам.
- **Мысли / вопросы:** «Что мы можем сыграть вдвоём прямо сейчас без подготовки?»
- **Эмоции:** 😊 / 😟 (если фильтры неудобные).
- **Точка контакта:** фильтры/поиск.
- **Боли:** нет фильтра «нужны ли игрушки», долго искать.
- **Возможности:** чипсы-фильтры, фильтр «без аксессуаров», сортировка по популярности.

## Этап 3. Просмотр игры
- **Действия:** открывает страницу: описание, правила, материалы, длительность.
- **Мысли / вопросы:** «Понятно ли, что делать? Безопасно ли?»
- **Эмоции:** 😊 / 😐
- **Точка контакта:** страница игры.
- **Боли:** нет правил/шагов, нет предупреждений.
- **Возможности:** пошаговые правила, отметка уровня/безопасности, список нужных игрушек (связь с инвентарём).

## Этап 4. Запуск игры как сессии
- **Действия:** нажимает «Играть», переходит в режим сессии (таймер/шаги).
- **Мысли / вопросы:** «Сколько прошло? Что дальше?»
- **Эмоции:** 😊
- **Точка контакта:** экран активной игры.
- **Боли:** нет таймера/шагов, неудобно держать телефон в процессе.
- **Возможности:** минимальный экран с таймером и следующим шагом, «минимальный»/голосовой режим.

## Этап 5. Фиксация результата
- **Действия:** завершает игру, приложение предлагает записать её в журнал.
- **Мысли / вопросы:** «Сохранилось ли? Как связать с записью?»
- **Эмоции:** 😊
- **Точка контакта:** диалог «Сохранить в журнал».
- **Боли:** результат не сохраняется, нужно дублировать ввод вручную.
- **Возможности:** автосоздание черновика записи с привязкой к игре.

## Итог
- **Критерии успеха:** игра находится за ≤ 1 мин; запуск сессии в 2 тапа; результат сохраняется в журнал без дублирования ввода.
