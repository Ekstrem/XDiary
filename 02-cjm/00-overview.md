# CJM — обзор

Customer Journey Map (карта путешествия пользователя) для каждого инкремента. Один файл на инкремент.

## Легенда (единый формат)

- **Этап** — фаза путешествия пользователя.
- **Действия** — что делает пользователь.
- **Мысли / вопросы** — что думает или спрашивает.
- **Эмоции** — 😊 позитив · 😐 нейтрально · 😟 тревожно/негатив.
- **Точка контакта** — где происходит (экран, файл, системный диалог).
- **Боли** — что раздражает/мешает.
- **Возможности** — как улучшаем опыт.
