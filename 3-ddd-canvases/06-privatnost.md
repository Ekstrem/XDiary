# Bounded Context Canvas: Приватность и доступ

## 1. Имя
Приватность и доступ (Privacy & Access)

## 2. Назначение
PIN-код, блокировка приложения и автоблокировка после сворачивания. Сквозной gatekeeper для всех остальных контекстов.

## 3. Стратегическая классификация
- [ ] Core Domain (конкурентное преимущество)
- [ ] Supporting (поддержка core)
- [x] Generic (типовой функционал)

## 4. Роль домена
- [x] Execution (исполняет бизнес-операции)
- [ ] Gateway (интеграция с внешними системами)
- [ ] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | ввод/смена/удаление PIN | диалог |
| Система | сворачивание приложения > 2 мин | событие visibilitychange |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Все контексты | доступ разрешён/запрещён | состояние блокировки |

## 7. Ubiquitous Language
- **PIN** — цифровой код 4–8 цифр.
- **Хеш** — PBKDF2-SHA256 с солью (хранится только хеш).
- **Блокировка / Разблокировка** — состояния доступа.

## 8. Бизнес-решения (Business Decisions)
- PIN хранится как PBKDF2-SHA256 с солью, без открытого текста.
- Смена PIN — через диалог (в настройках только кнопка).
- Автоблокировка при скрытии приложения дольше 2 минут.

## 9. Предположения (Assumptions)
- Биометрия (отпечаток/лицо) — позже.
- PIN не обязателен (можно без него).

|---|---|
| Все контексты | Gatekeeper |
