# Bounded Context Canvas: Переносимость данных

## 1. Имя
Переносимость данных (Data Portability)

## 2. Назначение
Экспорт и импорт записей и соматики в CSV, чтобы пользователь владел данными и мог их перенести/резервировать.

## 3. Стратегическая классификация
- [ ] Core Domain (конкурентное преимущество)
- [ ] Supporting (поддержка core)
- [x] Generic (типовой функционал)

## 4. Роль домена
- [x] Execution (исполняет бизнес-операции)
- [ ] Gateway (интеграция с внешними системами)
- [ ] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | «Экспорт CSV» / «Импорт CSV» / «Импорт данных Garmin» | файлы CSV |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Журнал | записи | CSV (`records`) |
| Соматика | соматика/сон/стресс/пульс покоя | CSV |
| Каталог | каталог (перспектива) | CSV |

## 7. Ubiquitous Language
- **CSV** — текстовый формат переноса.
- **Экспорт / Импорт** — направления переноса.
- **Колонки** — заголовки (started_at, duration_min, …).
- **Списки** — поля, разделённые `;` (позы, теги, игрушки…).

## 8. Бизнес-решения (Business Decisions)
- CSV — единый формат переноса (открывается в Excel/Sheets).
- Списки внутри полей разделяются `;`.
- Импорт объединяет записи по `id` (дополняет, не дублирует).

## 9. Предположения (Assumptions)
- JSON с полной схемой — позже (для безпотерьного переноса).
- CSV соматики/сна импортируется отдельно от CSV записей.

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Журнал | Published Language (CSV) |
| Соматика | Published Language (CSV) |
| Каталог и инвентарь | Published Language (CSV, перспектива) |
| Приватность и доступ | Gatekeeper |
