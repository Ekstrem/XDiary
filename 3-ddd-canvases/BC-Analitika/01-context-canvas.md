# Bounded Context Canvas: Аналитика и статистика

## 1. Имя
Аналитика и статистика (Analytics)

## 2. Назначение
Показывать тренды (стресс, пульс покоя, сон, HRV) и корреляции между активностью и соматикой. В перспективе — дашборд, стрики, цели.

## 3. Стратегическая классификация
- [ ] Core Domain (конкурентное преимущество)
- [x] Supporting (поддержка core)
- [ ] Generic (типовой функционал)

## 4. Роль домена
- [ ] Execution (исполняет бизнес-операции)
- [ ] Gateway (интеграция с внешними системами)
- [x] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Журнал | событие «акт записан» | запись (id, метрики) |
| Соматика | дневные тренды | стресс/пульс покоя/сон/HRV |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Пользователь (UI) | графики и таблицы корреляций | экран «Тренды», канвасы |

## 7. Ubiquitous Language
- **Тренд** — дневной ряд метрики.
- **Корреляция** — коэффициент Пирсона между длительностью и метрикой.
- **Дашборд** — сводный экран (будущее).
- **Стрик, Цель** — мотивационные метрики (будущее).

## 8. Бизнес-решения (Business Decisions)
- Корреляции считаются при ≥ 3 записях с данными.
- Метрики тренда: стресс, пульс покоя, сон (оценка), HRV.
- Экспорт данных — через контекст «Переносимость данных» (CSV).

## 9. Предположения (Assumptions)
- Дашборд, стрики и цели — следующие инкременты (ST-01, ST-04).
- Корреляции требуют достаточно длинного периода соматики (≥ месяц).

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Журнал | Customer/Supplier (поставщик событий) |
| Соматика | Customer/Supplier (поставщик трендов) |
| Переносимость данных | Published Language (CSV) |
| Приватность и доступ | Gatekeeper |
