# Bounded Context Canvas: Аналитика

## 1. Имя
Аналитика (Analytics) — бывш. «Статистика и аналитика» / «Тренды».

## 2. Назначение
Показывать аналитику пары: сводку за период, «физиопрофиль» сессии (пульс/Body Battery до-во время-после), топ-списки (позы/игрушки/костюмы/фантазии/места/партнёры), распределение по дням/времени, пороги и аномалии, расширенные корреляции, стрики/цели.

- [x] Supporting (поддержка core)

## 4. Роль домена
- [ ] Execution (исполняет бизнес-операции)
- [ ] Gateway (интеграция с внешними системами)
- [x] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Журнал | событие «акт записан» | запись (id, метрики) |
| Соматика | дневные тренды + срезы | стресс/пульс/BB/сон/HRV |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Пользователь (UI) | сводка/физиопрофиль/топы/корреляции | экран «Аналитика» |

## 7. Ubiquitous Language
- **Сводка за период** — карточки: сессии, суммарное время, средняя длительность, оргазмы, средняя оценка, стрик.
- **Физиопрофиль сессии** — пульс и Body Battery до/во время/после (±30 мин) + инсайты.
- **Топ-список** — позы/игрушки/костюмы/фантазии/места/партнёры (месяц/всё время).
- **Распределение** — по дням недели и времени суток.
- **Порог** — типичный пик пульса, BB на старте, падение BB.
- **Инсайт** — объяснение на русском + n наблюдений.
- **Корреляция** — коэффициент Пирсона между парами метрик.

## 8. Бизнес-решения (Business Decisions)
- Переключатель периода: 30 / 90 дней / всё время.
- Корреляции с пояснением на русском и числом наблюдений (n).
- Подсветка аномальных сессий против «порогов».

## 9. Предположения (Assumptions)
- Требует соматики (инк 3) для физиопрофиля и порогов.
- Стрики/цели — ST-04 (следующий инкремент).
