# Materialized Views: Аналитика и статистика

## Проекции
Постоянных хранилищ нет — проекции вычисляются на лету из чужих stores.

| Проекция | Тип | Источник |
|---|---|---|
| Тренд (стресс/пульс/сон/HRV) | computed | `weekly` + `sleep` |
| Корреляции | computed | `records` (durationMin) × `weekly`/`sleep` (метрики) |

## Правила вычисления
| Проекция | Правило |
|---|---|
| Тренд | фильтр точек с непустым полем метрики, график по датам |
| Корреляция | pearson(durationMin[], metric[]) при n ≥ 3 |

## Перспектива (следующие инкременты)
- Дашборд (частота/длительность/оргазмы) — ST-01.
- Стрики и цели — ST-04.
