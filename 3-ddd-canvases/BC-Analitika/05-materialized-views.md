# Materialized Views: Аналитика

## Проекции
Постоянных хранилищ нет — проекции вычисляются на лету из чужих stores.

| Проекция | Тип | Источник | Статус |
|---|---|---|---|
| Сводка | computed | `records` (агрегация) | ⬜ |
| Физиопрофиль | computed | `somatic` (срезы вокруг актов) | ⬜ |
| Топ-списки | computed | `records` (счётчики по полям) | ⬜ |
| Распределение | computed | `records.startedAt` (день/час) | ⬜ |
| Пороги | computed | `somatic` (типичные пики/BB) | ⬜ |
| Тренд | computed | `weekly` + `sleep` | ✅ |
| Корреляции | computed | `records` × `weekly`/`sleep` | ✅ |

## Правила вычисления
| Проекция | Правило |
|---|---|
| Сводка | агрегация записей за период (30/90/all): count, sum(durationMin), avg, sum(orgasms), avg(rating), streak |
| Физиопрофиль | усреднённый профиль пульса/BB по окну ±30 мин вокруг startedAt |
| Топ-списки | group by поле (позы/игрушки/…) → count → top |
| Распределение | group by день недели и час startedAt |
| Пороги | типичный пик пульса, BB на старте; аномалии = выход за пороги |
| Корреляции | pearson(durationMin[], metric[]) / (orgasms[], hr[]) / (bb[], durationMin[]) / (sleep[], frequency[]) при n ≥ 3 |

## Перспектива (следующие инкременты)
- ST-01 (сводка), ST-05 (физиопрофиль), ST-06 (топы), ST-07 (распределение), ST-08 (пороги) — не реализованы.
- ST-04 (стрики/цели) — отдельно.
