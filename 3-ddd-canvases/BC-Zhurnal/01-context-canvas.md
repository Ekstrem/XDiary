# Bounded Context Canvas: Журнал интимной активности

## 1. Имя
Журнал интимной активности (Activity Journal)

## 2. Назначение
Фиксировать и просматривать акты пары: дата/время, партнёр, место, позы, аксессуары (костюмы/игрушки/фантазии/теги), контрацепция, длительность, оргазмы (тип + оценка). Это ядро продукта — ради него существует приложение.

## 3. Стратегическая классификация
- [x] Core Domain (конкурентное преимущество)
- [ ] Supporting (поддержка core)
- [ ] Generic (типовой функционал)

## 4. Роль домена
- [x] Execution (исполняет бизнес-операции)
- [ ] Gateway (интеграция с внешними системами)
- [ ] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | создать/редактировать/удалить запись | визард (шаги), IndexedDB `records` |
| Приватность и доступ | разблокировать приложение | PIN → доступ к журналу |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Партнёры | выбор партнёра | имя партнёра |
| Каталог | выбор костюмов/игрушек/фантазий/контрацепции | имена элементов (массивы) |
| Соматика | запрос среза вокруг времени акта | `startedAt` ± окно |
| Аналитика | событие «акт записан» | запись (id, метрики) |
| Перенос данных | экспорт записей | CSV |

## 7. Ubiquitous Language
- **Запись / Акт** — единица фиксации активности.
- **Визард** — цепочка шагов вместо формы.
- **Партнёр, Место, Поза** — участники и контекст.
- **Аксессуары** — костюмы, игрушки, фантазии, теги.
- **Контрацепция** — средства (презервативы) со счётчиком.
- **Длительность** — `durationMin`.
- **Оргазм** — счётчик + тип (мультивыбор по полу) + оценка 1–5.
- **startedAt** — локальное время начала «YYYY-MM-DDTHH:mm».

## 8. Бизнес-решения (Business Decisions)
- Ввод через визард, а не единую форму.
- Пол («мой» и партнёра) определяет набор типов оргазмов.
- Клик по плашке инкрементирует счётчик через 0.6 с; кнопка сброса «↺».
- Последние партнёр и место подставляются по умолчанию.

## 9. Предположения (Assumptions)
- Одна пара; данные локальны.
- Автодетекции нет (пока) — только ручная фиксация.
- Позы/партнёры со временем получат «вес» (частота + недавность) — PR-1.

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Партнёры | Customer/Supplier |
| Каталог и инвентарь | Customer/Supplier |
| Соматика | Customer/Supplier |
| Аналитика и статистика | поставщик событий |
| Переносимость данных | Published Language (CSV) |
| Приватность и доступ | Gatekeeper |
