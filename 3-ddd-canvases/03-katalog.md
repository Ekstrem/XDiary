# Bounded Context Canvas: Каталог и инвентарь

## 1. Имя
Каталог и инвентарь (Catalog & Inventory)

## 2. Назначение
Вести каталог предметов по видам: костюмы, игрушки, фантазии, контрацепция (в перспективе — секс-игры). Отмечать использование, бренд, архивный статус, партнёра фантазии.

## 3. Стратегическая классификация
- [ ] Core Domain (конкурентное преимущество)
- [x] Supporting (поддержка core)
- [ ] Generic (типовой функционал)

## 4. Роль домена
- [x] Execution (исполняет бизнес-операции)
- [ ] Gateway (интеграция с внешними системами)
- [ ] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | CRUD элемента | форма (название, бренд, фото, заметки, пол/партнёр, архив) |
| Журнал | выбор элементов для записи | имена по видам |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Журнал | списки элементов по видам | IndexedDB `catalog` |
| Аналитика | использование элементов | имена (костюмы/игрушки/фантазии) |
| Перенос данных | экспорт каталога | CSV (перспектива) |

## 7. Ubiquitous Language
- **Костюм** — элемент вида `costume`.
- **Игрушка** — элемент вида `toy` (с брендом и архивом).
- **Фантазия** — элемент вида `fantasy` (с партнёром и признаком «реализована»).
- **Контрацепция** — элемент вида `contraception` (презервативы).
- **Бренд** — производитель игрушки.
- **Архив** — скрытый элемент (внизу списка, с возвратом).
- **Реализованная фантазия** — фантазия, использованная в записи.

## 8. Бизнес-решения (Business Decisions)
- Единый каталог с полем `kind` (costume/toy/fantasy/contraception).
- Архивные игрушки — внизу списка, полупрозрачные, с кнопкой «Вернуть из архива».
- Фантазия привязана к партнёру (select).
- Контрацепция выбирается на отдельном шаге записи со счётчиком; недавно использованные — впереди.

## 9. Предположения (Assumptions)
- Физические секс-игры (настольные/карточные) учтутся как инвентарь позже (IG-07).
- Полная история использования и обслуживание игрушек — следующие инкременты.

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Журнал | Customer/Supplier (поставщик выбора) |
| Партнёры | Customer/Supplier (для фантазий) |
| Аналитика и статистика | поставщик данных использования |
| Приватность и доступ | Gatekeeper |
