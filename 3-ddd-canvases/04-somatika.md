# Bounded Context Canvas: Соматика

## 1. Имя
Соматика (Somatics)

## 2. Назначение
Импорт и хранение соматических данных (пульс, Body Battery, стресс, сон, HRV) из локальных CSV/прокси и выдача срезов вокруг времени акта. Стратегический дифференциатор — интеграция с экосистемой Garmin.

- [x] Supporting (поддержка core)
- [ ] Generic (типовой функционал)

## 4. Роль домена
- [ ] Execution (исполняет бизнес-операции)
- [x] Gateway (интеграция с внешними системами)
- [ ] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | «Обновить статистику» / автосинк при входе | команда синка |
| Журнал | запрос среза вокруг времени акта | `startedAt` ± окно (15/30/60 мин) |
| Аналитика | запрос дневных трендов | даты |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Журнал | срез пульса/Body Battery | точки «YYYY-MM-DDTHH:mm» |
| Аналитика | дневные стресс/пульс покоя/сон/HRV | IndexedDB `weekly`, `sleep` |
| Garmin (внешний) | запросы данных | HTTP через прокси (нет прямого доступа) |

## 7. Ubiquitous Language
- **Соматика** — физиологические метрики тела.
- **Пульс, Body Battery, Стресс, Сон, HRV** — импортируемые метрики.
- **Точка** — значение за минуту (`t` = «YYYY-MM-DDTHH:mm»).
- **Срез вокруг акта** — окно ±N минут вокруг `startedAt`.
- **Синк** — пошаговая загрузка (стресс → пульс/BB → сон → HRV → занятия).
- **Прокси** — локальный HTTP-сервис на ПК, отдающий CSV.

## 8. Бизнес-решения (Business Decisions)
- В Garmin не ходим напрямую из приложения: данные берём из локальных CSV через прокси.
- Синк пошаговый с индикатором; окно — минимум 30 дней.
- OAuth-токен кэшируется на 23 часа; стресс тянется кусками по 7 дней.
- HRV — только дневной (ночной), поминутного нет.

## 9. Предположения (Assumptions)
- Garmin доступен на ПК (прокси в той же Wi-Fi).
- «Дыхание» (respiration) пока не импортируется — следующий инкремент.
- Прямая интеграция (Personal API) требует ключа в `.env` на ПК.

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Журнал | Customer/Supplier (поставщик среза) |
| Аналитика и статистика | Customer/Supplier (поставщик трендов) |
| Garmin (внешний) | Anti-Corruption Layer |
| Переносимость данных | Published Language (CSV) |
| Приватность и доступ | Gatekeeper |
