# Query API: Переносимость данных

## Запросы (чтение)
| Запрос | Функция (код) | Response | Источник |
|---|---|---|---|
| Заголовки CSV | CSV_HEADERS (константа) | список колонок | код |
| Распознавание типа | handleImportAnyFile (по заголовку) | тип CSV | CSV |

## Response DTO
- Типы CSV: records / somatic / sleep / stress / resting_hr (определяется по заголовкам).

## Потребители
| Потребитель | Запросы | Назначение |
|---|---|---|
| UI пользователя | экспорт/импорт | перенос и резерв |
