## Правило квитанции: всегда называть охват сборки (@TL, п.23 2026-11-13 01:03)

Если квитанция ссылается на прогон, включающий **сборку**, в ней обязателен охват: не «PASS 10/10»,
а «PASS 10/10, сборка **6 из 31** проекта». Причина: check_adr028_move.py --post при недоступном
restore печатает ::warning:: проверено 6 из 31 тестовых проектов и всё равно даёт 
c=0, поэтому
«10/10» без охвата читается как «собрано всё» — класс «зелёный на части». Такое предупреждение —
не шум, а часть результата: без него квитанция врёт масштабом.
