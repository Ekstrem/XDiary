# `DO-115`: обе стороны §5.4 для `check_canon` проверены (`2026-11-11`, круг 4)

Прогон в изолированном worktree (`git worktree add --detach … origin/main`), общий `main` не тронут;
после проверки файлы-пробы удалены, worktree чист (`git status --porcelain` пуст).

## Плечи

| Плечо | Что сделано | Квитанция |
|---|---|---|
| **норма** | прогон на `origin` | `rc=0`, `источник файлов: git ls-files (708 шт.)`, `ok: canon:receipt-v1 — ./04-architecture/ADL/adr-026.md` |
| **дефект** (класс `DO-115`) | рядом положены **две** копии файла с маркером (`.tmp-check-origin/adr-026-copy-{1,2}.md`) | `rc=0`, счётчик по-прежнему **1** и тот же адрес; `git ls-files (708)` — копии не попали в счёт, как и должно быть (старый дефект давал «3 раза») |
| **не-git-корень** | `--root` на каталог без `.git` (`.tmp-not-a-repo`) | `rc=2`, `источник файлов: НЕ ИЗМЕРЕНО: root не git-корень`, `::error:: НЕ ИЗМЕРЕНО — обход дерева не используется: он считает вложенные копии; см. DO-115` |

Плюс `--selftest` → `1/0/2/1 (ждём 1/0/2/1)`, то есть кейсы внутри самопроверки совпадают с ожиданиями.

## Что это значит для карточки

Критерии `DO-115`, которые проверяются моей стороной, выполнены:

- «при вложенной копии рядом маркер считается **1** раз, а не 3» — **подтверждено** (две копии рядом, счётчик 1);
- «в квитанции печатается **чем** считали» — **подтверждено**: строка `источник файлов: git ls-files (708 шт.)`
  и отдельная строка для не-git-корня («НЕ ИЗМЕРЕНО: root не git-корень»);
- «§5.4 в обе стороны» — норма `rc=0`, не-git-корень `rc=2`; дефект-плечо проверено копиями.

**Чего моя проверка не заменяет:** у карточки есть критерий «`--selftest` с кейсом „вложенный каталог
с `.git` не учитывается“ либо „не git-корень → `rc=2`“». Сейчас самопроверка печатает **`1/0/2/1`** и среди
кейсов есть не-git-корень (видно по `rc=2`), но **отдельного** кейса «вложенный каталог с `.git` не
учитывается» я не увидел; это зона @DO — правка `tools/check_canon.py` (+ копия в `LoopMaker/tools/`).
