## Красная проверка на `main`: `check_readstore_ddl` → `rc=2`

```
сверено моделей с DDL: 0 | расхождений: 0
::error::check_readstore_ddl: ни одной модели с DDL не найдено — фильтр сломан
```

При этом `check_readstore_ddl --selftest` → **14/14, rc=0**. То есть самопроверка зелёная, а прогон красный —
ровно класс `AR-023` («зелёный на пустоте», только наоборот).

**Причина (проверено чтением):** гейт ищет DDL регуляркой `CREATE TABLE IF NOT EXISTS …` в `Program.cs`
(`tools/check_readstore_ddl.py:33`), а регистрации на месте (`6-msa/BC-Journal/src/Journal.Api/Program.cs:44-46`,
`BC-Partners/…/Program.cs:50`). Но самого `CREATE TABLE IF NOT EXISTS` в `6-msa/**/*.cs` **нет ни одного**:
DDL теперь выражен EF-миграцией `migrationBuilder.CreateTable(...)` —
`6-msa/BC-Journal/src/Journal.Storage/Migrations/ReadStore/20261105170525_AddReadStores.cs:14`
(и такой же файл в `BC-Partners`). Гейт ищет SQL-строку, которой больше не существует, поэтому «моделей 0».

**Что нужно (зона @DO):** читать `CreateTable(...)` из миграций (или `.Sql("CREATE TABLE …")`, если вернут SQL),
и заодно покрыть это кейсом `--selftest`: «DDL только в миграции → модель всё равно сверяется».

## `chat_lint`: причина слепоты найдена (круг 5)

Повторил пробу на свежем `origin` (изолированный worktree): строка
`- [без метки] -> @TE: рецепт проверки` → гейт печатает «всё чисто», `rc=0`. Причина — регулярка
`tools/chat_lint.py:44-47`:

```python
CANON = re.compile(
    r"^-\s*(?:\[([^\]]+)\]|(\d{4}-\d{2}-\d{2}[ T]\d{1,2}:\d{2}))"
    r"\s*(?:→|->|=>)\s*@?([^:]+?)\s*:\s*(.+)$"
)
```

1. `\[([^\]]+)\]` принимает **любое** содержимое скобок — значит `[без метки]` считается меткой времени;
2. `->`/`=>` принимаются наравне с канонической `→`, хотя канон §4 — «`→ @КОМУ:`».

`CANDIDATE` (строка 51) такую строку ловит, но `CANON` её пропускает — поэтому «нераспознанных строк нет».

**Правка, и она безопасна для истории** (замер по всем 9 outbox-файлам на `origin`):

| Класс | Вхождений |
|---|---|
| ASCII-стрелка (`->`/`=>`) с меткой времени | **0** |
| «скобка-не-время» (`[что-то]` вместо `[YYYY-MM-DD HH:mm]`) | **1** — в `chat/README.md` (пример) |

То есть строгий `CANON` (`\[\d{4}-\d{2}-\d{2}[ T]\d{1,2}:\d{2}\]` + только `→`) не сломает ни одной
реальной строки. Кейсы для `--selftest` (сейчас `7/7`, этой дыры нет): «скобка не время → красный»,
«ASCII-стрелка → красный», «канон → зелёный».

**Вывод для `AR-023`:** по `chat_lint` критерий «дефект-строка → `rc=1`» **не выполнен** — доказано
прогоном, а не чтением.

## Аудит: какие гейты CI «зелёные на пустоте» без PyYAML (круг 8)

Метод: в изолированном worktree подсунул `yaml.py`, падающий на импорте (`PYTHONPATH`), и прогнал **все 23**
гейта, которые зовутся в `ci-guards.yml` / `guard-paths.yml`. worktree после проверки чист.

**Итог: ровно один гейт молча зелёный без зависимости — `check_workflow_paths`.**

| Гейт | `rc` без PyYAML | Что печатает |
|---|---|---|
| `check_workflow_paths` | **0** | `check_workflow_paths: PyYAML не установлен — пропускаю` |
| остальные 22 | 1–2 или честный `rc=0` с квитанцией | например `check_readstore_ddl: сверено моделей 4 \| расхождений 0`, `check_test_isolation: проектов 96 \| нарушений 0` |

То есть дефект узкий и точный: `tools/check_workflow_paths.py:20` («без него — предупреждение и код 0») +
`:68-70` (`if yaml is None: print(...); return 0`).

**Почему это не косметика:** гейт зовётся **только** из `guard-paths.yml:99`, а в этом workflow
`actions/setup-python` есть, а `pip install pyyaml` **нет** (в отличие от `apim-auth.yml:39`,
`canon-stability.yml:44`, `workflow-shape.yml:29`, где установка есть). Значит на раннере гейт почти
наверняка печатает «пропускаю» и отдаёт `rc=0` — проверка фильтров путей не измеряется вообще.

**Правка (зона @DO, `tools/` + копия `LoopMaker/tools/`):** либо `return 2` + `::warning::НЕ ИЗМЕРЕНО`
(таксономия остальных моих измерителей), либо добавить `python -m pip install --quiet pyyaml` в
`guard-paths.yml`; лучше — оба: установка, чтобы гейт работал, и `rc=2`, чтобы отсутствие зависимости не
выглядело как «проверено».

**Квитанция аудита (сводно):** гейтов проверено 23 | «зелёных на пустоте» — **1** (`check_workflow_paths`) |
остальные 22 без PyYAML либо измеряют (не нужен), либо честно падают.
