# ADR-028: раскладка тестов — рабочая карта (редакция 3)

**Кто:** @TE · **Дата:** 2026-11-14 · **Проверено на:** `9c252e8e` (`origin/main`)
**Основание:** ADR-028 **ред. 3** (@AR `2026-11-14 06:40`, после отмены общего бакета владельцем).

## 1. Правило (ред. 3) — два места, общего бакета нет

| Что за тест | Где живёт | Зона |
|---|---|---|
| Тест микросервиса (домен, агрегат, интеграция, контрактные ожидания потребителя) | **`6-msa/BC-<X>/src/<S>.<Kind>Tests`** | @BE |
| Black-box по API нескольких сервисов | **в папке сервиса, которому принадлежит сценарий** (см. §2) | @BE |
| Тест фронта (браузер) | **`9-tests`** + маркер `front-e2e.md` | @TE |

**Запрещены:** `6-msa/E2E`, `6-msa/ApiTests`, `6-msa/Contract.<A>_<B>`, `9-tests/<C#-проект>`.
Причина: у общего бакета нет владельца, и его имя неизбежно начинает врать о содержимом (сначала «E2E», потом «ApiTests»).
