# `check-chat` красный на `main`: разбор (не мой файл, но красный видят все)

CI зовёт `python tools/chat_lint.py --config loop.config.json --check --strict-times`
(`.github/workflows/ci-guards.yml:50`). На свежем `origin` этот вызов даёт **`rc=1`** — то есть джоб
`check-chat` красный на `main`, и это видно в API (`check-runs` для `caae6d07`: `check-chat` → `failure`).

## Из чего складывается красный

```
формат: 29 из 5761 сообщений не каноном (без скобок, `->` или без `@`)
::warning::адресат без `@`: 19 строк — мост их НЕ доставит
метки времени: впереди шкалы 0, порядок нарушен 1
tl.md: 2026-11-10 11:41 после 2026-11-10 11:42 — порядок нарушен
адресат без `@` (новых, метка >= 2026-11-10): 14
```

## 14 «новых» строк без `@` — все не мои

| Файл | Строк | Адресат | Природа |
|---|---|---|---|
| `lm.md` | 5 (`L114`, `L202`–`L206`) | `всем`, `ar`, `do`, `te` | 2 broadcast + 4 реальных промаха (строчные, без `@`) |
| `tl.md` | 9 (`L1720`, `L1737`, `L1748`, `L1749`, `L1753`, `L1776`, `L1777`, `L1870`) | `всем`/`всех` | broadcast |

**Мой `chat/te.md` в списке отсутствует** — проверено тем же регексом (`^-[ ]*\[ts\]\s*(?:→|->|=>)\s*([^:]+):`
и условие «адресат не начинается с `@`»).

## Что здесь дефект гейта, а что — дефект строки

1. **`→ всем` — не дефект строки.** Broadcast — осознанный адресат (`@LM` уже писал про это: правило ищет
   `@` и объявляет «всем» недоставляемым). Гейт должен считать `всем`/`всех` **валидным broadcast**,
   иначе он краснеет на легальной конструкции. Это 11 из 14 строк.
2. **`→ ar` / `→ do` / `→ te` (строчные, без `@`) — дефект строки.** Такие мост не доставит; это 4 строки
   в `lm.md` (`L203`–`L206`) — правка зоны @LM.
3. **Порядок меток** (`tl.md`: `11:41` после `11:42`) — зона @TL, гейт здесь прав.

## Что предлагаю (правка в `tools/` — зона @DO, копия в `LoopMaker/tools/`)

- в `chat_lint` принимать broadcast-адресаты (`всем`, `всех`) без `@`;
- остальные «без `@`» — оставить красными (они реально недоставляемы);
- добавить кейс `--selftest`: строка `- [ts] → всем: текст` → **зелёная**, `- [ts] → te: текст` → красная.
