# Bounded Context Canvas: Клиент (Client)

## 1. Имя
Клиент (Client) — идентификация/аутентификация пользователя (ADR-021).

## 2. Назначение
Аккаунт пользователя: номер телефона, верификация (SMS OTP), связь с партнёром-«я».

## 3. Стратегическая классификация
Supporting.

## 4. Роль домена
Execution (идентификация).

## 5. Inbound
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| UI (PWA) | регистрация, верификация OTP, связь с партнёром | REST `/api/v1/clients` |

## 6. Outbound
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Partners | ссылка `clientId` (партнёр-«я») | ссылка |

## 7. Ubiquitous Language
| Термин | Определение |
|---|---|
| Клиент (Client) | пользователь (номер телефона) |
| «Я» | партнёр, связанный с текущим клиентом |
| Верификация | подтверждение номера (SMS OTP) |

## 8. Бизнес-решения
- Идентификация по номеру телефона (пока); PIN — опционально (Privacy BC, ADR-008).

## 9. Зависимости
| Контекст | Тип интеграции |
|---|---|
| Partners | ссылка `clientId` (Customer/Supplier) |
| Privacy | PIN/JWT (Gatekeeper) |
