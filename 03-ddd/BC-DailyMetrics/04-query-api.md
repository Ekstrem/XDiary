# Query API: Дневные метрики

## Запросы (чтение)
| Запрос | Функция (код) | Response | Источник |
|---|---|---|---|
| Дневные тренды | renderTrends() / getWeekly | DailySeries | `weekly`, `sleep` |

## Response DTO
- DailySeries: стресс, пульс покоя, сон (оценка), HRV по датам.

|---|---|---|
