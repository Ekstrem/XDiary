# Bounded Context Canvas: Дневные метрики

## 1. Имя
Дневные метрики (DailyMetrics)

## 2. Назначение
Хранить дневные сводки физиологии (стресс, пульс покоя, HRV, сон) и отдавать тренды Аналитике. Один агрегат — DailyMetrics.

## 3. Стратегическая классификация
- [ ] Core Domain (конкурентное преимущество)
- [x] Supporting (поддержка core)
- [ ] Generic (типовой функционал)

## 4. Роль домена
- [ ] Execution (исполняет бизнес-операции)
- [x] Gateway (интеграция с внешними системами)
- [ ] Analysis (аналитика, отчёты)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | «Обновить статистику» / автосинк | команда синка |
| Аналитика | запрос дневных трендов | даты |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Аналитика | стресс / пульс покоя / сон / HRV по дням | IndexedDB `weekly`, `sleep` |
| Garmin (внешний) | запросы данных | HTTP через прокси |

## 7. Ubiquitous Language
- **Стресс** — stress (int, день).
- **Пульс покоя** — resting_hr (int).
- **HRV** — hrv (int, ночной).
- **Сон** — score, durationMin, deepMin, lightMin, remMin, awakeMin.
- **День** — дата (keyPath).

## 8. Бизнес-решения (Business Decisions)
- Стресс тянется кусками по 7 дней (лимит эндпоинта).
- HRV — только дневной (ночной), поминутного нет.

## 9. Предположения (Assumptions)
- «Дыхание» пока не импортируется.
- Требует Garmin на ПК (прокси).

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Аналитика | Customer/Supplier (поставщик трендов) |
| Garmin (внешний) | Anti-Corruption Layer |
| Переносимость данных | Published Language (CSV) |
| Приватность и доступ | Gatekeeper |
