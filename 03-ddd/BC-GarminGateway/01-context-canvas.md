# Bounded Context Canvas: Шлюз Garmin

## 1. Имя
Шлюз Garmin (GarminGateway)

## 2. Назначение
Anti-Corruption Layer к экосистеме Garmin. Изолирует модель Garmin (Personal API, OAuth, CORS) и отдаёт две нормализованные сущности: **соматику** (пульс, Body Battery, стресс, сон, HRV) и **занятия** (активности/сессии). Один агрегат — GarminSync.

## 3. Стратегическая классификация
- [ ] Core Domain
- [x] Supporting
- [ ] Generic

## 4. Роль домена
- [ ] Execution
- [x] Gateway (интеграция с внешними системами)
- [ ] Analysis

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | «Обновить статистику» / синк / «Из Garmin» | команда синка |
| Соматика (минутные точки / дневные) | запрос нормализованной соматики | метрики за период |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Соматика — минутные точки | точки пульс / Body Battery | нормализованные точки |
| Дневные метрики | стресс / пульс покоя / HRV / сон | нормализованные дневные сводки |
| Журнал | занятия (кандидаты в акты) | активность (start, end, hr) |
| Garmin (внешний) | запросы данных | HTTP (Personal API) |

## 7. Ubiquitous Language
- **Соматика** — физиологические метрики (точки/дневные сводки).
- **Занятие** — активность/сессия с таймстампом (кандидат в акт журнала).
- **Синк** — пошаговая загрузка (стресс → пульс/BB → сон → HRV → занятия).
- **Токен** — OAuth (кэш 23 ч).

## 8. Бизнес-решения (Business Decisions)
- Синк пошаговый; окно минимум 30 дней; токен кэшируется 23 ч.
- Занятия по умолчанию без фильтра «избранное» (виден ❤/🖤).

## 9. Предположения (Assumptions)
- Garmin доступен на ПК (прокси в той же Wi-Fi).
- «Дыхание» пока не импортируется.

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Соматика — минутные точки | Customer/Supplier (норм. точки) |
| Дневные метрики | Customer/Supplier (норм. сводки) |
| Журнал | Customer/Supplier (занятия) |
| Garmin (внешний) | Anti-Corruption Layer |
| Приватность и доступ | Gatekeeper |
