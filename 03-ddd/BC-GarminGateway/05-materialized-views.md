# Materialized Views: Шлюз Garmin

## Проекции
Шлюз не хранит постоянных данных соматики/занятий — отдаёт нормализованные DTO наружу.

| Проекция | Тип | Назначение |
|---|---|---|
| Соматика (норм.) | поток DTO | → SomaticSeries / DailyMetrics |
| Занятия (норм.) | поток DTO | → Журнал (автоперенос) |

## Проекционные правила
| Событие | Действие |
|---|---|
| GarminSomaticsFetched | отдать точки/сводки в соматику |
| GarminActivitiesFetched | отдать занятия в журнал |
