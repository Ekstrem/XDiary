# Aggregate Design Canvas: CsvDocument (документ переноса)

> Bounded Context: Переносимость данных (Portability)
> Агрегат: CsvDocument (документ-агрегат, транзитный)

## 1. Name (Имя)
- **Имя:** CsvDocument (CSV-документ переноса).
- **Создаётся когда:** экспорт или импорт CSV.

## 2. Description (Описание)
Контекст сериализует/десериализует записи и соматику в CSV — «опубликованный язык» (Published Language) для обмена.

**Идентификатор агрегата (DF):**
- Составной ключ `<guid, long>` — технический, для **быстрого поиска**. Документ транзитный (формируется/читается разово).

**Сущность (Entity — корень агрегата):**
- **CsvDocument** — транзитный документ; идентичность неявная (экспорт/импорт-батч).

**Объект-значения (Value Objects):**
- **Headers**: фиксированный набор колонок (CSV_HEADERS)
- **Row**: строка записи (поля, списки через `;`)

**2.2. Состояние (`AnemicModel`) — атрибуты корня агрегата (AR-017).** Сверено с кодом 2026-11-15:
`ICsvDocumentAnemicModel` (`Root`, `Rows`, `Kind`) + `CsvDocumentRoot` (`Headers`).

| Атрибут | Тип в коде | Кард. | Обяз. | Задаётся | Инвариант | Источник |
|---|---|---|---|---|---|---|
| `Root.Headers` | `IReadOnlyList<string>` | 1 | **да** | `Upload(kind, headers, rows)` | первая строка CSV; **порядок значим** (позиции колонок должны совпадать с `Rows`), дубли заголовков → отказ | US-007 |
| `Rows` | `IReadOnlyList<string>` | 1 | **да** | `Upload` | число колонок в каждой строке == `Headers.Count`; иначе строка отбрасывается целиком, а не «докидывается» | US-007 |
| `Kind` | string | 1 | **да** | `Upload` | один из поддерживаемых форматов (журнал/соматика/метрики); неизвестный → 400 | US-007 |

**2.2.2. Расхождения:** `Headers`/`Rows` — плоские списки строк, поэтому **типы колонок не описаны** и валидируются
только на импорте: ошибка «в этой колонке дата, а не число» обнаружится при разборе, а не при загрузке. Для экспорта
это приемлемо, для импорта — нет (пользователь получит отказ позже, чем мог бы).
