# Bounded Context Canvas: Соматика — минутные точки

## 1. Имя
Соматика — минутные точки (SomaticSeries)

## 2. Назначение
Хранить минутные физиологические точки (пульс, Body Battery) и отдавать срезы вокруг времени акта. Один агрегат — SomaticPoint. Источник — носимые устройства (Garmin / Apple Watch), данные нормализуются в единый формат.

- [x] Supporting (поддержка core)
- [ ] Generic (типовой функционал)

## 4. Роль домена
- [ ] Execution (исполняет бизнес-операции)
- [x] Gateway (интеграция с внешними системами)

## 5. Входящая коммуникация (Inbound)
| Кто вызывает | Что вызывает | Формат |
|---|---|---|
| Пользователь (UI) | «Обновить статистику» / автосинк | команда синка |
| Журнал | запрос среза вокруг акта | `startedAt` ± окно (15/30/60 мин) |

## 6. Исходящая коммуникация (Outbound)
| Кому отправляет | Что отправляет | Формат |
|---|---|---|
| Журнал | срез пульса / Body Battery | точки «YYYY-MM-DDTHH:mm» |
| Носимые устройства (Garmin / Apple Health) | импорт данных | HTTP / CSV |

## 7. Ubiquitous Language
- **Точка** — значение за минуту (`t`).
- **Пульс** — hr (int).
- **Body Battery** — body_battery (int).
- **Срез вокруг акта** — окно ±N минут вокруг `startedAt`.
- **Синк** — пошаговая загрузка.
- **Прокси** — локальный HTTP-сервис на ПК.

## 8. Бизнес-решения (Business Decisions)
- В Garmin не ходим напрямую: данные из локальных CSV через прокси.
- Окно синка — минимум 30 дней; OAuth-токен кэшируется на 23 часа.

## 9. Предположения (Assumptions)
- Garmin доступен на ПК; Apple Health — через ручной экспорт из «Здоровье».
- «Дыхание» (respiration) пока не импортируется.

## 10. Зависимости / интеграции
| Контекст | Тип интеграции |
|---|---|
| Журнал | Customer/Supplier (поставщик среза) |
| Garmin / Apple Health (внешние) | Anti-Corruption Layer |
| Переносимость данных | Published Language (CSV) |
| Приватность и доступ | Gatekeeper |
