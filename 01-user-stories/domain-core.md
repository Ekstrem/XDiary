# Смысловое ядро (Core Domain) XDiary

Единый справочник по домену. Источник истины для команды реализации: если смысл термина неясен — сюда или к PO.

## 1. Главное понятие

**Запись (акт)** — фиксация одного сексуального эпизода пары. Центральная сущность журнала. Всё остальное (партнёры, каталог, соматика, аналитика) существует вокруг записи.

## 2. Сущности и атрибуты

### Запись (Record)
| Поле | Смысл |
|---|---|
| startedAt | дата/время начала (локальное) |
| durationMin | длительность, мин |
| partner | имя партнёра (один на запись) |
| place | место |
| positions[] | позы (несколько) |
| tags[] | свободные теги |
| costumes[] / toys[] / fantasies[] | аксессуары из каталога |
| contraceptives[] + contraceptiveCount | использованная контрацепция (что + сколько) |
| orgasmsMe / orgasmsPartner | число оргазмов «я» / партнёр |
| orgasmMeType[] / orgasmPartnerType[] | типы оргазмов (по полу) |
| orgasmMeRating / orgasmPartnerRating | оценка 1–5 |
| garmin / garminId | признак и id занятия из Garmin |

### Партнёр (Partner)
- `name`, `photo`, `gender` (male | female), `notes`.
- `gender` определяет список типов оргазмов.

### Элемент каталога (CatalogItem)
- `kind`: `costume` | `toy` | `fantasy` | `contraception`.
- Общее: `name`, `photo`, `notes`.
- `toy`: + `brand` (бренд), + `archived` (архив — вниз списка, возврат).
- `fantasy`: + `partner` (чей фантазия), + признак «реализована» (по факту использования в записи).
- `contraception`: средства (презервативы и т.п.).

### Соматика (Somatic) — временные ряды
- Поминутно: `hr` (пульс), `body_battery`.
- По дням: `stress`, `resting_hr`, `hrv`, `sleep`.
- Источник: **Garmin** или **Apple Health**.
- Body Battery и «стресс» есть **только у Garmin**; у Apple — `hr`, `hrv`, `sleep`, `resting_hr`. Отсутствующие метрики просто пустуют.

### Аналитика (производное)
- Сводка, топы, распределение по времени, корреляции, «пороги» — считается из записей + соматики, ничего не хранит отдельно.

## 3. Отношения
- Запись → 1 партнёр; 1 место; N поз; N аксессуаров; контрацепция = список средств + общий счётчик.
- Каталог — источник допустимых значений для аксессуаров/контрацепции/фантазий (запись хранит **имена**, а не ссылки).
- Соматика связывается с записью по времени (окно ±N минут).

## 4. Ubiquitous Language (словарь)
- **Запись / Акт** — один эпизод.
- **Партнёр, Место, Поза, Аксессуары** (Костюм/Игрушка/Фантазия/Тег), **Контрацепция, Оргазм, Длительность**.
- **Соматика, Аналитика, Тренд, Корреляция, Стрик, Порог** — производные понятия.

## 5. Правила домена (инварианты)
- Типы оргазмов зависят от пола: male — «обычный», «простатический»; female — «клиторальный», «вагинальный».
- «Вес» позиций/партнёров = частота + недавность (PR-1); последние партнёр/место подставляются по умолчанию.
- Контрацепция: счётчик использованных средств; недавно использованные — впереди.
- Данные локальны (IndexedDB) + экспорт/импорт CSV; PIN на входе; без облака.

## 6. Bounded contexts (черновой)
- **Журнал** — записи.
- **Каталог** — инвентарь (костюмы/игрушки/фантазии/контрацепция) и, в перспективе, секс-игры.
- **Соматика** — данные тела (импорт с устройств).
- **Аналитика** — производное над журналом и соматикой.
