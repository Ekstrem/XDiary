# LoopMaker — копии правил для ролей

Источник правды — приватный репозиторий `Ekstrem/LoopMaker`. Здесь лежат **копии**,
чтобы роли XDiary могли читать правила, которые раньше были им не видны (корневой
`AGENTS.md` ссылается на них, а файлов в чекауте не было).

Правила здесь **не правятся**: правки вносятся в LoopMaker, затем копия обновляется
`python tools/sync_tools.py --pull` или вручную. `Roles/LoopMaster/RULES.LoopMaster.md`
сюда **не копируется** — это приватный файл владельца и @LM.
