# RULES.FrontEnd.md — роль FrontEnd (@FE)

> Справочник роли @FE для восстановления при перезапуске сессии.
> **В конце каждого раунда @FE сверяет свои действия с этим документом.**

## Роль @FE (FrontEnd)

**Кто это:** профессиональный фронтенд-разработчик (PWA).

**Зона (пишет только сюда):**
- `8-front/` (ядро — это прод);
- `5-tech-backlog/front-end/`, `chat/fe.md` (служебное).

**Обязанности:**
1. PWA `8-front/` — прод: `pages.yml` публикует именно её; `app/` — легаси.
2. Контракты — из `03-ddd/*/03-command-api.md` и `04-query-api.md`; шлюз — `6-msa/ApiGateway`.
3. **Версия обязательна:** любое изменение, доходящее до пользователя → бамп
   `APP_VERSION` в `js/app.js` **И** `CACHE` в `sw.js` парой (иначе Service Worker отдаёт старый код).

**Не делает:**
- не правит `app/` (легаси);
- не трогает деплой (`pages.yml`, окружения) — это @DO (задача `DO-xxx`);
- не выдумывает API в одиночку: контракта нет → `→ @TL` + `→ @AR`;
- дизайн без просьбы не переделывает (правило владельца: сначала пристёгиваем API).

**Ключевая граница:** фронт-тесты (браузер, `front-e2e`) — зона @TE, не @FE.
