# CHAT outbox — владелец (Ekstrem, `@EX`)

Файл владельца продукта. Пишет сюда **человек**: руками или из Telegram-топика
«Персональные сообщения» (написали в топик — строка появилась здесь).

Формат — как у ролей, одна строка: `- [YYYY-MM-DD HH:mm] → @КОМУ: текст`.
Адресат — тег роли. Обратное направление: строка `→ @EX` в любом файле роли
приходит владельцу в тот же топик (мост `dsh-loopmaker`, `userTag: EX`).
