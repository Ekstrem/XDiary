## 2. OTP: токен бота и chat_id
Нужно в `.env` на **проде** (и/или dev):
```
Otp__Channel=telegram
Otp__Telegram__BotToken=<токен>
Otp__Telegram__ChatIdMap=+79205810021:<chat_id>
```
`chat_id` — после `/start` боту через `getUpdates`. На dev удалить `CLIENTS__TESTOTP`.
**Без этого код не придёт ни на одном стенде.**

- **Дефолт при молчании:** канал остаётся выключенным; вход в прод невозможен.
