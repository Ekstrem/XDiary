## Проблема
Сообщения чата ролей с **несколькими адресатами** (`→ @DO + @TE:`) **молча не доставляются** адресату и не попадают в авто-сводку `_dialogue.md`. Ошибки нет — строка просто пропускается парсером.

## Факты (замер 2026-11-03)
- Прогон `5-tech-backlog/chat/tl.md` через `LoopMaker/lib/parse.js`: **192 разобрано, 6 — НЕ разобрано**.
- Все 6 — с двумя адресатами:
  - `→ @DO + @TE:`
  - `→ @TE + @DO:`
  - `→ @TE + @BE + @FE:`
  - `→ @DO + @PO:`
- Причина: регекс адресата `@([^\s:@]+)` матчит **одного**; `+ @TE` ломает строку → `parseLine()` возвращает `undefined` → сообщение выпадает.
- Та же ошибка была в `tools/merge_chat.py` (`@([^\s:]+)`) — сводка `_dialogue.md` теряла те же строки.
- `tools/chat_inbox.py` использовал `(.+?)` — видел мультиадресатов, поэтому гейт «неотвеченных» не сигналил.

## Как проверить (регресс-тест)
```bash
cd LoopMaker && node --input-type=module -e "
import { readFileSync } from 'fs';
import { parseLine } from './lib/parse.js';
const lines = readFileSync('../XDiary/5-tech-backlog/chat/tl.md','utf8').split(/\r?\n/);
let ok=0, bad=[];
for (const l of lines) { if (!l.trim().startsWith('-')) continue; const p = parseLine(l); if (p) ok++; else bad.push(l.slice(0,120)); }
console.log('разобрано:', ok, 'НЕ разобрано:', bad.length);
bad.slice(0,10).forEach(b => console.log('X:', b));
"
```
Ожидаемо после фикса: `НЕ разобрано: 0`.

## Почему это важно
Молчаливая потеря сообщений = роль не получает задачу/вопрос, координатор не видит ответ — петля застревает без ошибки. Пример: 2026-11-03 шесть сообщений `@DO + @TE` не дошли, и это заметил PO, а не система.
