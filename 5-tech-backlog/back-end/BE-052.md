# BE-052: Профиль клиента (`displayName`, `gender`, `photo?`) + миграция «эго-партнёров» — ADR-024

- **Статус:** В паузе
- **Приоритет:** P1 (вход в продукт; после ретро)
- **Пауза:** ретро владельца (объявлена 2026-11-09) — работы не ведутся
- **Разблокирует:** решение владельца после ретро
- **Источник:** ADR-024 (AR 2026-11-09 05:26) + владелец: «на онбординге я должен добавлять партнёра вместо того, чтобы написать просто имя и пол» (AR-011), «я вижу себя в партнёрах» (AR-012)
- **Зависимости:** ADR-024, ADR-021 (`participant="me"`), BE-048 (скоуп партнёров), BE-049 (`POST /partners` ↔ `ClientId`)
- **Проверяет:** @TL (TechLead) — доменный ревьюер @AR по модели

## Задача (зона @BE, `6-msa/BC-Client`)
1. **Профиль в `Client`:** поля `displayName` (обязательное для онбординга), `gender` (обязательное; значения — по решению @PO), `photoUrl?` (опционально). Миграция EF с nullable-семантикой для существующих записей (у владельца уже есть клиент).
2. **Контракт:** `POST /api/v1/clients/{id}/profile` (или `PATCH /api/v1/clients/{id}`) — аддитивно в `/v1`; в ответе `me` добавить профиль.
3. **«Я» больше не партнёр по построению:** `GET /api/v1/partners` не должен возвращать запись с `ClientId == sub` (после миграции её там не будет).
4. **Миграция эго-партнёров:** для каждого клиента, у которого есть `Partner` с `ClientId == self` — перенести `name` → `displayName` (если профиль пуст), записать **бэкап таблицы** и список перенесённых `id`; саму запись «эго-партнёра» **не удалять** до подтверждения, но **исключить из выдачи**.
5. **Тесты:** «нет профиля → онбординг требует имя/пол», «профиль сохранён → `me` отдаёт его», «эго-партнёр не появляется в `/partners`», «миграция перенесла имя, история (`participant="me"`) не изменилась».

## Критерии приёмки
- [ ] Поля и контракт в `origin`, миграция применяется на dev и на проде (с бэкапом).
- [ ] `GET /partners` не содержит «я» (проверено фактом на проде).
- [ ] Тесты из п.5 зелёные в `ci-backend`.
- [ ] После онбординга «я» в списке партнёров отсутствует (проверка владельцем).
