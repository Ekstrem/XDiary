# BE-028: Домен «я» = партнёр + опциональный PIN (AR-004, ADR-021)

- **Статус:** На проверке
- **Приоритет:** P1 (Фаза 1: идентификация/аутентификация)
- **Источник:** AR-004 → P1 (@AR 2026-11-04 00:00); ADR-021 (Предложено)
- **Зависимости:** ADR-021 (принятие), AR-004

## Контекст
Фаза 1 — идентификация/аутентификация. Контракт: **ADR-021** — «я» = партнёр (признак `self` на Partner), онбординг + **опциональный** PIN. Домен уточняется после принятия ADR-021.

## Задача
- Признак `self` на `Partner` (кто из пары — «я»), миграция + read-model.
- Эндпоинт/команда «сделать партнёра собой» (+ снятие).
- Аутентификация: PIN остаётся **опциональным** (BE-019/020 уже дают device-токен без PIN).
- Согласовать с @AR (ADR-021).

## Критерии приёмки
- [x] `Partner` имеет `self`-признак, API отдаёт «я».
- [x] PIN опционален (без PIN — device-токен, с PIN — PIN).
- [ ] E2E/CI зелёные.
