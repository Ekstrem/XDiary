# BE-002: Переделать `journal` (Журнал, агрегат Record) — с нуля

- **Статус:** Закрыта (TechLead: классический CEQRS, CI green, соответствует исправленному канвасу)
- **Приоритет:** P0
- **Источник:** BC-Journal (`03-ddd/BC-Journal/*`), US-01..09, ADR-001
- **Зависимости:** BE-001

## ⚠️ Переделка
Архитектор допустил ошибку — микросервис `journal` сделан неверно. Требовалась **полная переделка с нуля**. Канвас исправлен архитектором, старый код удалён.

## Задача
Реализовать Core-микросервис `journal` по исправленному канвасу `03-ddd/BC-Journal/02-aggregate-canvas.md`:
- **Сущность Record = признаки «кто + во сколько»:** `partners[]` (uuid[], 0..N, 0 = соло) + `startedAt` («YYYY-MM-DDTHH:mm»).
- **Идентификатор (DF) — технический, НЕ в сущности:** составной `<guid, long>` (guid — агрегат, long — версия), только для быстрого поиска.
- **Команды — именованные методы по экранам визарда:** `StartManualEntry`, `StartFromGarmin`, `SpecifyWhen`, `AddPartner`, `RemovePartner`, `SpecifyPlace`, `AddPositions`, `AddAccessories`, `RecordContraception`, `SpecifyDuration`, `RecordOrgasms`, `Complete`, `Delete`.
- **Оргазмы по участникам:** `orgasms[]` = { participant («me» | partnerId), count, types[], rating (0–5) }.
- **События — от каждого метода** (`ManualEntryStarted`, `WhenSpecified`, `PartnerAdded`, `PartnerRemoved`, …, `RecordCompleted`, `RecordDeleted`).

## Критерии приёмки
- [x] Сущность Record без технического id (идентичность = partners[] + startedAt; DF = `<guid, long>`).
- [x] Команды и события соответствуют канвасу (13 именованных, по экранам визарда).
- [x] Терминология «партнёр» (не «клиент»).
- [x] Интеграционный тест: Command → Query → Assert.

## Результат
Микросервис `journal` переделан с нуля в `6-msa/BC-Journal/` (edm-net, DigiTFactory.Libraries + AbstractAggregate, CEQRS, профиль Single).
- Сущность Record: `partners[]` (0..N, 0 = соло) + `startedAt`; оргазмы `orgasms[]` по участникам.
- 13 команд визарда (StartManualEntry → Complete, с AddPartner/RemovePartner), по событию на команду.
- Complete: соло допустимо (PartnersCardinality 0..N), обязателен только startedAt.
- Query читает Read Store (`records`, startedAt DESC), не трогает Event Store.
- Доменные тесты (8) + интеграционный тест Command → Query → Assert (in-process, ProjectionHandler + fake read store).
- CI: `.github/workflows/ci-journal.yml` — build + unit + integration tests + Docker в GHCR `ghcr.io/ekstrem/xdiary-journal` (`single`, `latest`).
