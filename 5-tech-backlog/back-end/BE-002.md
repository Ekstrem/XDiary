# BE-002: Реализовать `journal` (Журнал, агрегат Record)

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** BC-Journal (`03-ddd/BC-Journal/*`), US-01..09, ADR-001
- **Зависимости:** BE-001

## Задача
Реализовать Core-микросервис `journal` по канвасам `03-ddd/BC-Journal/`:
- Агрегат **Record** (startedAt, durationMin, partner, place, positions, tags, costumes, toys, fantasies, contraceptives, contraceptiveCount, orgasms*, garminId).
- Command API: создание/редактирование/удаление записи (визард → команды).
- Query API: журнал, деталь записи (срез соматики через `somatic-series`).
- MV: `records` (по `id`, индекс `startedAt`).

## Критерии приёмки
- [ ] Команды соответствуют `03-ddd/BC-Journal/03-command-api.md`.
- [ ] Запросы соответствуют `04-query-api.md`; Query не трогает Event Store.
- [ ] Оргазмы: мультивыбор типа + оценка 1–5 (пол `male`/`female`).
- [ ] Интеграционный тест: Command → Query → Assert.
