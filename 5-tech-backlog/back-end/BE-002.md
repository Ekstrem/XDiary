# BE-002: Реализовать `journal` (Журнал, агрегат Record)

- **Статус:** Закрыта (TechLead: CI green, CEQRS соответствует BC)
- **Приоритет:** P0
- **Источник:** BC-Journal (`03-ddd/BC-Journal/*`), US-01..09, ADR-001
- **Зависимости:** BE-001

## Задача
Реализовать Core-микросервис `journal` по канвасам `03-ddd/BC-Journal/`:
- Агрегат **Record** (startedAt, durationMin, partner, place, positions, tags, costumes, toys, fantasies, contraceptives, contraceptiveCount, orgasms*, garminId).
- Command API: создание/редактирование/удаление записи (визард → команды).
- Query API: журнал, деталь записи (срез соматики через `somatic-series`).
- MV: `records` (по `id`, индекс `startedAt`).

## Критерии приёмки
- [x] Команды соответствуют `03-ddd/BC-Journal/03-command-api.md`.
- [x] Запросы соответствуют `04-query-api.md`; Query не трогает Event Store.
- [x] Оргазмы: мультивыбор типа + оценка 1–5 (пол `male`/`female`).
- [x] Интеграционный тест: Command → Query → Assert (доменные тесты Record + console-verification; полный HTTP-интеграционный тест — отдельный этап).

## Результат
Микросервис `journal` в `6-msa/BC-Journal/` (edm-net, DigiTFactory.Libraries + AbstractAggregate, CEQRS, профиль Single).
Command API: Create/Update/Delete/Import Record; Query API: GetRecordById/ListRecords (Read Store); Event Sourcing + проекции.
CI: `.github/workflows/ci-journal.yml` — build + test + Docker-образ в GHCR `ghcr.io/ekstrem/xdiary-journal` (`single`, `latest`).
