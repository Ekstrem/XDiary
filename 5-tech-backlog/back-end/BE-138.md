## Задача

На dev: `POST /api/v1/catalog` → 200, но `GET /api/v1/catalog` → 200 `[]`, `GET /api/v1/catalog/<id>` → 404.
Класс — тот же, что `BE-134` (Client: запись есть, проекции нет), но в `BC-Catalog`.

## Корень (установлен по коду + дампу @DO)

Catalog на `main` — **event-sourced** (не классический CEQRS, как было до `737e2bdc2`):

- `Catalog.DomainServices`: `BusAdapter` + `Notifier` + `AggregateProvider` (публикация в in-memory шину);
- `Catalog.Storage`: `CatalogEventSourcingRepository` + `CatalogEventReplay` + `EventStoreDbContext` (схема `Commands`);
- `Catalog.Api/Program.cs`: `AddEventStorePostgres` + `AddEventBusInMemory` + `AddReadStorePostgres<…, ReadDbContext>`.

**Чего не хватало: консьюмера событий и хендлера проекции.** В `Catalog.Api` не было папки `Events/`
(только `Program.cs`, `CatalogController.cs`, `HealthChecks/`, `HttpActorProvider.cs`), поэтому события
писались в `Commands."DomainEvents"`, но `public.catalog_read` **никогда не заполнялась** — отсюда 404/[].
Дамп @DO это подтвердил: `DomainEvents` есть (9 событий), `catalog_read` — 0 строк.

Схема БД при этом корректная: одна база `catalog`, но объекты разделены по схемам —
`Commands."AggregateStates"/"DomainEvents"/"Snapshots"` (события) и `public.catalog_read` (матпредставление).

## Что сделано

1. **`6-msa/BC-Catalog/src/Catalog.Api/Events/CatalogEventConsumer.cs`** (новый): `CatalogEventConsumer`
   (`BackgroundService`, подписка на `IEventBusConsumer`) + `CatalogEventHandler`
   (`IDomainEventHandler<ICatalog>`, `IObserver<IDomainEvent<ICatalog>>`) + `CatalogProjection.ApplyVos`
   (per-field: `Root`→Kind/Name, `ClientId`, `Photo`, `Notes`, `Brand`, `Archived`, `FantasyPartner`).
   Хендлер держит только `IServiceScopeFactory` (класс BE-134: hosted service из root-scope не резолвит scoped-зависимости).
2. **`Catalog.Api/Program.cs`**: `AddHostedService<CatalogEventConsumer>()` + `AddSingleton<CatalogEventHandler>()`.
3. **`CatalogReadModel`**: добавлен `Version` (нужен для stale-skip QG-305).
4. **Миграция `AddVersionToCatalogRead`**: `AddColumn Version` + недостающий `IX_catalog_read_ClientId`
   (таблица создаётся `AddReadStores`, поэтому только дельта — таблица не пересоздаётся).
5. Stale-skip с `LegacyTimestampFloor` (класс BE-137): `existing.Version >= domainEvent.Version && existing.Version < 1e12`.
