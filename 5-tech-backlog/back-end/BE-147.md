## Корень

`Catalog.Domain/Implementation/Aggregate.cs`: `Remove() => Success(Clone())` — no-op, модель не меняется.
`CatalogEventHandler` только `UpsertAsync`, поэтому `catalog_read` сохраняет запись с `Archived=false`.

## Задача

1. Добавить `DeletedAt` в доменную модель и read-модель; `Remove()` выставляет его идемпотентно.
2. Проекция при `DeletedAt` удаляет строку через `IReadModelStore.DeleteAsync`.
3. `ListCatalogItemsQuery` и `GetCatalogItemByIdQuery` фильтруют `DeletedAt is null`.
4. Миграция `AddDeletedAtToCatalogRead` + регрессионные тесты.

## Критерии приёмки

- [ ] После Remove событие содержит `DeletedAt`; повторный Remove не меняет дату;
- [ ] Проекция удаляет строку из `catalog_read`;
- [ ] GET по id и список не возвращают удалённую позицию;
- [ ] Сборка Catalog и IntegrationTests зелёные; PR открыт.
