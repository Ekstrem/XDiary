## Проблема
`Aggregate.SetPin` в `BC-Privacy` теперь `SetPin(Guid clientId, string salt, string hash, int iterations)` (4 параметра, BE-036). В тестовом проекте BC-Privacy остался вызов старой формы:

```
6-msa/BC-Privacy/src/Privacy.IntegrationTests/PrivacyIntegrationTest.cs:14
    var (salt, hash, iter) = PinHasher.Hash("1234");
    var set = Aggregate.CreateInstance(new AnemicModel()).SetPin(salt, hash, iter);   // 3 аргумента
```

`9-tests` уже исправлен (@TE, TE-033: `PrivacyTests.cs` L37/L48 передают `clientId`), но проект `Privacy.IntegrationTests` входит в сборку, поэтому `test` останется красным.

## Задача
Привести вызов к новой сигнатуре: передавать `clientId` (для теста — `Guid.NewGuid()`), `iterations` — значение из `PinHasher` (`iter`), т.е. `SetPin(clientId, salt, hash, iter)`. Проверить, нет ли других вызовов `SetPin` со старой арностью в `6-msa` (поиск по `SetPin(`).
