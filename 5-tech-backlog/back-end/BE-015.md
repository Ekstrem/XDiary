# BE-015: portability — идемпотентный импорт (дедуп по `id`)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** TE-006 (gap), `chat/te.md` 21:30
- **Зависимости:** —

## Проблема
`BC-Portability.ImportRecords` не дедуплицирует по `id` — повторный импорт того же CSV создаёт дубли. Критерий TE-006 «идемпотентность по `id`» не выполняется.

## Задача
Сделать импорт идемпотентным: при импорте строки с уже существующим `id` — обновлять существующую запись (upsert), а не создавать новую.

## Критерии приёмки
- [ ] Повторный импорт того же CSV не создаёт дублей.
- [ ] Существующая запись обновляется (upsert) — зафиксировать поведение.
- [ ] CI green, образ в GHCR обновлён.
