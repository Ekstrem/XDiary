## Проблема
`BC-Portability.ImportRecords` не дедуплицирует по `id` — повторный импорт того же CSV создаёт дубли. Критерий TE-006 «идемпотентность по `id`» не выполняется.

## Задача
Сделать импорт идемпотентным: при импорте строки с уже существующим `id` — обновлять существующую запись (upsert), а не создавать новую.

## Критерии приёмки
- [x] Повторный импорт того же CSV не создаёт дублей.
- [x] Существующая запись обновляется (upsert) — зафиксировать поведение.
- [x] CI green, образ в GHCR обновлён.
