## Задача

1. В Journal реализовать `IAggregateProviderWithCompletion<IJournal, IRecordAggregate>`:
   провайдер возвращает `(aggregate, completion)`; scoped TCS общий для provider и BusAdapter одной команды.
2. `BusAdapter.OnNext` завершает TCS на `PublishAsync`: `TrySetResult` / `TrySetException`; при неуспешном
   бизнес-результате тоже завершает, чтобы команда не зависла. MV и Event Store остаются асинхронными подписчиками.
3. Обработчики команд: `var (aggregate, completion) = await provider.GetAggregateWithCompletionAsync(...)`;
   синхронный бизнес-метод; `await completion`; вернуть результат.
4. Тесты: completion ждёт публикацию, ошибка публикации пробрасывается, неуспешный результат не блокирует команду.
5. После ревью Journal раскатать тот же паттерн на остальные 9 BC.

## Критерии приёмки

- [ ] SeedWorks 0.7.0 подключён;
- [ ] Journal provider реализует новый интерфейс и scoped completion;
- [ ] `BusAdapter` только `PublishAsync`, без `SaveEventAsync` и `.GetAwaiter().GetResult()`;
- [ ] команды ожидают `completion`;
- [ ] тесты подтверждают ожидание publish и проброс ошибки;
- [ ] Journal затем остальные 9 BC собираются с 0 ошибок; PR открыт.

## Результат

Реализовано в PR #3252 для Journal и остальных 9 BC:

- SeedWorks обновлён до 0.7.0; `AggregateProvider` реализует `IAggregateProviderWithCompletion`, сохраняя старый `IAggregateProvider`.
- Добавлен scoped `AggregateCompletion`: один TCS на команду, общий для provider и BusAdapter через `InstancePerLifetimeScope`.
- `BusAdapter` только публикует: завершение completion на `PublishAsync` — `TrySetResult(null)` / `TrySetException`; неуспешный бизнес-результат тоже завершается без публикации.
- Все обработчики получают `(aggregate, completion)`, вызывают синхронный бизнес-метод и делают `await completion`. Старый constructor-injection сохранён (QG-210).
- MV и Event Store остаются асинхронными подписчиками: completion именно на durable-publish, а не на применении проекций.
- Тесты Journal: ожидание незавершённой публикации, проброс ошибки публикации, завершение без publish при неуспешном результате.
- `Analyzers.DomainServices` обновлён до 0.6.0, suppression QG-104 не требуется.
- Проверка: Release-сборка `*.IntegrationTests` всех 10 BC — **0 ошибок**.
