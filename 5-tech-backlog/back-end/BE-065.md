# BE-065: `ClientId` не сохраняется в агрегате журнала (P0 — владелец видит пустой журнал и 403 на свою запись)

- **Статус:** В работе
- **В работе с:** 2026-11-10
- **Приоритет:** **P0** (это функциональный регресс BE-053: утечку закрыли, но данные у владельца «исчезли»)
- **Источник:** @TE 2026-11-10 16:13 (прогон `Point3b` на dev `d2326de0`): `POST /journal/records` → 200, в теле `clientId: null`; `GET /journal/records` с токеном A → 200, **0 записей**; чтение своей записи → **403**; `recent` → 204. Подтверждено по коду @TL.
- **Зависимости:** BE-053 (внесла `clientId` в сигнатуры, но не в инициализатор)
- **Проверяет:** @TL (код) + @TE (`Point3b` на dev)

## Причина (одна строка в двух местах)

`6-msa/BC-Journal/src/Journal.Domain/Implementation/Aggregate.cs`:
- `StartManualEntry(Guid clientId)` — принимает `clientId`, но в `new AnemicModel { … }` **не проставляет `ClientId`** (в инициализаторе только `Root/Garmin/CreatedAt/UpdatedAt`);
- `StartFromGarmin(…, Guid clientId)` — то же самое.

Следствие: в БД `journal.records.ClientId = NULL` → `JournalReadRepository` фильтрует `x.ClientId == clientId` → пусто; `EnsureOwns` сравнивает `null != clientId` → **403** на собственную запись.

## Почему тесты не поймали

`9-tests/Journal/Journal.IntegrationTests/JournalReadRepositoryTests.cs` создаёт `RecordEntity` **напрямую с `ClientId`**, минуя команду → проверяет фильтр, но не путь «команда → агрегат → запись». Это дефект тест-дизайна, а не случайность.

## Задача

1. `ClientId = clientId` в **обоих** инициализаторах (`StartManualEntry`, `StartFromGarmin`).
2. **Тест через реальный путь:** `StartManualEntry(clientId)` → проверять `model.ClientId == clientId` **в агрегате** (unit) + интеграционный «создал → вижу свою; чужая → 403» (через API, как делает @TE).
3. Проверить, что `journal/recent` тоже возвращает запись (сейчас 204).

## Критерии приёмки

- [ ] `POST /journal/records` → в ответе `clientId` = владелец (не null).
- [ ] `GET /journal/records` с токеном A → **своя запись видна**; B её не видит.
- [ ] Чтение своей записи по id → **200**; чужой → **403/404**.
- [ ] Unit-тест агрегата: `model.ClientId == clientId` после `StartManualEntry`/`StartFromGarmin`.
- [ ] На dev: `Point3b` @TE зелёный **без правки теста**.
