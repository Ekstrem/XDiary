## Задача

В `6-msa/BC-Analytics/src/Analytics.Api/Precompute/JournalRecord.cs` поля объявлены как `public string Date { get; set; } = string.Empty;` (`:24`) и `public string T { get; set; } = string.Empty;` (`:28`). При `<Nullable>enable</Nullable>` (`Analytics.Api.csproj`) `[ApiController]` добавляет неявный `[Required]`, поэтому отсутствие поля в теле даёт `400` — хотя канон `Analytics.Events` держит `date`/`t` в `request.optional` (тело — событие с дискриминатором, обязателен только `eventType`).

Нужно выбрать **одну** сторону и сделать её правдой:
1. **код:** `string?` для `Date`/`T` (если они действительно необязательны в своей ветке) — тогда канон верен;
2. **канон:** объявить их обязательными для соответствующих веток (`SleepRecorded`/`SomaticPointRecorded`) — тогда верен канон, а не «optional для всех».
