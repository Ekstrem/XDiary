## Состав (уровни)

**L1 — unit, на каждый BC (`{BC}ProjectionTests`)**
1. `Project_UsesEveryKeyOfGetValueObjects` — ключи `AnemicModel.GetValueObjects()` ⊆ обрабатываемых проекцией.
2. `Project_Sets_AllFields` — полный `ChangedValueObjects` → все поля read-модели.
3. `ApplyVos_PerField_DoesNotWipeUnchanged` — отсутствующий ключ не обнуляет поле.
4. `ApplyVos_EmptyDiff_NoOp`.

**L2 — unit, на каждый BC (`{BC}StaleSkipTests`)** — класс BE-137
5. `AppliesSmallVersion_AfterLegacyMsVersion` — `existing=1.79e12`, `event=2` → применяется.
6. `SkipsOlderSmallVersion` — `existing=5`, `event=3` → skip.
7. `AppliesFirstEvent` — `existing=0`, `event=ms` → применяется.

**L3 — integration на реальном Postgres (`{BC}EventBusProjectionTests`)**
8. `Bus_Publish_Projects_RealReadModel` — `AddEventBusInMemory` + реальный `IReadModelStore` (`XDIARY_TEST_POSTGRES`) +
   хендлер + консьюмер → `PublishAsync` → `SELECT` из `<bc>_read` → строка есть. Ловит «нет консьюмера» (BE-134/138).
9. `Consumer_Registered_InCompositionRoot` — `IEventBusConsumer` + `{BC}EventHandler` резолвятся из DI.

**L4 — integration на реальном Postgres (`{BC}ReadModelEndToEndTests`)**
10. `Command_Then_Read_FromDb` — команда через MediatR (с `IActorProvider` → известный `ClientId`) → чтение через
    `IReadRepository` → строка есть, `ClientId` совпадает.
11. `GetById_Owner_Returns200_Other_Returns404`.

**L5 — архитектурный гейт (`tools/check_read_projection.py`, согласовать с @DO)**
12. Для каждого BC с `AddReadStorePostgres<…>` в `Program.cs`: обязательны `AddHostedService<*EventConsumer>` +
    `AddSingleton<*EventHandler>` и класс в `Api/Events/`.
13. Для каждой `*ReadModel` — есть `*Projection`, покрывающий `GetValueObjects()`.

**L6 — level 4 (@DO/@TE, `smoke-api`)** — вне сдачи роли
