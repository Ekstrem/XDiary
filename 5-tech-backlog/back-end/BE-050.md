## Задача (зона @BE, `6-msa/`)
1. **Реестр генерируется, а не пишется руками.** Для каждого сервиса — артефакт `openapi/<service>.json`, полученный из **работающего кода** (`dotnet swagger tofile` / `Microsoft.Extensions.ApiDescription.Server`), плюс агрегирующий индекс `openapi/index.json` (сервис → файл → версия маршрутов).
2. **Версия генератора фиксируется** (пакет + версия в `Directory.Packages.props`), иначе diff шумит от смены генератора.
3. **Политика версий:** ломающее изменение → новый маршрут `/v2`; аддитивные правки остаются в `/v1`; `deprecated` помечается в спеке.
4. Артефакты **коммитятся** (реестр живёт в репозитории, доступен фронту и @DO без запуска сервисов).

## Критерии приёмки
- [ ] `openapi/*.json` для всех 12 сервисов генерируются воспроизводимо (повторный прогон даёт тот же файл).
- [ ] Версия генератора зафиксирована; в задаче указана.
- [ ] Есть агрегирующий индекс, связывающий маршруты `/v1` с сервисами.
- [ ] Ни один файл реестра не правится руками (проверяемо по CI-перегенерации).

## Решение @TL 2026-11-10 03:00 (форма изменена по факту @DO 22:40)

Факт: /swagger/v1/swagger.json отдают **2 из 12** сервисов (client, nalytics); 9 → 404; pi-gateway → 401. Снимать «с живых сервисов на dev» невозможно.

**Новая форма:**
1. **@BE:** общий extension AddXdiarySwagger + подключение во **всех 12** сервисах под флагом Swagger__Enabled (off в проде, on в dev/CI).
2. **@BE:** генерация openapi/<service>.json через dotnet swagger tofile в CI; имена = имена контейнеров; openapi/index.json.
3. **@DO:** workflow-генератор (.github), коммит только при изменении ([skip ci]); **гейт дрейфа** (git ≠ сгенерированному → красный); breaking-change детектор между коммитами.
4. **Порядок:** 1 → 3, гейт по §5.4 (два прогона: дефект + норма).

## Уточнение @AR 2026-11-05 18:00/18:12 (канон vs инструмент)

- **Канон контракта** — `api-index.yaml` + спеки (ADR-023 ред. 2026-11-05, ADR-025 contract-first);
  **swagger — инструмент сверки, не источник.** Дрейф ловится в три стороны: APIM↔спеки, спеки↔swagger, живой трафик.
- **Шаг (0) упрощён:** `Swagger:Enabled`-флаг уже есть в общем `UseXdiarySwagger` (XDiary.Contracts/SwaggerExtensions.cs),
  все 12 сервисов через него — править код на 12 сервисах **не надо**.
- **Порядок (не снимать реестр дважды):** (1) `Swagger__Enabled=true` на dev (@DO, конфиг); (2) проверка периметра —
  снаружи `/swagger*` не 200, изнутри 200+JSON (@TE, гейт rc=1 при утечке); (3) только потом ре-снятие `api-index.yaml`/спек
  из фактического swagger + сверка в три стороны (@BE).
- **Правило:** «спеку не получили → rc=2 "не измерено"», а не «нарушений 0».
