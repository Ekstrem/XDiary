# BE-008: Реализовать `apple-health-gateway` (Шлюз Apple Health, AppleImport)

- **Статус:** Открыта
- **Приоритет:** P2
- **Источник:** BC-AppleHealthGateway (`03-ddd/BC-AppleHealthGateway/*`), AW-01, ADR-012
- **Зависимости:** BE-001

## Задача
Реализовать шлюз-ACL к Apple Health:
- Агрегат **AppleImport** (sourceId, importConfig, lastImport, processedFiles).
- Импорт ручного экспорта `export.xml`/CSV (пульс, HRV, сон, пульс покоя).
- Отдаёт нормализованную **соматику** → `somatic-series`/`daily-metrics`.

## Критерии приёмки
- [ ] Парсинг `export.xml`/CSV из «Здоровья».
- [ ] Идемпотентность по файлу (не импортировать дважды).
- [ ] Нет Body Battery/стресса (специфика Garmin).
- [ ] Интеграционный тест.
