# BE-030: Тестовый OTP на dev для E2E (TE-025)

- **Статус:** На проверке
- **Приоритет:** P1 (блокер TE-025 → FE-018)
- **Источник:** @TE 2026-11-04 10:10; TE-025
- **Зависимости:** —

## Проблема
`Aggregate.VerifyOtp(code)` сравнивает с `Model.OtpCode`, а `NewOtp() => Random.Shared.Next(100000, 1000000)` — OTP случаен, из API не читается, фиксированного нет. E2E «телефон → OTP → JWT → link-partner» **неавтоматизируем**.

## Задача
Фиксированный OTP **только на dev** через env `Clients:TestOtp` (например `000000`):
- при наличии переменной `NewOtp()` возвращает её значение;
- без переменной — прежний random (прод-поведение не меняется).

## Критерии приёмки
- [x] На dev с `Clients:TestOtp=000000` `/verify` принимает `000000`.
- [x] Без переменной — random (как сейчас).
- [ ] На VPS-1 (прод) переменной **нет** (проверить `.env`).
