# BE-086: тесты Partners не КОМПИЛИРУЮТСЯ — из-за этого образ Partners не публикуется

- **Статус:** На проверке
- **В работе с:** 2026-11-06
- **Приоритет:** **P0** (блокирует публикацию образа `ekstrem/xdiary-partners` ⇒ правки `BE-080`/`BE-085` не доедут до прода)
- **Источник:** аннотация CI (`ci-partners`, run на sha `629ca2ff`), прочитана @TL `2026-11-06 00:5x`
- **Проверяет:** @TL

## Точная ошибка (текст из аннотации, без пересказа)

```
6-msa/BC-Partners/src/Partners.IntegrationTests/PartnerEventHandlerTests.cs(18,38): error CS0738:
'PartnerEventHandlerTests.FakeStore' does not implement interface member
'IEventStoreRepository<IPartners, IPartnerAnemicModel>.GetEventCountAsync(Guid, CancellationToken)'.
'PartnerEventHandlerTests.FakeStore.GetEventCountAsync(Guid, CancellationToken)' cannot implement it
because it does not have the matching return type of 'Task<int>'.
```

## Причина

`PartnerEventHandlerTests.cs:23`:

```csharp
public Task<long> GetEventCountAsync(Guid id, CancellationToken ct = default) => Task.FromResult(0L);
```

Интерфейс `IEventStoreRepository<…>.GetEventCountAsync` объявлен как **`Task<int>`**, а фейк возвращает **`Task<long>`**.
Это ровно тот случай, когда «тест написан, но не собирается»: сам пакет тестов падает на компиляции, и никакие падения
тестов даже не запускаются.

## Почему это P0 для продукта, а не «красный тест»

`ci-partners.yml` устроен так: `build-and-test` (build → тесты) → **`docker` (публикация образа)**.
Когда падает шаг тестов, job `docker` — **`skipped`** (это видно в том же прогоне). Значит:

```
тесты Partners красные  →  docker job skipped  →  образа ekstrem/xdiary-partners нет
                        →  deploy.sh тянет старый тег  →  BE-080/BE-085 не в проде
```

**То есть это одна из причин, почему «бэкенд-правки не доехали», независимо от `deploy.yml`.**

## Исправление (одна строка)

```csharp
public Task<int> GetEventCountAsync(Guid id, CancellationToken ct = default) => Task.FromResult(0);
```

Других мест с `Task<long> GetEventCountAsync` в репозитории нет (проверено `git grep` по `6-msa`).

- `ci-partners` → шаг «Тесты Partners» **зелёный**, job `docker` — **выполняется** (не `skipped`);
- образ публикуется (в `### Вердикт @TL 2026-11-11 12:00 — **принято по артефакту; нужен номер прогона с запущенными тестами**

Номера такого прогона в результате **нет**, а `dotnet` в моей среде недоступен ⇒ по правилу «прогон без шагов — не прогон» это **не доказано**.
