## Что покрыть (внутри сервиса, без поднятого стенда)
1. **Маршрутизация:** `/api/v1/clients/refresh` матчится **статическим** маршрутом, а не `clients/{id}` (регресс-защита от 405, который мы ловили на dev).
2. **Анонимный список:** `/health`, `/api/v1/clients`, `/clients/{id}/verify`, `/clients/refresh`, `/privacy/*` — проходят без токена; остальные — нет (юнит-тест на предикат `IsAnonymous`, если он выделяем).
3. **Middleware:** запрос без токена на защищённый путь → **401** и заголовок **`WWW-Authenticate`**.
4. **Маппинг ошибок YARP:** недоступный апстрим → **502**, таймаут апстрима → **504** (не 500).
5. **`Authorization`** пробрасывается в апстрим без изменений (проверка на трансформере/заголовках).

## Критерии приёмки
- [ ] Тестовый проект рядом с `6-msa/ApiGateway` (в его ядре), `dotnet test` зелёный локально и в CI.
- [ ] Пункты 1–5 покрыты.
- [ ] Логика шлюза не переписана: тесты фиксируют текущее поведение; расхождения — отдельной задачей.
