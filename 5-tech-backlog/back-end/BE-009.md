# BE-009: Реализовать `analytics` (Аналитика, read-only)

- **Статус:** Открыта
- **Приоритет:** P2
- **Источник:** BC-Analytics (`03-ddd/BC-Analytics/*`), ST-01..ST-08
- **Зависимости:** BE-002, BE-005, BE-006

## Задача
Реализовать read-only микросервис `analytics` (нет агрегата записи, только проекции):
- Сводка за период (30/90/всё время).
- Физиопрофиль, топы, распределение, пороги, корреляции (Пирсон).
- Читает записи из `journal` и тренды из `daily-metrics` (query-API).

## Критерии приёмки
- [ ] Только чтение: не обращается к Domain/Event Store напрямую.
- [ ] Корреляции с пояснением + n наблюдений (n ≥ 3).
- [ ] Переключатель периода 30/90/всё время.
- [ ] Интеграционный тест.
