# BE-003: Реализовать `partners` (Партнёры, агрегат Partner)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** BC-Partners (`03-ddd/BC-Partners/*`)
- **Зависимости:** BE-001

## Задача
Реализовать микросервис `partners`:
- Агрегат **Partner** (name, photo, gender, notes).
- Command API: создать/редактировать/удалить партнёра.
- Query API: список партнёров, деталь.

## Критерии приёмки
- [ ] Команды/запросы соответствуют канвасам `BC-Partners`.
- [ ] Пол (`gender`) определяет допустимые типы оргазмов (используется в `journal`).
- [ ] Интеграционный тест Command → Query → Assert.
