# BE-003: Реализовать `partners` (Партнёры, агрегат Partner)

- **Статус:** Закрыта (TechLead: CI green, CEQRS соответствует BC)
- **Приоритет:** P1
- **Источник:** BC-Partners (`03-ddd/BC-Partners/*`)
- **Зависимости:** BE-001

## Задача
Реализовать микросервис `partners`:
- Агрегат **Partner** (name, photo, gender, notes).
- Command API: создать/редактировать/удалить партнёра.
- Query API: список партнёров, деталь.

## Критерии приёмки
- [x] Команды/запросы соответствуют канвасам `BC-Partners`.
- [x] Пол (`gender`) определяется как `male`/`female` (валидация в handler'е; используется в `journal`).
- [x] Интеграционный тест Command → Query → Assert (доменные тесты Partner + console-verification; полный HTTP-интеграционный тест — отдельный этап).

## Результат
Микросервис `partners` в `6-msa/BC-Partners/` (edm-net, DigiTFactory.Libraries + AbstractAggregate, CEQRS, профиль Single).
Command API: Create/Update/Delete Partner; Query API: GetPartnerById/ListPartners (Read Store); Event Sourcing + проекции.
CI: `.github/workflows/ci-partners.yml` — build + test + Docker-образ в GHCR `ghcr.io/ekstrem/xdiary-partners` (`single`, `latest`).
