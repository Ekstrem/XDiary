## Проблема

## Задача
- MV `summary`/`tops`/`distribution`/`trends`/`correlations` — инкрементально от событий (Journal/Somatic).
- Query API читает готовое; клиент не считает агрегаты.
- Контракт уже обновлён @AR (`BC-Analytics/05-materialized-views.md`).

## Критерии приёмки
- [x] MV обновляются от событий (Фаза 1: Journal RecordCompleted/RecordDeleted).

- [ ] Клиент не считает агрегаты (FE-012/013 перепроверить: тренды/корреляции — только рендер).
- [ ] CI зелёный.
