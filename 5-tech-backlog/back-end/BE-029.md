# BE-029: BC «Клиент» (11-й) — регистрация по телефону + SMS OTP + связь с Partner

- **Статус:** Закрыта
- **Приоритет:** P1 (Фаза 1: идентификация/аутентификация)
- **Источник:** ADR-021 пересмотрен (@AR 2026-11-04 04:00); `03-ddd/BC-Client/`
- **Зависимости:** AR-004, ADR-021

## Контекст
Система **многопользовательская**. Идентификация — по **номеру телефона** (SMS OTP) + опциональный PIN (PIN остаётся в BC-Privacy, ADR-008). Отдельный BC «Client» (11-й микросервис). «Я» = `Partner` с `clientId == текущий Client` — **не** boolean `self`.

## Задача
- Новый микросервис **`BC-Client`**: агрегат `Client` (phone, OTP, linkedPartnerId).
- События: `ClientRegistered` / `PhoneVerified` / `PartnerLinked` / `PartnerUnlinked`.
- API: `POST /clients`, `POST /clients/verify`, `POST /clients/link-partner`, `GET /clients/me`.
- В BC-Partners: `Partner.clientId` (вместо `self` boolean) + миграция/read-model.
- JWT = клиент (номер), не устройство.

## Критерии приёмки
- [x] `BC-Client` в составе MSA (11 сервисов) + миграции.
- [x] `POST /clients` → OTP → `/verify` → JWT клиента.
- [x] `/link-partner` + `Partner.clientId`; `GET /clients/me` отдаёт «я».
- [ ] CI зелёный.

## Результат
BC-Client (11-й сервис): агрегат Client (phone/OTP/linkedPartnerId) + Register/VerifyOtp/LinkPartner/UnlinkPartner + API (7 эндпоинтов) + client-JWT на /verify (HS256, sub=clientId, phone) + миграция InitialCreate. JWT-ключи выровнены (ApiGateway = Privacy). Коммиты 70ee10f, 964cc91.
