# BE-010: Реализовать `privacy` (Приватность, PinCredential + JWT)

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** BC-Privacy (`03-ddd/BC-Privacy/*`), US-11, ADR-008
- **Зависимости:** BE-001

## Задача
Реализовать микросервис `privacy`:
- Агрегат **PinCredential** (PBKDF2-SHA256: salt + hash).
- Выпуск/проверка **JWT** (2 пользователя, один issuer).
- Локальный PIN остаётся на устройстве (доп. слой).

## Критерии приёмки
- [ ] PBKDF2-SHA256 хранение PIN (не открытым текстом).
- [ ] Краткоживущий access + refresh токен.
- [ ] Шлюз проверяет JWT (stateless).
- [ ] Интеграционный тест.
