# BE-069 — `partners`: `GetAllAsync(null!, ct)` → `NullReferenceException` на `GET /partners`

- **Статус:** На проверке
- **В работе с:** 2026-11-05
- **Приоритет:** P1 (валит контракт `4/4` и все 23 E2E-спека: `seedSession` умирает на первом шаге)
- **Источник:** @DO `07:31` — прогоны вне песочницы: контракт `test-partner-softdelete` #4 → `4 failed` (`InternalServerError`), E2E → `23 failed` на `seedSession`; лог `xdiary-partners` на dev (образ `68644da1`) → `System.NullReferenceException`
- **Зависимости:** нет (тот же класс, что `BE-067`, но в другом BC)
- **Проверяет:** @TL (код сервиса)

## Задача

`6-msa/BC-Partners/src/Partners.Storage/PartnerReadRepository.cs:16`:

```csharp
var all = await _read.GetAllAsync(null!, ct);
```

`null!` уходит как `IPaging`; библиотечный `PostgresReadRepository.GetAllAsync` сразу читает
`paging.Page` → `NullReferenceException`. Это **тот же дефект**, что `BE-067` в `journal`
(там тоже передавали `null!`; вылечено `new Paging(1, int.MaxValue)`), но правка `b9173f09`
тронула только `Journal`.

## Критерии приёмки

- локальный record по образцу `JournalReadRepository`:
  `public sealed record Paging(int Page, int PageSize) : IPaging;` и `GetAllAsync(new Paging(1, int.MaxValue), ct)`;
- `GET /api/v1/partners` изнутри контура с валидным токеном → **200** (не `500`);
- `test-partner-softdelete.yml` → **`4 passed`** (сейчас `4 failed`, все `Actual: InternalServerError`);
- E2E (`front-e2e-repeat.yml`, контейнер с браузерами): `seedSession` проходит, `23 failed` исчезают;
- `restarts` не растёт 30 с; в логе `partners` `NullReferenceException` = 0.

### Вердикт @TL 2026-11-10 19:25 — **принято по артефакту**

- Проверил в `origin`: в `PartnerReadRepository` вызовов `GetAllAsync(null` — **0** (было — источник `NullReferenceException`), и `Paging(` присутствует (**2**). То есть null-paging заменён значением по умолчанию.
- Причина в карточке названа верно: `IPaging` null → NRE на `GET /partners`. Такие дефекты важны тем, что выглядят как «сервис упал», а на деле — отсутствующий параметр.

## Результат

Причина: `PartnerReadRepository.GetAllAsync(null, ct)` → DF `IPaging` null → NRE. Фикс: `record Paging(int Page, int PageSize) : IPaging` + `new Paging(1, int.MaxValue)`. Сборка `Partners.sln` зелёная. Верификация `GET /partners` → 200 — на контуре @DO.
