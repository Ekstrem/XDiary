# BE-001: Скаффолд .NET solution (DigiTFactory, профиль Single)

- **Статус:** Закрыта (TechLead: проверено — CI green, 11 сборок: 10 сервисов + шлюз)
- **Приоритет:** P0
- **Источник:** ADR-001, ADR-002, edm-net skill
- **Зависимости:** —

## Задача
Создать .NET 8 solution с 10 проектами микросервисов + шлюзом. Подключить `DigiTFactory.Libraries` (SeedWorks, CommandRepository.Postgres, ReadRepository.Postgres, EventBus.InMemory).

Профиль **Single** на каждый сервис:
- `AddEventBusInMemory()`;
- `AddEventStorePostgres(..., FullEventSourcing)`;
- `AddReadStorePostgres` (та же БД, без отдельной схемы).

> Примечание: скаффолд — по одному solution на сервис (норма для MSA), а не один общий solution на 10 проектов.

## Критерии приёмки
- [x] `dotnet build` проходит без ошибок — все 10 микросервисов + шлюз собираются (CI green).
- [x] Каждый сервис стартует как 1 процесс (Cmd+Evt+Qry) — профиль Single (ADR-002).
- [x] Используются только `DigiTFactory.Libraries` (без собственных `IEventBus`/репозиториев) — SeedWorks + AbstractAggregate + EventBus.InMemory + ReadRepository.Postgres.
- [x] Выбор профиля через `ASPNETCORE_ENVIRONMENT` → `appsettings.{Profile}.json`.

## Результат
Скаффолд завершён: 10 микросервисов (journal, partners, catalog, somatic-series, daily-metrics, garmin-gateway, apple-health-gateway, analytics, privacy, portability) + API Gateway (YARP).
Каждый сервис — 7 проектов (Domain/DomainServices/InternalContracts/Application/Storage/Api/Domain.Tests) по edm-net; analytics — read-only (3 проекта); шлюз — YARP.
CI на каждый сервис публикует Docker-образ в GHCR (`ghcr.io/ekstrem/xdiary-*`).
