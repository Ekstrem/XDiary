# BE-017: Маршрут somatic-series: шлюз ≠ контроллер

- **Статус:** Закрыта
- **Приоритет:** P1
- **Источник:** E2E (находка @TE); `6-msa/ApiGateway` (routes), `SomaticSeriesController`
- **Зависимости:** —

## Проблема
- Шлюз маршрутизирует `/api/v1/somatic-series/{**catch-all}`.
- Контроллер объявлен как `[Route("api/v1/somatic")]` (`6-msa/BC-SomaticSeries/src/SomaticSeries.Api/Controllers/SomaticSeriesController.cs`).

Итог: запросы через шлюз по `/api/v1/somatic-series/...` приходят в сервис, который ждёт `/api/v1/somatic/...` → **404**.

## Задача
Согласовать путь (выбрать один вариант и применить в одном месте):
- (a) контроллер → `api/v1/somatic-series`; **или**
- (b) шлюз → `/api/v1/somatic/{**catch-all}`.

Не путать с `daily-metrics` (отдельный сервис).

## Критерии приёмки
- [x] Путь шлюза и контроллера совпадают.
- [x] E2E somatic-сценарий проходит.
- [x] CI green.
