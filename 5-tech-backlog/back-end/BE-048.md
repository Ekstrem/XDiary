## Проблема
`ListPartnersQuery()` не принимает контекст пользователя, поэтому отдаёт **всех партнёров** из БД. Для приватного дневника пары это: (1) утечка чужих данных (имена, фото), (2) бессмысленный экран выбора «кто ты», (3) владелец не может понять, где его партнёр, а где мусор от тестов.

## Задача (зона @BE, `6-msa/BC-Partners`)
1. **Скоупить список по текущему клиенту:** брать `clientId` из JWT (`sub`) и возвращать только партнёров, связанных с этим клиентом (через `link-client`), плюс, если нужно для онбординга, — партнёров, у которых связи ещё нет, но только созданных этим клиентом (поле «создал»/`CreatedBy`).
2. **Не отдавать чужих никогда:** партнёры другого клиента не должны попадать в ответ ни при каких параметрах.
3. Покрыть тестами: клиент A видит только своих; клиент B не видит партнёров A; пустой список — валидный ответ.
4. **Проверить фронт-сценарий:** на шаге «Кто ты?» показывать только «своих» и явно предлагать «Создать партнёра», если список пуст.

## Критерии приёмки
- [ ] `GET /partners` для клиента A возвращает только партнёров, связанных с A (или созданных им).
- [ ] Тест «чужой партнёр не виден» в `Client.IntegrationTests`/`Partner.IntegrationTests`.
- [ ] Владелец на экране «Кто ты?» видит только своих (или пусто + «Создать партнёра»).
