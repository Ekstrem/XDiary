# BE-007: Реализовать `garmin-gateway` (Шлюз Garmin, GarminSync)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** BC-GarminGateway (`03-ddd/BC-GarminGateway/*`), G-01, GA-01..03, ADR-012
- **Зависимости:** BE-001

## Задача
Реализовать шлюз-ACL к Garmin:
- Агрегат **GarminSync** (credentials, token, syncConfig, lastSync).
- Personal API (ключ, OAuth-токен, кэш 23 ч); синк пошаговый (стресс → пульс/BB → сон → HRV → занятия).
- Отдаёт: **соматику** → `somatic-series`/`daily-metrics`; **занятия** → `journal` (автоперенос).

## Критерии приёмки
- [ ] Соматика и занятия — раздельные потоки (разные сущности).
- [ ] Токен кэшируется ≤ 23 ч; реавторизация при истечении.
- [ ] Занятия отдаются без фильтра «избранное» (видны ❤/🖤).
- [ ] Интеграционный тест.
