# BE-011: Реализовать `portability` (Перенос данных, CsvDocument)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** BC-Portability (`03-ddd/BC-Portability/*`), US-09, ADR-011
- **Зависимости:** BE-001

## Задача
Реализовать микросервис `portability`:
- Агрегат **CsvDocument**.
- Экспорт/импорт CSV (записи, соматика, сон, стресс).
- Импорт идемпотентный (upsert по `id`).

## Критерии приёмки
- [ ] CSV-заголовки соответствуют `CSV_HEADERS` (текущий формат).
- [ ] Списки внутри полей через `;` (позы, теги, игрушки…).
- [ ] Импорт не дублирует записи (merge по `id`).
- [ ] Интеграционный тест.
