# BE-150 — P1: версия события = `DomainEvent.Command.Version` вместо `GetEventCountAsync + 1`

- **Приоритет:** P1

## Задача

1. Во всех 10 `*EventStoreHandler` убрать `Version = await store.GetEventCountAsync(domainEvent.Id) + 1`;
   сохранять `Version = domainEvent.Command.Version`.
2. Обеспечить, чтобы `Command.Version` был новой версией агрегата (timestamp),
   а `DomainEvent.Version` оставался acted-on версией для оптимистичной блокировки.
3. Обновить регрессионные тесты версий: сохранённая версия равна `Event.Command.Version`,
   последовательные команды дают строго возрастающие версии.
4. @DR 22:37: после Journal-пилота раскатать `CommandToAggregate` на остальные 9 BC —
   Application-хендлеры создают команду и передают её через Notifier в агрегат.

## Критерии приёмки

- [x] Ни одного `GetEventCountAsync + 1` в `*EventStoreHandler`;
- [x] Во всех BC `Command.Version` — новая версия агрегата (timestamp с монотонной защитой), не счётчик событий;
- [x] Регрессии версий обновлены: 12/12 PASS при локальном запуске рефлексией + 106 доменных unit-тестов PASS;
- [x] Release-сборка всех BC = 0 ошибок; PR #3342 открыт;
- [x] `CommandToAggregate` раскатан на все 10 BC: Journal — обязательный параметр,
      остальные 9 — опциональный для обратной совместимости тестов, хендлеры передают
      `AggregateCommandFactory.Create(...)` явно.
