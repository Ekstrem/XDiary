## Задача

1. Во всех 10 `*EventStoreHandler` убрать `Version = await store.GetEventCountAsync(domainEvent.Id) + 1`;
   сохранять `Version = domainEvent.Command.Version`.
2. Обеспечить, чтобы `Command.Version` был новой версией агрегата (timestamp),
   а `DomainEvent.Version` оставался acted-on версией для оптимистичной блокировки.
3. Обновить регрессионные тесты версий: сохранённая версия равна `Event.Command.Version`,
   последовательные команды дают строго возрастающие версии.

## Критерии приёмки

- [ ] Ни одного `GetEventCountAsync + 1` в `*EventStoreHandler`;
- [ ] Во всех BC `Command.Version` — новая версия агрегата (timestamp), не счётчик событий;
- [ ] Регрессии версий обновлены и проходят в CI;
- [ ] Release-сборка всех BC = 0 ошибок; PR открыт.
