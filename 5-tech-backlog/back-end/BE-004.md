# BE-004: Реализовать `catalog` (Каталог, агрегат CatalogItem)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** BC-Catalog (`03-ddd/BC-Catalog/*`), US Инк 4/5/8/9
- **Зависимости:** BE-001

## Задача
Реализовать микросервис `catalog`:
- Агрегат **CatalogItem** (kind: costume/toy/fantasy/contraception; name, notes, photo, brand, archived, partner).
- Command API: CRUD элемента; архив игрушек.
- Query API: список по `kind`, деталь.

## Критерии приёмки
- [ ] CRUD по всем `kind` (костюм/игрушка/фантазия/контрацепция).
- [ ] Архив игрушек (archived) отображается внизу.
- [ ] Интеграционный тест Command → Query → Assert.
