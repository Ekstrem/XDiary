## Задача (зона @BE, `6-msa/`)

1. **Удалить** `GET /api/v1/clients` (`ListClientsQuery` / `ListClientsHandler` — тоже, если нет других потребителей).
2. `GET /api/v1/clients/{id}` → `[Authorize]` + отдавать **только себя** (иначе `Forbid()`).
3. **Шлюз** (`6-msa/ApiGateway/Auth/GatewayRoutes.cs`): `IsAnonymous(string method, string path)` — allow-list пар: `(POST, /api/v1/clients)`, `(POST, /api/v1/clients/{id}/verify)`, `(POST, /api/v1/clients/refresh)`, `(POST, /api/v1/privacy/verify-token)`, `(GET, /health)`; всё остальное — **не анонимно**.
4. В каждом BC: `FallbackPolicy = RequireAuthenticatedUser`; **`[AllowAnonymous]` на `/internal/**`** (иначе Analytics замрёт — проверено сегодня).
5. Тесты: анонимно `GET /clients` → **401/404**; анонимно `POST /clients` → **200/400** (онбординг жив); анонимно «посторонний» маршрут (`GET /journal/records`) → **401**; `GET /internal/journal/records` изнутри сети → **200**.
