## Задача
1. Проверить `POST /connect` end-to-end: валидация Credentials (`CredentialsValidator`), сохранение в агрегат `GarminSync`, ответ для UI (`state`).
2. `SyncCommand`/`FetchActivitiesCommand` — реально ходят в Garmin Personal API с сохранённым токеном (или явно задокументировать, если пока прокси-заглушка), ошибки истечения токена — по спецификации `ReauthOnExpiry`.
3. Тесты: `GarminGateway.Domain.Tests` (Credentials/истечение) + `*.ApiTests` на `/connect` 401 без токена и 200/4xx с валидными/невалидными данными.

## Критерии приёмки
- `/connect` с валидными Credentials → агрегат сохранён, `GET /state` его показывает; с невалидными → 4xx с причиной.
- `/sync` с подключённым токеном отрабатывает (или документированный статус «прокси ещё не подключён» с картой следующих шагов).
- Истёкший `TokenExpiry` → предсказуемая ошибка/`ReauthOnExpiry`-путь, а не 500.
- Тесты зелёные; контракт описан для @FE (поля, коды).

## Результат

Реализовано в PR #3230 (`93a5d72f5`) по `03-ddd/BC-GarminGateway/06-connect-contract.md`:

- OpenAPI: 6 схем — `ConnectCommand`, `CredentialsDto`, `SyncCommand`, `SyncConfigDto`, `GarminConnectionState`, `GarminApiError`; 18 `$ref`, dangling=0; ответы 200/400/502 получили тела.
- `Connect`, `Sync`, `FetchActivities`, `State` возвращают единый `GarminConnectionState`: `connected`, `sourceId`, `tokenExpiry`, `metrics`, `windowDays`, `lastSync`, `requiresReauth`. **`apiKey`/`oauthToken` из ответов убраны.**
- Машиночитаемые ошибки: `validation_error` (400), `not_connected` (400), `token_expired` (400), `upstream_unavailable` (502). `State` до Connect — 404.
- Sync/FetchActivities до Connect и при истёкшем `TokenExpiry` блокируются; невалидные `tokenExpiry`/`windowDays` отклоняются. Повторный Connect обновляет credentials, `requiresReauth` вычисляется из срока действия.
- Реальный вызов Garmin Personal API пока остаётся следующим прокси-этапом: текущие Sync/FetchActivities обновляют конфигурацию и `lastSync`; это явно задокументировано в PR.
- Тесты: 9 доменных кейсов + 3 интеграционных на отсутствие секретов и `requiresReauth`; Release-сборка Domain.Tests/IntegrationTests — 0 ошибок. `check_api_index` — 82/82.
