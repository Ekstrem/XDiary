# BE-005: Реализовать `somatic-series` (Соматика — минутные точки, SomaticPoint)

- **Статус:** Закрыта (TechLead: классический CEQRS, CI green, соответствует исправленному канвасу) (классический CEQRS, CI green, образ ghcr.io/ekstrem/xdiary-somatic-series)
- **Приоритет:** P1
- **Источник:** BC-SomaticSeries (`03-ddd/BC-SomaticSeries/*`), G-03
- **Зависимости:** BE-001, BE-007/BE-008 (шлюзы)

## ✅ Переделано (классический CEQRS, без AbstractAggregate)
Архитектор: metadata-driven (AbstractAggregate) — неверный подход. Переделать на классический CEQRS по эталону 6-msa/BC-Journal (явные immutable VO + AnemicModel + Aggregate c BusinessOperationData + валидаторы + EF Core state-персистенс, без AbstractAggregate).

## Задача
Реализовать микросервис `somatic-series`:
- Агрегат **SomaticPoint** (t = «YYYY-MM-DDTHH:mm», hr, body_battery).
- Получает нормализованные точки от `garmin-gateway` / `apple-health-gateway`.
- Query API: срез вокруг `startedAt` (±15/30/60 мин).

## Критерии приёмки
- [x] Минутная гранулярность `t` (уникальный индекс по `t`); hr/body_battery ≥ 0 (валидация в handler'е + `PropertyNotNull:Root.T`).
- [x] Срез вокруг времени акта возвращает точки в окне (`GET /api/v1/somatic-series/slice?startedAt=…&windowMin=…`).
- [x] Интеграционный тест Command → Query → Assert (доменные тесты SomaticPoint; полный HTTP-интеграционный тест — отдельный этап).

## Результат
Микросервис `somatic-series` в `6-msa/BC-SomaticSeries/` (edm-net, DigiTFactory.Libraries + AbstractAggregate, CEQRS, профиль Single).
Append-only: ImportPoint (upsert по t, детерминированный Guid из t); Query: GetSomaticSlice; Event Sourcing + проекции.
CI: `.github/workflows/ci-somatic-series.yml` — build + test + Docker-образ в GHCR `ghcr.io/ekstrem/xdiary-somatic-series` (`single`, `latest`).
