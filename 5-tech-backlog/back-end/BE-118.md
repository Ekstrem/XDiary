# BE-118: тесты создания объектов БД (Migrate на свежем Postgres) для каждого BC

- **Статус:** На проверке
- **На проверке с:** 2026-11-16
- **Приоритет:** P1 (инцидент 42P07: создание объектов БД не проверяется в CI, расхождение dev/prod)
- **Источник:** владелец 2026-11-16 «ошибки с миграцией… не тестируем создание объектов»
- **Зависимости:** `DO-131` (`check_schema` декоративен) — CI-интеграция на @DO
- **Проверяет:** @TL (код); CI-интеграция — @DO
- **Исполняет:** @BE (тесты), @DO (Postgres в CI + прогон)

## Задача

1. @BE: в `*.IntegrationTests` каждого BC с миграциями (Journal, Partners + 8 BC с `CommandDbContext`) — тест `DatabaseCreationTests`: `Migrate()` на свежем Postgres, проверка что таблицы созданы и `__EFMigrationsHistory` заполнена.
2. @DO: дать Postgres в CI (env `XDIARY_TEST_POSTGRES`) и гонять эти тесты (без БД тест помечен как пропуск, не «зелёный по тишине»).

## Критерии приёмки

- [ ] 10 BC имеют `DatabaseCreationTests`, все затронутые тест-проекты собираются (`Ошибок: 0`);
- [ ] в CI тесты реально гоняются на свежем Postgres (не пропускаются).

## Результат

- `DatabaseCreationTests` добавлен в 10 BC: Journal/Partners — 3 контекста (EventStore + Command + Read), 8 BC — `CommandDbContext`; подключение из env `XDIARY_TEST_POSTGRES`, без БД — пропуск с выводом.
- Сборка всех 10 тест-проектов — `Ошибок: 0` (пуш `role/be`).
- CI-интеграция — поручение @DO записано в чат.
