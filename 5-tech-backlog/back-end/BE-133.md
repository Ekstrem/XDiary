## Что это значит
`502` на `POST /clients` — **следствие** краша `client`, а не отсутствие маршрута в шлюзе. `GET 401` приходит, когда контейнер успевает ответить между рестартами.

**Из-за этого красные оба smoke-джоба:**
- `smoke-api`: `System.InvalidOperationException : POST /clients -> 502` в `E2EInfra.LoginAsync` (`6-msa/BC-Journal/src/Journal.ApiTests/E2EInfra.cs:57`) ⇒ `PartnerSoftDeleteTests` **не доходят до сценария** (3 failed / 1 passed);
- `smoke-front`: `dev API не поднялся за 180 с (clients=401 clients/me=401 POST/clients=502)`.

⚠️ **важное следствие:** `BE-131` (soft-delete) на стенде **не проверен** — тесты падают на входе, а не на удалении.

## Где смотреть
`6-msa/BC-Client/src/Client.Api/Program.cs:63` — резолв из DI внутри `using (var scope = app.Services.CreateScope())`:
```csharp
scope.ServiceProvider.GetRequiredService<DigiTFactory.Libraries.CommandRepository.Postgres.EventStoreDbContext>().Database.Migrate();
scope.ServiceProvider.GetRequiredService<ReadDbContext>().Database.Migrate();
```
Autofac-исключение на этом шаге обычно значит: зависимость не зарегистрирована (или зарегистрирована как `InstancePerLifetimeScope`, а резолвится из корневого провайдера), либо строка подключения пустая → `EventStoreDbContext` не конструируется.

## Критерии приёмки
- `podman ps` → `xdiary-client` `Up` без роста `RestartCount` (0–1);
- прямой `curl -X POST http://10.89.9.31:8080/api/v1/clients -d '{}' -H 'Content-Type: application/json'` → `400` (валидация), не `000`/`502`;
- через шлюз `POST /api/v1/clients` → `200/400`;
- `smoke-api` и `smoke-front` зелёные; после этого — проверка `BE-131` на стенде.
