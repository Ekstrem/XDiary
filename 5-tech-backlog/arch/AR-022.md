# AR-022: индекс описывает маршруты журнала, но **не тела запросов** — фронт и тесты угадывают

- **Статус:** На проверке
- **Приоритет:** **P1** (из-за этого `POST /records/{id}/when` дал `400` в прогоне @TE, и это выглядело дефектом)
- **Источник:** @TE `23:26` (транскрипт `9-tests/reports/be093-dev-transcript.md`) + проверка @TL по `api-index.yaml`
- **Проверяет:** @TL
- **Артефакт:** `04-architecture/api-index.yaml` — блоки `request` у **14** POST-операций журнала (включая `Journal.IngestPartnerEvent`); гейт `check_api_index` → 82 = 82, `rc=0`

## Факт

В `04-architecture/api-index.yaml` для команд журнала описаны `codes`, `auth`, `verification`, но **нет `request`**:

```yaml
- bc: Journal
  method: POST
  path: "/api/v1/journal/records/{id}/when"
  operationId: Journal.SpecifyWhen
  auth: jwt
  codes: {200: "ok", 400: "доменная ошибка (validation/invariant)", 401: ..., 403: ..., 404: ...}
  # request: — ОТСУТСТВУЕТ
```

При этом фактический контракт есть в коде (`JournalCommands.cs:11`):

```csharp
public sealed record SpecifyWhenCommand(Guid AggregateId, string StartedAt);
```

⇒ тело **`{"startedAt": "<ISO>"}`**, а `{"when": "..."}` (как пробовал @TE) законно даёт `400` — не дефект, а **угадывание тела**.

## Что сделать

Обязательно (минимум — то, на чём уже спотыкались):

| Операция | Тело (из кода) |
|---|---|
| `Journal.SpecifyWhen` | `{ "startedAt": string }` |
| `Journal.SpecifyPlace` | `{ "place": string }` |
| `Journal.AddPartner` | `{ "partnerId": string }` |
| `Journal.AddAccessories` | `{ "costumes": [], "toys": [], "fantasies": [], "tags": [] }` — **все четыре обязательны**, иначе `400` |
| `Journal.RecordContraception` | `{ "contraceptives": [], "contraceptiveCount": int }` |
| `Journal.AddPositions` / `Duration` / `Orgasms` | по коду `JournalCommands.cs` |
| `Journal.StartManualEntry` / `StartFromGarmin` | по коду (`clientId` из токена, не из тела) |

Плюс правило на будущее: **если у операции есть тело, оно описано в индексе**; `check_api_index` может это проверять (операция с `request.required` непустым ⇒ в индексе есть `request`).

## Критерии приёмки

- у всех команд журнала в индексе есть `request` с полями и обязательностью;
- `check_api_index` → `rc=0`, счётчик не изменился (82);
- @TE прогоняет `POST /records/{id}/when` с `{"startedAt": "..."}` → **200** и фиксирует в транскрипте.

## Почему P1

Тело — часть контракта. Без него фронт и тесты угадывают, а `400` выглядит как дефект бэкенда; мы на этом уже потеряли два разбора (`when`, `accessories`).
