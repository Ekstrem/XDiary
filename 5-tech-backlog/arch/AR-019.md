# AR-019: `api-index` после вывода YARP — маршруты и владельцы операций

- **Статус:** ToDo
- **Приоритет:** P2 (`ADR-030` §4 строка 6)
- **Источник:** `ADR-030` §5 этап 4; §4 строка 6

- **Проверяет:** @TL

## Задача

Привести `04-architecture/api-index.yaml` и `openapi/*.json` в соответствие с состоянием после
удаления `api-gateway`: ни одна операция не должна остаться «на YARP».

## Критерии приёмки

- `check_apim_drift.py --specs-only` → `rc=0` (индекс ↔ спеки). **Сейчас `rc=1`:** два **внутренних** маршрута (`DailyMetrics.InternalSeries`, `Journal.ClientIds`) есть в индексе и **не должны** быть в публичном снимке ⇒ инструмент обязан **пропускать `internal: true`** (патч передан @DO: функция `internal_operations` + `want -= internal` в обоих сравнениях);
- **в индексе нет упоминаний YARP** — проверено 2026-11-10: `yarp` = 0, `api-gateway` как текст = 0 ⇒ **выполнено**.
  *Было:* «в индексе не осталось операций, помеченных как обслуживаемые `api-gateway`» — **формулировка неверна**: сервис `api-gateway` **жив** (`7-deploy/podman-compose.yml`, `6-msa/ApiGateway/README.md:35` — `GET /api/v1/bff/analytics-summary`), это **BFF**, а не YARP. По такой формулировке задача была бы невыполнима **по построению**;
- `check_api_index.py` зелёный — **`rc=0`** (82=82) ⇒ **выполнено**; `tool=` в квитанции `check_apim_drift` **отсутствует** (`:131` печатает `REF=… | образ=… | время=…`) — правка @DO (1 строка).

## Результат

**Обновлено 2026-11-10 (после правки @DO `07768c4d9`), по критериям:**
1. `check_apim_drift.py --specs-only` → **`rc=0`**, квитанция `индекс 78, спеки 78, расхождений 0` ⇒ **выполнено**. Инструмент фильтрует **обе** стороны: индекс — блоки без `internal: true`, спеки — пути `/internal/**`. **Моя арифметика в патче была неверной:** я написал «82 − 2 = 80», хотя внутренних в индексе **4** (`Journal.ListAll`, `Journal.IngestPartnerEvent`, `DailyMetrics.InternalSeries`, `Journal.ClientIds`), из них в снимке **2** (`ListAll`, `IngestPartnerEvent`) ⇒ одной фильтрации индекса не хватало (получалось 78 против 80). @DO нашёл это и починил шире — фильтр по обеим сторонам.
2. YARP: `yarp` = 0, `api-gateway` как текст = 0 ⇒ **выполнено** (критерий переформулирован: шлюз живёт как BFF).

**Прежняя запись (для истории):**
1. `check_apim_drift.py --specs-only` → **`rc=1`**, 2 ошибки: `DailyMetrics.InternalSeries`, `Journal.ClientIds` — «есть в `api-index`, нет в `openapi/*.json`». **Причина вне моей папки:** это **внутренние** маршруты (`internal: true`), которых в публичном снимке быть не должно; инструмент сравнивает **все** операции индекса с публичными спеками. Решение (@TL `18:30`): `internal/**` из снимка **исключается** ⇒ инструмент обязан **пропускать операции с `internal: true`** (3 строки, зона @DO).
