# AR-163 — Проработка: `Connect` в BC-GarminGateway = ввод токена (серверный прокси), снять ограничение «без UI подключения»

- **Статус:** В работе
- **В работе с:** 2026-11-20
- **Артефакт:** `03-ddd/BC-GarminGateway/02-aggregate-canvas.md`, `03-ddd/BC-GarminGateway/06-connect-contract.md`
- **Приоритет:** P1 (блокирует FE-057/BE-142: без уточнения канваса фронт не знает, что допустимо)
- **Прорабатывает:** @AR
- **Источник:** владелец 2026-11-20 («в настройках нужна кнопка для диалога ввода токена пользователя Garmin»); текущий канвас `03-ddd/BC-GarminGateway/02-aggregate-canvas.md:13` говорит «Connect = выбор источника + импорт CSV/прокси, **не OAuth-UI**»; backlog `G-01` — статус «без UI подключения»
- **Зависимости:** `G-01`, `G-02`, `G-06`, ADR-012

## Задача
1. Обновить канвас: **Connect = ввод токена пользователем в настройках** (пользователь получает OAuth-токен Garmin вне PWA и вставляет; токен хранится серверно в `Credentials`), синк — серверный прокси. Снять/переформулировать «не OAuth-UI» (ограничение было про браузерный OAuth-redirect, не про ввод токена).
2. ~~Обновить `01-user-stories/backlog.md`~~ — **убрано (ошибка постановки @TL 2026-11-21): backlog — зона @PO**, у @AR её нет. Формулировки G-01 (диалог токена, CSV запасной, контракт `06-connect-contract.md`) готовы в `dc18eb8c3` — их применит @PO, когда вернётся с итерации техдолга (или владелец своим словом). На закрытие AR-163 не влияет.
3. Зафиксировать контракт для FE/BE: поля (`ApiKey`, `OauthToken`, `TokenExpiry`), коды ошибок, поведение при истечении (`ReauthOnExpiry`), что CSV остаётся запасным путём.

## Критерии приёмки
- Канвас и `06-connect-contract.md` без противоречия «не OAuth-UI» vs «диалог токена»; ссылка на решение владельца 2026-11-20.
- @FE и @BE имеют однозначный контракт (поля/коды/истечение) в одном месте.
- Согласовано с владельцем (это изменение принятого решения).

## Результат
Канвас и контракт обновлены по решению владельца 2026-11-20: Connect = диалог ввода токена, синк через серверный прокси, CSV — запасной путь. Добавлен единый `06-connect-contract.md`: поля `CredentialsDto`, общий `GarminConnectionState` без секретов, коды `400/401/404/502`, `requiresReauth` и повторный Connect. В §6 перечислены отклонения кода для BE-142.

**Осталось для перехода `На проверке`:** применить правки G-01 в `01-user-stories/backlog.md` владельцем зоны @PO. Подготовленный текст был в коммите `dc18eb8c3`; из PR @AR он убран, потому что `guard-paths` запрещает @AR коммитить `01-user-stories/**` (коммит `dc18eb8c3` был сделан по прямому поручению владельца, но зона всё равно чужая).
