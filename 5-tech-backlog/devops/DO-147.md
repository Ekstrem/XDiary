## Факт (замер @DO на проде)

```
api-gateway: image=:single, running, restarts=1, exit=0, oom=false   ← образ НЕ из lock
остальные 11: single-48ca55f, /health = 200
файла /tmp/recreate-api-gateway.err НЕТ  ⇒ recreate-service для шлюза не запускался
```

## Корень (по коду `7-deploy/update.sh:281-298`)

```bash
OLD_STATE="$(cat "$IDFILE" 2>/dev/null || true)"
CHANGED=""
for svc in "${!CUR_IDS[@]}"; do
  old_id="$(printf '%s' "$OLD_STATE" | awk -v s="$svc" '$1==s {print $2}')"
  if [ "$old_id" != "${CUR_IDS[$svc]}" ]; then CHANGED="$CHANGED $svc"; fi
done
if [ -z "$CHANGED" ]; then
  say "изменений нет (по-образное сравнение): деплой не требуется"
  exit 0
fi
```

`CHANGED` считается сравнением **ID образов из lock с прошлым состоянием (файл `$IDFILE`)**, а **не** с тем, что реально запущено. Следствия:
1. Если lock не менялся (или менялся не для этого сервиса) — сервис в `CHANGED` не попадает, `recreate-service` для него не вызывается, и контейнер остаётся на прежнем образе — **навсегда**;
2. Состояние считается «сошедшимся» по `$IDFILE`, а не по факту ⇒ рассинхрон «файл говорит одно, контейнер другое» не лечится;
3. Именно поэтому в прогоне `900bfc42` не появился `/tmp/recreate-api-gateway.err` (@DO): шлюз в `CHANGED` не попал, хотя фактически работал не на том образе.

## Задача

Добавить **сверку с фактом** перед формированием `CHANGED`:
```
for svc: running_img = podman inspect <container> --format '{{.ImageName}}'
         want_img    = ghcr.io/ekstrem/xdiary-$svc:<tag из lock>
         если running_img != want_img → CHANGED += svc  (даже если IDFILE совпадает)
```
Плюс: если контейнера нет — тоже в `CHANGED`. И печатать причину попадания (`changed: image-id` / `changed: image-mismatch(<running> != <want>)`).

## Критерии приёмки

- На стенде/проде при расхождении «контейнер ≠ lock» сервис **всегда** попадает в `CHANGED` и пересоздаётся (проверка: `api-gateway` переходит с `:single` на `single-<lock>`);
- при полном совпадении — поведение прежнее (`изменений нет…`, `exit 0`);
- в логе видно, **почему** сервис попал в `CHANGED`;
- прогон `deploy-prod` зелёный, `images.lock` = образы всех 12 контейнеров.
