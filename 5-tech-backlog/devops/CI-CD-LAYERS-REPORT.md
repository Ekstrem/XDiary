## Канон: как его числа читать (измерено 2026-11-10)

| режим | результат |
|---|---|
| 1 проход | `rc=0`, 74/74, длительность 104 с |
| 3 прохода, пауза **300 с** | `rc=0` ×3, 74/74, unknown=0 (145.5 / 121.4 / 121.2 с) |
| 3 прохода, пауза **20 с** | `rc=0` → `rc=2` (unknown 7) → `rc=2` (unknown 2) |
| 3 прохода подряд, попробные длительности | 222 пробы, **0 unknown**; медиана **0.58–0.61 с**, максимум **15.1 с** (хвост: `Analytics.Correlations` 15.1, `Journal.RecordOrgasms` 11.8, `Catalog.Archive` 10.0) |

Правило: у числа канона указывать **точку, число проходов, паузу и распределение** (медиана/максимум) — агрегат `74/74` скрывает хвост, из которого и появляются `unknown`.
Инструмент попробной диагностики: `python tools/canon_per_probe.py --base <URL> --passes N`.
