# DO-004: TLS (Tailscale) + приватная сеть + проверка доступа

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** ADR-009, ADR-015, `04-architecture/vps-setup.md` (§2.3, §6)
- **Зависимости:** DO-003

## Задача
- Tailscale на VPS-1 и на телефонах пары (один tailnet).
- TLS через `tailscale cert xdiary.vps1.ts.net` (Let's Encrypt DNS-01, автопродление) → шлюз терминирует HTTPS.
- Публичный 443 **не открывается** (доступ только по MagicDNS-имени).
- Приватная сеть VPS-1 ↔ VPS-2 (PostgreSQL не наружу).
- Сквозной доступ: PWA → шлюз (HTTPS) → сервисы → БД.

## Критерии приёмки
- [ ] `https://xdiary.vps1.ts.net` — валидный сертификат, PWA грузится (Service Worker работает).
- [ ] Публичный 443 закрыт (доступ только через tailnet).
- [ ] `nc -zv VPS2 5432` снаружи — закрыто; с VPS-1 — открыто.
- [ ] Анонимный запрос к API → 401 (кроме `/api/v1/privacy/*` и `/health`).
