# DO-004: TLS (caddy/nginx) + приватная сеть + проверка доступа

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** `04-architecture/vps-setup.md` (§2.3, §6), ADR-009
- **Зависимости:** DO-003

## Задача
- TLS на шлюзе: caddy (авто Let's Encrypt) или nginx+certbot.
- Приватная сеть VPS-1 ↔ VPS-2 (PostgreSQL не наружу).
- Проверить сквозной доступ: PWA → шлюз (HTTPS) → сервисы → БД.

## Критерии приёмки
- [ ] `https://<домен>` — валидный сертификат, PWA грузится.
- [ ] `nc -zv VPS2 5432` снаружи — закрыто; с VPS-1 — открыто.
- [ ] Анонимный запрос к API → 401 (кроме `/api/v1/privacy/*` и `/health`).
