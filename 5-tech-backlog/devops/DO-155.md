## Задача
1. После мержа спеки (@BE) прогнать `7-deploy/apim/import.sh` (contract-first: import swagger -> план -> publish -> start) на VPS-1, **ID API GarminGateway** зафиксировать в карточке.

3. Прогнать гейты APIM (`apim-auth.yml`, `apim-drift.yml`), убедиться что `/api/v1/garmin/*` присутствует и отвечает 401 без токена.
4. Дать @FE строку «как читать контракт» (URL страницы Gravitee docs / имя API + версия).

## Критерии приёмки
- В Gravitee API GarminGateway `started`, план `published`, спека с непустыми схемами (видно поля токена).
- `apim-auth` и `apim-drift` зелёные (или честно «не измерено» с причиной).
- @FE имеет ссылку/имя API и версию контракта; в карточке — ID API и дата публикации.

## Результат

Гармин-контракт опубликован в Gravitee (prod, VPS-1), все критерии выполнены фактом:

1. **Import (contract-first):** `import.sh` прогнан со спекой из main (#3395 — 6 схем: ConnectCommand/CredentialsDto/SyncCommand/SyncConfigDto/GarminConnectionState/GarminApiError, dangling=0; свежая скопирована на прод с raw.githubusercontent, старая — 0 схем — забэкапена в /tmp). **ID API GarminGateway: `83ff3a03-f683-4b51-bf3a-03f683db51e7`**.
2. **Состояние:** API `STARTED` (management, проверено), план Default KEY_LESS создан и опубликован (publish 200, start 204).
3. **Маршруты через APIM (8081), стабильно 3x подряд:** `/api/v1/garmin/state` = **401**, `POST /api/v1/garmin/connect` = **401**, `/api/v1/garmin/activities` = **401**; регресс-ручки `journal/recent` = 401, `catalog` = 401, `/health` = 200.
4. **Гейты:** `check_apim_health` = **APIM: OK**; `check_apim_drift --api garmin` = rc=0 с честным warning «GRAVITEE_TOKEN не задан — сравнение не выполнено» (не «совпадает»).

**Найденный и закрытый дефект класса «мёртвые записи»:** root-причина 500 на маршрутах — `events_latest` в Mongo содержал START_API-события записей, удалённых напрямую через Mongo (bd56826a с target=`/api/v1/garmin` — невалидный путь вместо URL); gateway маршрутизировал по мёртвой реплике. Чистка events_latest по 5 мёртвым garmin-записям + рестарт gateway → все ручки 401. Урок: удаление записи через Mongo без события оставляет «зомби-маршрут» — удалять через management API (или чистить events_latest).

**@FE — как читать контракт:** Gravitee Management Console (http://127.0.0.1:18084 через ssh-туннель на VPS-1, prod), API «GarminGateway.Api», версия 1.0, ID `83ff3a03…`; поля схем — в `openapi/garmin-gateway.json` (main, PR #3395) и `04-architecture/06-connect-contract.md`.
