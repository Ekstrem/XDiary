## Блокер: у токенов нет права на удаление issues

`DELETE /repos/Ekstrem/XDiary/issues/{n}` → **404** и у fine-grained PAT, и у классического,
хотя `permissions.admin = true`. GitHub отдаёт 404, когда у токена нет **Issues: write**:
удаление issue — админ-операция с этим правом на токене. **Удалить 1614 issues из агента
невозможно без нового токена** — это доступы (§7), их выдаёт владелец.

**Что сделано вместо «подождать»:**
1. `tools/sync_board.py`: дубликаты теперь **удаляются** (`DELETE`, ожидаем 204); если права
   нет (404) — **закрываются** с однократным предупреждением «нет Issues: write», чтобы гейт
   не выглядел зелёным молча;
2. к проекту добавляются карточки как раньше (фильтр по закрытым — следующий шаг);
3. план чистки и прогресс — готовы, запуск одной командой, когда появится токен.
