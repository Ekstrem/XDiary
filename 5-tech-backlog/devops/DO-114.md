## Задача

Убрать старые данные из прод-баз, не тронув схему и миграции, чтобы CJ-сценарии начинались с чистого
состояния. Прод до этого был «только чтение» — это единственное разрешённое исключение, по прямому
указанию владельца.

## Критерии приёмки

- [x] дамп **всех** БД до операции и его проверка (`pg_restore -l`: объектов > 0 либо в БД нет таблиц)
- [x] `TRUNCATE ... RESTART IDENTITY CASCADE` по всем таблицам, кроме `__EFMigrationsHistory`
- [x] после: строк **0** в каждой БД, `__EFMigrationsHistory` на месте
- [x] `/health` **200**, `GET /api/v1/clients` без токена **401**
- [x] в логах `client/journal/partners` — **0** исключений (`28P01`, `42P01`)
- [x] процедура зафиксирована ранбуком `7-deploy/runbooks/prod-data-reset.md`
