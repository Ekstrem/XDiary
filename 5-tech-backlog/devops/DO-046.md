# DO-046: P0 — OTP по Telegram не приходит на проде, войти невозможно

- **Статус:** В работе
- **В работе с:** 2026-11-08
- **Приоритет:** **P0** (владелец не может войти в прод: код не приходит → продукт недоступен для проверки)
- **Источник:** владелец 2026-11-08 ~03:20: «Попытался протестить. Код в телеграм не приходит, соответственно ничего не могу сделать»
- **Зависимости:** DO-025 (образ с `TelegramOtpSender`), ключи в `/opt/xdiary/7-deploy/secrets/.env`
- **Проверяет:** @TL (TechLead)

## Факты
- Отправитель: `6-msa/BC-Client/src/Client.Application/Security/TelegramOtpSender.cs`; ключи: `Otp:Telegram:BotToken`, `Otp:Telegram:AdminChatId` (или `ChatId`), опционально `Otp:Telegram:ChatIdMap`.
- В коде явные отказы: нет `BotToken` → `InvalidOperationException`; нет `chatId` → «номер не в ChatIdMap и нет AdminChatId — OTP не отправлен».
- На dev работает `CLIENTS__TESTOTP`, на проде его нет (правильно) — значит прод-путь упирается именно в Telegram.

## Диагностика (зона @DO, по порядку)
1. **Env контейнера:** `docker exec <client-api> env | grep -i '^Otp'` — проверить наличие и **непустоту** `Otp__Channel=telegram`, `Otp__Telegram__BotToken`, `Otp__Telegram__AdminChatId`. Имена с двойным подчёркиванием соответствуют `Otp:Telegram:...`.
2. **Логи API** по вызову `POST /api/v1/clients`: есть ли исключение `BotToken не задан` / `OTP не отправлен`, и **код ответа Telegram** (`401` — токен неверен, `400 chat not found` / `403 bot can't initiate` — пользователь не нажимал `/start` или `chat_id` не тот).
3. **Проверка бота напрямую** (без приложения): `curl -s "https://api.telegram.org/bot<TOKEN>/getMe"` → `ok:true`; затем `sendMessage` в `chat_id` из env тем же токеном. Токен **не печатать** в чат (правило §6).
4. **Сверка id:** `AdminChatId` должен быть **id пользователя** (личный чат) или группы, где бот участник. Если владелец не нажимал `/start` у бота — Telegram физически не даст боту написать первым.
5. **Сеть:** доступ VPS-1 → `api.telegram.org` (на dev работало, но проверить именно прод-контейнер).

## Обходной путь (только по решению владельца)
Временный тестовый код на проде (`Clients__TestOtp=000000`) — даёт войти и проверить остальное, но **ослабляет прод**; включать только с явного разрешения владельца и снять сразу после проверки.
