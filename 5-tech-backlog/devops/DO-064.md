# DO-064: гейт сверки `api-index.yaml` (AR) ↔ контроллеры (код)

- **Статус:** ToDo
- **Приоритет:** P2 (после T2/T9/`DO-051`; блокирует только «complete» индекса, не продукт)
- **Источник:** @AR 2026-11-11 15:03: `04-architecture/api-index.yaml` (79 операций, 12 BC, `status: draft`); спека гейта от @AR; ADR-025 §3 п.2 (индекс и гейт меняются одним коммитом)
- **Зависимости:** `openapi/index.json` (T4, @BE) — для второй половины (код ↔ реестр)
- **Проверяет:** @TL (домен инфраструктуры — @DO; саморевью запрещено)

## Задача (зона @DO, `tools/` + `.github/`)

1. Скрипт `tools/check_api_index.py`:
   - **парсит маршруты из кода**: `6-msa/BC-*/**/*Controller.cs` — `[Route("...")]` + класс `[ApiController]`, `[Http{Verb}("...")]`, `{id:guid}` → `{id}`; учитывать класс-уровневый `[Authorize]`/`[AllowAnonymous]`;
   - **сравнивает множества** с `operations` в `api-index.yaml` — расхождение **в любую сторону** → `rc=1` с конкретной парой (метод+путь);
   - проверяет, что у **каждой** операции есть `codes`;
   - проверяет, что `auth: anonymous` ровно у **4** контроллерных маршрутов (`POST /clients`, `POST /clients/{id}/verify`, `POST /clients/refresh`, `POST /privacy/verify-token`); `GET /health` — исключить (не контроллер);
   - `internal: true` не требует токена.
2. Подключить в CI (`ci-guards.yml` или отдельный job), **по §5.4 — два прогона**: дефект (удалить операцию из индекса → rc=1), норма (вернуть → rc=0) + `--selftest`.

## Критерии приёмки

- [ ] `--selftest` внутри, оба прогона записаны в `## Результат`.
- [ ] Дефект (операция удалена из индекса) → **rc=1** с парой `method path`.
- [ ] Дефект (новый маршрут в контроллере без записи в индексе) → **rc=1**.
- [ ] Норма → **rc=0**; на реальном репозитории — зелёный.
- [ ] Источник в `LoopMaker/tools/`, копия через `sync_tools --pull`.
