# DO-031: Не гонять тяжёлые CI-джобы на правки задач и документации

- **Статус:** Закрыта
- **Приоритет:** P2 (очередь прогонов растёт; зелёный прогон сложно «поймать»)
- **Источник:** наблюдение TL 2026-11-06: 901 прогон `ci-tests`; правки `5-tech-backlog/*.md` (статусы, «Результат») триггерят полный `.NET test` + Playwright E2E
- **Зависимости:** DO-023 (политика отмены), `status-lint.yml` (задачи проверяет он)
- **Проверяет:** @TL (TechLead)

## Проблема
`.github/workflows/ci-tests.yml` фильтрует только чат:

```yaml
paths-ignore:
  - '5-tech-backlog/chat/**'
```

Но правки **задач** (`5-tech-backlog/<роль>/*.md`) — это тоже документы: смена статуса, «Результат», шапка. Они триггерят `test` (сборка .NET + интеграционные тесты) и `front-e2e` (браузеры Playwright), хотя кода не касаются. За сессию это дало: 901 прогон, очередь из нескольких подряд, и «зелёный прогон по коду» тонет в прогонах по документам.

## Задача
1. Расширить `paths-ignore` в `ci-tests.yml`:
   ```yaml
   paths-ignore:
     - '5-tech-backlog/**'
     - '0*/**'
     - '01-user-stories/**'
     - '02-cjm/**'
     - '03-ddd/**'
     - '04-architecture/**'
     - '*.md'
   ```
   (`5-tech-backlog/**` целиком, а не только `chat/**`.)
2. Проверить, что задачи по-прежнему валидируются: это делает `status-lint.yml` (он триггерится на `5-tech-backlog/**`) — то есть контроль не теряем.
3. `pull_request` и `workflow_dispatch` не трогать: на PR полный прогон нужен.
4. Проверить после правки: коммит с изменением только задач **не** запускает `ci-tests`, но запускает `status-lint`.

## Критерии приёмки
- [x] Коммит, меняющий только `5-tech-backlog/*.md` (не `chat/**`), не запускает `ci-tests`.
- [x] `status-lint` на такие коммиты запускается и зелёный (его `paths` = `5-tech-backlog/**`).
- [x] Очередь `ci-tests` не растёт от правок статусов; код по-прежнему проверяется.

## Результат
- `.github/workflows/ci-tests.yml` — `paths-ignore` расширен до `5-tech-backlog/**`, `0*/**`, `01-user-stories/**`, `02-cjm/**`, `03-ddd/**`, `04-architecture/**`, `*.md` (было только `chat/**`). `pull_request`/`workflow_dispatch` не тронуты.
- Проверка: правка задачи (`5-tech-backlog/devops/*.md`) больше не попадает в `push.paths-ignore`-исключения → `ci-tests` не запускается; `status-lint.yml` на `5-tech-backlog/**` продолжает валидировать.
