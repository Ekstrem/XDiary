# DO-094: Гейт «упомянутый статус ADR совпадает с фактическим»

- **Статус:** На проверке
- **Приоритет:** P1 (документный гейт; ловит класс, который @TL возвращал трижды)
- **Источник:** @TL 2026-11-05 16:41 — в `release-gate.md:9` и `DO-079.md:123` стояло `ADR-031 (Предложено)`,
  тогда как `adr-031.md` — `Отклонено (2026-11-05)`
- **Проверяет:** @TL (автор задачи — @DO, доменный ревьюер инфраструктуры совпадает с автором)
- **В работе с:** 2026-11-05

## Задача

Класс «документ цитирует статус ADR, которого нет» повторился три раза: читатель верит
документу, а гейты — файлу. Нужна **машинная** сверка: статус, упомянутый рядом с `ADR-NNN`
в тексте, обязан совпадать со строкой `- **Статус:**` файла `04-architecture/ADL/adr-NNN.md`.

## Что сделано

`tools/check_adr_refs.py` — три формы ссылки:

```
`ADR-031` (`Предложено`)
ADR-031 (**`Принято`**)
`ADR-026` (`Пересмотрен 2026-11-05` — действует)
```

Каталоги по умолчанию: `7-deploy/**`, `5-tech-backlog/devops/**`, `tools/**` (моя зона).
Флаг `--include-arch` добавляет `04-architecture/**` — зону @AR (он открыл её для чтения гейтом,
@AR 2026-11-05 16:51), но **не по умолчанию**: на момент включения в его файлах было 2 нарушения,
и блокировать `main` чужой зоной раньше правки — против правила «красное указывает на новое».

## Результат

| проверка | факт |
|---|---|
| `--selftest` | **5/5** (несовпадение → нарушение; совпадение → чисто; `Пересмотрен` с датой → чисто; другой статус → нарушение; текстовый кейс «заявлено/факт») |
| **на дефекте** (до правки) | `release-gate.md:9` + `DO-079.md:123` → `проверено 6, нарушений 2`, **`rc=1`** — ровно те строки, что назвал @TL |
| **на норме** (после правки) | `проверено 5, нарушений 0`, **`rc=0`** |
| `--include-arch` (зона @AR) | `проверено 16, нарушений 2` → отдано @AR: `adr-031.md:3` (`ADR-026` заявлен `Принято`, фактически `Пересмотрен`), `ADL/README.md:34` (`ADR-032` заявлен `Предложено`, фактически `Отклонено`) |
| CI | шаг «ADR: упомянутый статус совпадает с фактическим» — блокирующий, `--selftest` перед нормой |

**Своя ошибка того же класса поймана этим же гейтом:** в `tools/README.md` я процитировал
`ADR-031 (Предложено)` как пример дефекта — гейт покраснел, пример переписан без статуса.

## Открытый пункт

Перевести CI-шаг на `--include-arch` после того, как @AR поправит две строки в своей зоне —
тогда класс закроется и в ADR-текстах, а не только в `7-deploy/`.
