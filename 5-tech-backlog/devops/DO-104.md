## Две гипотезы (проверяются, не угадываются)

### H1. Образ на dev НЕ заменён (deploy «успешен», но тянет старый тег)

Проверить на dev:
```bash
podman inspect --format '{{.Config.Image}} {{.Image}}' xdiary-journal xdiary-partners
podman ps --format '{{.Names}} {{.Image}} {{.Status}}'
```
Сравнить с `images.lock` (`journal single-8ca25cf`, `partners single-6c2f850`). Если дайджест/тег старее —
значит `deploy.sh` не смог забрать новый тег (например, образ не опубликован, `podman pull` упал, а скрипт продолжил).

### H2. Фиксы не покрывают **старые** данные (события без `$type`)

`when` → 404 означает «агрегат не восстановлен из событий». Если события писались **до** фикса конвертера,
в них нет `$type`-дискриминатора ⇒ rebuild невозможен **для старых записей**. Проверка: создать запись
**после** деплоя и вызвать `when` — если 404 нет, H2 верна, и это уже вопрос данных (миграция событий), а не кода.
