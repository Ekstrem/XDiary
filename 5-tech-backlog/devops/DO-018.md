# DO-018: Guard — запрет утечки секретов (токены/ключи) в чат, задачи и коммиты

- **Статус:** Открыта
- **Приоритет:** P1 (безопасность; репозиторий **публичный**)
- **Источник:** инцидент 2026-11-03 (@BE вписал фрагменты `Jwt:SigningKey` в `chat/be.md`); PO 2026-11-04; `AGENTS.md` §6
- **Зависимости:** —

## Проблема
В публичный репозиторий попали фрагменты `Jwt:SigningKey` (`chat/be.md`, коммит `2aa7bf9`). §6 AGENTS.md это запрещает, но **ничто не проверяет** — утечку обнаружили вручную, уже после пуша. Сейчас есть только `guard-paths` (зоны ролей), проверки секретов нет.

## Задача
- `tools/check_secrets.py`: сканирует `5-tech-backlog/**/*.md` (чат/задачи), `README.md`, `CHANGELOG.md`, `XDiary/AGENTS.md`, `*.cs`, `appsettings*.json` на паттерны:
  - `SigningKey`/`Jwt:SigningKey` со **значением** (base64 длиной ≥ 20);
  - `GARMIN_API_KEY=`, `PROJECT_PAT=`, `password=`/`passwd=` с значением;
  - длинные base64/hex строки в **чате** (≥ 32 символов) — с allowlist для dev-ключей из `appsettings.json`.
- Job `guard-secrets` в CI (push/PR) — падает при находке, выводит файл+строку (без значения!).
- **Allowlist:** dev-ключи `appsettings.json` (они не прод-секрет) — по пути/шаблону; секреты прод — только `.env`/Secrets, в git не бывают.
- Дописать правило в `XDiary/AGENTS.md` §6 и `5-tech-backlog/chat/README.md`: «ключи/токены/пароли в чат, задачи, README и коммиты — запрещено; проверяется `guard-secrets`; при утечке — зачистка + ротация через @DO».

## Критерии приёмки
- [ ] `tools/check_secrets.py` + job `guard-secrets` в CI.
- [ ] CI **краснеет** на тестовом секрете (проверено).
- [ ] Текущее дерево — зелёное (0 находок; dev-ключи в allowlist).
- [ ] Правило дописано в `AGENTS.md` §6 и `chat/README.md`.
