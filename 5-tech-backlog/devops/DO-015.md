# DO-015: CD pipeline (GitHub Environments dev/prod + SSH-деплой)

- **Статус:** Открыта
- **Приоритет:** P2
- **Источник:** ADR-020 (CD pipeline, черновик)
- **Зависимости:** DO-012 (Funnel), ADR-019 (dev-стенд VPS-2)

## Задача
Реализовать CD по ADR-020: автоматическая доставка в **dev** на каждый merge в `main`, продвижение в **prod** по ручному approval.

## Критерии приёмки
- [ ] GitHub Environments `dev` и `prod` (у `prod` — protection rule: required reviewers / approval).
- [ ] Секреты в GitHub: `DEV_SSH_HOST`/`DEV_SSH_USER`/`DEV_SSH_KEY` (VPS-2 `77.91.73.67`/`ubuntu`) и `PROD_SSH_HOST`/`PROD_SSH_USER`/`PROD_SSH_KEY` (VPS-1 `31.192.111.168`/`deploy`).
- [ ] Workflow `deploy.yml`: push/merge в `main` → deploy **dev** (SSH → `update.sh` → `/health` 200) → E2E dev (`XDIARY_E2E_BASE_URL=https://xdiary-vps2.taile0b6ee.ts.net`) → manual approval → deploy **prod** (SSH → `update.sh` → `/health` 200).
- [ ] Продвижение dev→prod **теми же образами** (тег по commit SHA, а не `:single`).
