# DO-007: Починить деплой PWA на GitHub Pages

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** `.github/workflows/pages.yml`, CI (GitHub Actions)
- **Зависимости:** —

## Диагноз (TechLead)
Workflow падает на шаге **«Setup Pages»** (`actions/configure-pages@v5`), «Upload artifact» и «Deploy» — skipped. Сам `pages.yml` корректен (permissions `pages: write` + `id-token: write` на месте). Причина — **GitHub Pages не включён** для репозитория (Source ≠ «GitHub Actions»).

## Задача
Включить Pages: **Settings → Pages → Source: «GitHub Actions»** (действие владельца репозитория, НЕ правка кода/пайплайна).

## Критерии приёмки
- [ ] `pages.yml` завершается `success` (шаг «Setup Pages» зелёный).
- [ ] PWA доступен по URL GitHub Pages (`https://ekstrem.github.io/XDiary/`).
