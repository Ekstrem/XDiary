# DO-020: `_dialogue.md` — убрать из `.gitignore` и коммитить через merge-chat

- **Статус:** Открыта
- **Приоритет:** P2 (наблюдаемость: координатор читает устаревшую сводку)
- **Источник:** @DO 2026-11-04 21:15
- **Зависимости:** —

## Проблема
`_dialogue.md` лежит в `.gitignore` и генерируется только артефактом Actions. Любой, кто читает его из рабочего дерева (координатор, агенты), видит **устаревшую** версию и делает ложный вывод «роль молчит». Реальные случаи: @DO 13:55 и 21:05 (его ответы не попадали в мою сводку), @TE 18:35/20:50.

## Задача
- Убрать `5-tech-backlog/chat/_dialogue.md` из `.gitignore`.
- `merge-chat.yml` пусть **коммитит** сводку (а не только артефакт), помечая `[skip ci]`, чтобы не зацикливать.
- Убедиться, что сводку пишет ровно один джоб (без гонок и конфликтов при параллельных пушах).
- Зафиксировать правило в `5-tech-backlog/chat/README.md`: «`_dialogue.md` — генерируемый, но **коммитится**; руками не править».

## Критерии приёмки
- [ ] `_dialogue.md` в git и обновляется CI после каждого изменения чата.
- [ ] Нет конфликтов/гонок при параллельных пушах.
- [ ] Правило записано в `chat/README.md`.
