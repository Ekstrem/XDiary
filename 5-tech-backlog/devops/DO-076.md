# DO-076: APIM (Gravitee) в пути трафика — Funnel → Caddy → APIM → сервисы

- **Статус:** В работе
- **Приоритет:** P1 (решение владельца; меняет путь доставки — риск единой точки отказа)
- **Источник:** владелец 2026-11-16 «ставим гравити в пути»; факты и оценка — @DO `2026-11-04 20:13` (`REF=ccc19481`); решение ADR-023 (полный APIM)
- **Зависимости:** `DO-056` (импорт 12/12 `STARTED`), `DO-075` (креды), `DO-067` (Caddy вне пути — чинится здесь же)
- **Проверяет:** @AR (архитектура: @TL арбитр) + @TL (техника)

## Задача (зона @DO, `7-deploy/`)

Перевести трафик через APIM так, чтобы **снаружи ничего не изменилось**, кроме пути внутри.
Порядок обязателен (после каждого шага — проверка, до следующего не идти):

1. **Пути в APIM:** listener-пути 12 API привести к реальным `/api/v1/<домен>` (правка `7-deploy/apim/import.sh`, повторный импорт). Проверка: `curl` через шлюз `127.0.0.1:18082` на `/api/v1/...` отвечает так же, как напрямую на `:8080`.
2. **`/health` через APIM:** сейчас на `18082` → `404`. Сделать так, чтобы smoke-гейт (`/health`) проходил через новый путь.
3. **Funnel → Caddy → APIM:** `Caddyfile.prod` `reverse_proxy 127.0.0.1:8080` → `127.0.0.1:18082`; Funnel переключить на Caddy `:443` (иначе Caddy снова вне пути, `DO-067` повторится).
4. **Жизненный цикл:** APIM-контейнеры включить в `deploy.sh`/`update.sh` + `images.lock` (сейчас поднимаются вручную `up.sh` — это дрейф, `check_env_drift` его видит).

## Критерии приёмки

- [ ] Внешняя проверка: публичный URL отдаёт `/api/v1/*` и `/health` **200** так же, как до перевода (сравнение кодов до/после, в `## Результат`).
- [ ] Прямой обход APIM закрыт: `127.0.0.1:8080` снаружи недоступен (или слушает только APIM), т.е. трафик **не** может пойти мимо.
- [ ] Замер латентности до/после: p50/p95 на 3–4 ручках, числа в `## Результат` (бюджет: p95 ≤ 1000 мс).
- [ ] RSS стека APIM зафиксирован (сейчас ≈1.06 ГБ): числа и потолки; правило «< 500 МБ свободной RAM на пике» не нарушено.
- [ ] **Откат — одной строкой** (`reverse_proxy` назад) и он **проверен** (не «описан»): в `## Результат` — что именно откатывалось и что вернулось.
- [ ] `smoke` и `check_apim_drift` зелёные **через новый путь**; `check_env_drift` не видит APIM как дрейф.
- [ ] Ранбук `7-deploy/runbooks/apim.md` обновлён: путь запроса, откат, где смотреть метрики.
