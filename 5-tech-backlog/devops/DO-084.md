# DO-084: этап 1 `ADR-030` — `/health` через Caddy, проверки живости изнутри

- **Статус:** На проверке
- **В работе с:** 2026-11-05
- **Приоритет:** P1 (этап 1 плана вывода YARP, `ADR-030 (Принято, 2026-11-05)`)
- **Источник:** `ADR-030` §5 этап 1; §4 «Заведённые задачи» строка 1
- **Зависимости:** —
- **Проверяет:** @AR (связность с ADR) + @TL

## Задача

Публичный `/health` должен идти **через Caddy**, а не через YARP; проверки живости сервисов —
**изнутри** (не публично). Переписать `deploy.yml`/`public-probe` под это.

## Критерии приёмки

- публичный `/health` → **200** и в ответе **нет** `Server: Kestrel` от `api-gateway`;
- `grep -n 'api-gateway' 7-deploy/*.yml .github/workflows/public-probe.yml` — не используется для `/health`;
- проверки живости сервисов выполняются **изнутри** контура (ssh/`podman exec`), а не публичным запросом;
- прогон `public-probe` зелёный **после** изменения; откат описан одной командой.

## Результат

**Сделано (этап 1 `ADR-030`):** `/health` отдаёт **сам Caddy** (`respond "ok" 200` в `handle /health*`),
YARP в публичном пути по `/health` больше не участвует.

**Замер (прод, после применения):**

| проверка | результат |
|---|---|
| `http://127.0.0.1:8081/health` | **200**, `Server: Caddy` (не `Kestrel`) |
| tailnet-host `/health` | **200**, `Server: Caddy` |
| `/api/v1/catalog` | **401**, **3** заголовка `x-gravitee` (APIM в пути не тронут) |
| несуществующий путь | **404** |
| `public-probe` (GitHub-раннер, вне tailnet) | **#2 success**: `/health` 200, `catalog` 401 `x-gravitee=3`, unknown 404 |

**Критерии:**
- «публичный `/health` 200 и **нет** `Server: Kestrel`» — **выполнен** (заголовок `Server: Caddy`);
- «`api-gateway` не используется для `/health`» — **выполнен**: в `7-deploy/caddy/Caddyfile.prod` строки
  с прокси на `:8080` нет (проверка: `git show origin/main:7-deploy/caddy/Caddyfile.prod | grep -c 'reverse_proxy 127.0.0.1:8080'` → **0**);
- «проверки живости изнутри» — health-гейт APIM и проверки сервисов уже идут `podman exec`/внутри сети
  (`tools/check_apim_health.py`), публичный `/health` — только liveness края;
- «`public-probe` зелёный после изменения» — **#2 success**; откат — `sudo cp /etc/caddy/Caddyfile.bak-do-20261105-141603 /etc/caddy/Caddyfile && sudo systemctl reload caddy`.

**Порядок применения (как делалось):** бэкап → `cp` из репозитория → `caddy validate` → `systemctl reload caddy`
→ замер → **и только потом коммит**. Файл в репозитории = снятое с машины состояние (до правки в `origin`
лежал только старый tailnet-блок без `http://:8081` и без развилки на APIM — дрейф закрыт).
