# DO-003: VPS-1 — podman + .NET SDK + развёртывание 10 сервисов

- **Статус:** Закрыта (DevOps: 11 контейнеров + сеть xdiary + автодеплой 15 мин; см. примечание о стабильности)
- **Приоритет:** P0
- **Источник:** `04-architecture/vps-setup.md` (§2), ADR-009/010
- **Зависимости:** DO-001

## Задача
На VPS-1 (`ru-vps-msahost`) по памятке §2:
- Установить podman, podman-compose, git, .NET 8 SDK.
- `git clone` в `/opt/xdiary/`.
- `podman compose build && up -d` — поднять 10 микросервисов + шлюз (11 контейнеров).
- Логи в journald (`podman logs`).

## Критерии приёмки
- [ ] `podman ps` = 11 контейнеров (10 сервисов + шлюз).
- [ ] Образы собраны (Docker-образы уже есть в GHCR — можно `podman pull`).
- [ ] Сервисы коннектятся к БД (VPS-2 по приватной сети).
- [ ] rootless podman от пользователя `deploy`; лимиты `--memory 256m`, `--pids-limit`.
