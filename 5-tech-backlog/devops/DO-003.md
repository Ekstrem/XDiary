# DO-003: Сеть и TLS между ВМ

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** ADR-009
- **Зависимости:** DO-001

## Задача
Настроить сеть:
- PWA (телефон) → ВМ-1 (шлюз) по HTTPS.
- ВМ-1 ↔ ВМ-2 по внутренней сети (PostgreSQL:5432).

Выпустить/настроить TLS-сертификат на шлюзе (YARP). Для podman rootless на порту 443 — `CAP_NET_BIND_SERVICE` или высокий порт + проброс.

## Критерии приёмки
- [ ] PWA доступен по HTTPS через шлюз.
- [ ] ВМ-2 недоступна извне (только ВМ-1 по 5432).
- [ ] Firewall закрывает всё лишнее.
- [ ] TLS-сертификат валиден (или самоподписанный, осознанно).
