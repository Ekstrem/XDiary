# DO-001: Развернуть ВМ-1 (podman) и ВМ-2 (PostgreSQL)

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** ADR-009, `04-architecture/vm-sizing.md`
- **Зависимости:** —

## Задача
Поднять две ВМ по расчёту ресурсов:
- **ВМ-1 (podman):** 2 vCPU / 4 ГБ RAM / 40 ГБ диск.
- **ВМ-2 (PostgreSQL):** 2 vCPU / 2 ГБ RAM / 40 ГБ диск.

Установить на ВМ-1 podman (rootless), на ВМ-2 — PostgreSQL.

## Критерии приёмки
- [ ] Обе ВМ запущены, доступны по SSH.
- [ ] На ВМ-1 работает `podman` (rootless, без демона от root).
- [ ] На ВМ-2 установлен и запущен PostgreSQL.
- [ ] Ресурсы соответствуют `vm-sizing.md` (или обосновано отклонение).
