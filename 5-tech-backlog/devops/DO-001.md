# DO-001: Базовая настройка и безопасность VPS (Ubuntu 22.04)

- **Статус:** В работе
- **Приоритет:** P0
- **Источник:** `04-architecture/vps-setup.md` (§2.1, §4), ADR-009
- **Зависимости:** —

## Задача
Подготовить VPS по памятке архитектора (§2.1, §4):
- **VPS-1:** `ru-vps-msahost` (31.192.111.168) — приложения.
- **VPS-2:** PostgreSQL (данные; адрес/доступы — уточнить у PO).

Базовое: `apt update && full-upgrade`, создать пользователя `deploy`, SSH **только по ключам** (`PermitRootLogin no`, `PasswordAuthentication no`), `ufw` deny-by-default, `fail2ban`, `unattended-upgrades`.

## Критерии приёмки
- [ ] `ssh root@VPS` — отказано; вход только `deploy` по ключу.
- [ ] ufw: deny incoming, разрешены только 22 (и 443/80 на VPS-1).
- [ ] fail2ban + unattended-upgrades включены.
- [ ] Пароль (из чата) НЕ в git — репозиторий публичный; после настройки ключей пароль-вход отключить.

## Секреты
- SSH-пароль/ключ — передаётся исполнителю отдельно, **не коммитится**.
