# DO-006: Бэкапы PostgreSQL (cron + restore-тест)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** `04-architecture/vps-setup.md` (§3.2, §6)
- **Зависимости:** DO-002

## Задача
- Скрипт бэкапа (`pg_dumpall` или pgBackRest) в cron на VPS-2.
- Бэкапы на отдельный диск/том.
- Проверить восстановление (`pg_restore` в тестовую БД).

## Критерии приёмки
- [ ] Бэкап создаётся по расписанию (cron).
- [ ] `pg_restore` в тестовую БД проходит без ошибок.
- [ ] Бэкапы хранятся вне системного диска.
