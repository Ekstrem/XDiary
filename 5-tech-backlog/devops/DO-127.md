# DO-127 — откат образа падал на сравнении digest: `client` оставался снятым

- **Статус:** На проверке
- **Приоритет:** P0 (стенд без контейнера, прод-деплой красный)
- **Источник:** прогон `deploy` #2039: `xdiary-client не поднялся` -> «откат client не удался»
- **Зависимости:** нет
- **Проверяет:** @TL
- **На проверке с:** 2026-11-13
- **Исполняет:** @DO (зона `7-deploy/`)

## Дефект

`recreate-service.sh` сравнивал контроль подмены образа «как есть»:

```bash
[ "$last_tok" = "$IMAGE_OVERRIDE" ]
```

`podman` отдаёт ID в разных формах (`sha256:<64>`, `<64>`, короткий 12), плюс мог попасть
CR или пробел из `podman ps --format`. В логе #2039 значения выглядели одинаково, а сравнение
падало. Следствие: при неудачном подъёме `client` откат не срабатывал и контейнер оставался
снятым — на VPS-2 было 12 контейнеров вместо 13.

## Правка

Нормализация обеих сторон (убрать CR/пробелы, срезать `sha256:` и `@`) и сравнение по 12 hex:
podman принимает короткий ID. Диагностика печатает hex с обеих сторон, форма перестаёт быть
загадкой.

## Проверка

- `client` восстановлен на VPS-2: `sudo podman ps` -> 13 контейнеров, `xdiary-client Up 14 seconds`,
  `curl 127.0.0.1:8080/health` -> 200;
- `bash -n` локально на Windows не показателен (flaky), проверку даёт `CI guards`.

## Результат

Сравнение устойчиво к форме ID; откат больше не падает на визуально равных строках.
