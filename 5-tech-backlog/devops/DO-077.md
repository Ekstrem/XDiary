## Задача

На проде публичный путь — `Funnel → Caddy:8081 → (health → YARP | остальное → APIM 18082)`;
на **тесте** APIM не развёрнут (`18082` не слушает), и публичный вход идёт в YARP.
Из-за этого `(ii-a)`/`(ii-c)` на тесте измеряют **другой объект**: неизвестный путь на проде → `404` + `X-Gravitee-*`,
на тесте → `401` + `Server: Kestrel`.

Нужен симметричный контур, чтобы «зелено на тесте» означало то же, что «зелено на проде».

## Критерии приёмки

- `podman ps` на тесте: `apim-management`, `apim-gateway`, `apim-mongo` — `running`, `restarts` не растёт 30 с;
- `ss -ltn` на тесте: `127.0.0.1:18082` слушает;
- импортированы **12 API** (как на проде, `DO-056`), `check_apim_drift.py` → расхождений 0;
- публичный вход теста: `/api/v1/catalog` → `401` **с** `X-Gravitee-*`; неизвестный путь → **404**;
  `/internal/**` → **404**; `/health` → `200` без Gravitee;
- `(ii-a)` и `(ii-c)` на тесте перемерены **после** смены пути, `where=` называет тестовый вход, `via=gravitee` в квитанции;
- откат (вернуть вход на YARP) проверен исполнением в обе стороны;
- ранбук `7-deploy/runbooks/apim.md` дополнен разделом «тестовый контур» в том же коммите.

## Критерий одной командой (сформулирован @TE, `04:24`)

```
python 9-tests/scripts/check_apim_auth.py --all --probe-entry \
  --base https://xdiary-vps2.taile0b6ee.ts.net \
  --where "Funnel->Caddy->APIM, снаружи"
```

Ожидание после поднятия APIM на тесте:

- `via=gravitee` в квитанции `(ii-a)`;
- `ИТОГ: (ii-a) PASS 74/74 · (ii-c) PASS 2/2 · 74+2=76 из 80 · rc=0`;
- проба входа: несуществующий путь → **404**, тело `No context-path matches the request URI.` (~40 Б);
  сейчас на тесте — `401` `Unauthorized` (~12 Б) и `Server: Kestrel`.

**Три независимых признака** (код, тело, `via=`) — поэтому «подняли APIM» нельзя зачесть по одному из них.

## Результат (частичный, 2026-11-05)

Сделано на тестовом контуре (VPS-2), факты проверяемы:

1. **RAM была блокером, а не процедура:** на dev **1963 МБ** всего, свободно **87 МБ**, `swap = 0`.
   APIM нужно ≈1.26 ГБ RSS (по замеру прода). Добавлен **swap 2 ГБ** (`/swapfile`, закреплён в
   `/etc/fstab`, обратимо: `swapoff -a` + `rm`). После запуска: RAM свободно 322 МБ, swap занято 966 МБ.
2. **CNI был второй ловушкой** (описана в шапке `up.sh` как проблема №4): `podman network create apim`
   на rootful podman пишет `/etc/cni/net.d/apim.conflist` с `cniVersion: 1.0.0` + плагин `firewall`,
   который понимает только `0.4.0` → контейнеры создаются и **не стартуют**
   (`CNI network "apim" not found`). Исправлено: удалён битый конфиг, записан рабочий
   `/etc/cni/net.d/10-apim.conflist` (`0.4.0`, bridge `cni-podman30`, subnet `10.89.30.0/24`).
3. **Стек поднят:** `xdiary-apim-gateway|management|mongo|ui` — все `running`, `restarts=0`;
   `127.0.0.1:18082` (gateway) и `127.0.0.1:18084` (ui) слушают; management root
   `/management/v2/` → **200**.
4. **Заблокировано на install:** `GET /management/v2/organizations` пуст,
   `POST /management/v2/organizations` (`admin:admin`) → **500**; в логах пусто. Значит API-импорт
   (`import.sh`) запускать нечем — 12 API импортировать пока нельзя.
5. **Не сделано и не может быть сделано без install:** импорт 12 API, `check_apim_drift` = 0,
   переключение публичного входа теста на APIM, перемер `(ii-a)`/`(ii-c)` с `via=gravitee`.
   На проде этот шаг исторически проходил через консоль — то есть разблокировка не «ещё код»,
   а доступ к консоли.

## План (решение B + «APIM везде»)

1. **Повторить headless-install** — на dev уже добавлен **swap 2 ГБ**; `POST /management/v2/organizations` → `500`
   мог быть следствием нехватки памяти (было 87 МБ свободных), а не только quirk Gravitee.
2. **Если снова `500`** — владелец даёт туннель `ssh -L 18084:127.0.0.1:18084 <dev>` и проходит install
   в консоли (первый админ/организация). Дальше — снова headless.
3. **Импорт 12 API** той же последовательностью, что на проде (`DO-056`, `7-deploy/apim/import.sh`).
4. **Публичный вход теста** по образцу прода: Caddy на отдельном порту (`:8081`) →
   `Funnel → Caddy → (health → YARP | остальное → APIM)`.
5. **Перемер, не перенос:** `(ii-a)` и `(ii-c)` на тесте заново.

**Критерий готовности:** `check_apim_auth.py --all --probe-entry --base https://xdiary-vps2.taile0b6ee.ts.net`
