# DO-008: Pages — деплоить новый фронт (`8-front/`) вместо `app/`

- **Статус:** Закрыта (DevOps: `pages.yml` → `8-front/`; `app/` оставлен как архив)
- **Приоритет:** P0
- **Источник:** FE-001 (`8-front/`), `.github/workflows/pages.yml`
- **Зависимости:** FE-001

## Проблема

`pages.yml` публикует `path: "app"` — старый фронт на IndexedDB. Новый API-фронт живёт в `8-front/`. Пока деплой не переключён, PWA на GitHub Pages остаётся старой версией, и работа FE-001 в прод не попадает.

## Задача

После завершения FE-001 переключить деплой Pages на `8-front/` (или на собранный артефакт).

## Критерии приёмки
- [ ] `pages.yml` деплоит `8-front/` (или собранный артефакт).
- [ ] PWA на `https://ekstrem.github.io/XDiary/` открывается и обращается к API (при заданном base).
- [ ] Старый `app/` — осознанно удалён или оставлен как архив (решить).
