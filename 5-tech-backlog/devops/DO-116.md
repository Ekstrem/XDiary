# DO-116: `guard-secrets` сканирует только изменённые файлы — уже лежащая утечка не ловится никогда

- **Статус:** ToDo
- **Приоритет:** P1 (гейт есть, но состояние репозитория им не проверяется: утечка живёт в файле, который никто не менял)
- **Источник:** @TL `2026-11-11 17:30` (прогон на `origin`: `check_secrets` → `утечек 1`, `rc=1`, адрес `5-tech-backlog/chat/be.md:233`) + механика CI (`ci-guards.yml:320`: `--range "$range"` — только изменённые файлы)
- **Зависимости:** зачистка строки владельцем outbox (`@BE`) — до неё полный скан будет красным по факту, и это правильно
- **Проверяет:** @TL (саморевью запрещено: автор — @DO, домен — инфраструктура)

## Задача

`ci-guards.yml` вызывает `tools/check_secrets.py` только с `--range` (`:320`), то есть проверяются **изменённые** файлы. Следствие: строка с секретом, попавшая в файл раньше и с тех пор не тронутая, не проверяется **никогда**. Ровно это и произошло: утечка в `chat/be.md:233` (правило `assign:password`, значение скрыто) не ловится ни одним прогоном, а полный локальный прогон даёт `rc=1`.

Нужно: полный скан как **отдельный** режим, не блокирующий обычные пуши:
1. job по `schedule` (например, ежедневно) — `python tools/check_secrets.py --config loop.config.json` **без** `--range`;
2. в квитанции печатать **сколько файлов проверено** и **сколько утечек** (иначе «зелёный» неотличим от «ничего не смотрел»);
3. `--range` оставить как есть для пушей: он дешёвый и ловит новое.

## Критерии приёмки

- [ ] В `.github/workflows/` есть job с `schedule:`, запускающий полный скан (без `--range`).
- [ ] Квитанция печатает `файлов проверено: N` и `утечек: M` — на текущем `origin` это **`утечек: 1`** и адрес `chat/be.md:233` (пока строка не зачищена).
- [ ] §5.4 в обе стороны: **дефект** — подложенный секрет в файле, который не менялся в диапазоне, → scheduled-скан красный (`rc=1`), `--range` по тому же пушу зелёный (это и есть доказательство разницы); **норма** — после зачистки полный скан `rc=0`.
- [ ] Job не блокирует пуши (не в required checks) и не создаёт ложного «всё чисто»: при `rc=2` (не измерено) — отдельный исход, не «зелёный».
