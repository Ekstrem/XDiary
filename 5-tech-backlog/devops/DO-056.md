- **Статус:** ToDo
- **Приоритет:** P2 (после P0 по продукту; начинать после BE-050)
- **Источник:** ADR-023 пересмотрен **C → B** решением владельца (AR 2026-11-09 00:38: «владелец решил ADR-023 → B (полный APIM, Gravitee): OpenAPI-контракты импортируются в APIM, источник правды»); условие @LM 01:37 («repo → APIM»: спека в git, APIM — рантайм, иначе экспорт+drift-check)
- **Зависимости:** BE-050 (OpenAPI генерируется из кода и коммитится — **остаётся обязательным**, APIM потребляет эти спеки), DO-052 (path-based деплой), ADR-007 (YARP), ADR-013
- **Проверяет:** @TL (TechLead) — саморевью запрещено: автор @DO

## Задача (зона @DO, `.github/`, `7-deploy/`, `tools/`)

1. **Импорт вместо ручного авторинга:** OpenAPI-спеки из `openapi/*.json` (артефакт BE-050) импортируются в Gravitee **идемпотентно по тегу** (`single-<SHA>`), а не вручную в UI и не в `latest`.
2. **Drift-check (обязателен, это ядро решения):** ежедневная сверка «экспорт APIM ↔ git»; расхождение → **красный гейт/алерт**. Ручные правки в APIM запрещены, кроме аварийного хотфикса с обязательным обратным экспортом в git в тот же день.
3. **Локальная разработка без APIM:** профиль dev не требует APIM (сервисы поднимаются как сейчас) — иначе новый компонент остановит работу всех ролей.
4. **Breaking-change детектор** (перенос из прежней редакции): сравнение спеки с версией в `main` (`oasdiff`, версия пинована), нормализация формата, удаление поля/смена типа/новый обязательный параметр → failure с требованием `/v2`.
5. **Версия Gravitee пинована** и записана в задаче; **лицензия проверена** (LM назвал риск: лицензия Gravitee) и зафиксирована в ADR/ранбуке.
6. **Smoke через APIM:** отдельный прогон, который проверяет путь «клиент → APIM → сервис», а не только прямой порт.

## Критерии приёмки
- [ ] Спека из git импортируется в APIM по тегу; повторный импорт идемпотентен (не создаёт дублей).
- [ ] Ручная правка в APIM ловится drift-check в течение суток (негативный контроль: изменил в APIM → красный).
- [ ] Ломающее изменение спеки → failure с перечнем; аддитивное → success.
- [ ] `dev`-профиль поднимается **без** APIM (проверено прогоном).
- [ ] Версия Gravitee и решение по лицензии зафиксированы в ADR-023/ранбуке.
- [ ] Smoke «через APIM» зелёный и покрывает хотя бы один реальный маршрут (`/api/v1/clients`).
