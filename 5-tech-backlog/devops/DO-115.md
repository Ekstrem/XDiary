## Задача

`tools/check_canon.py` берёт файлы из `git ls-files` (`_git_tracked`, `:33-54`) — это уже правильно. `glob` работает только как fallback, когда `root` не git-корень (`_walk_files`, `:57-64`), и в этом режиме попадает во вложенные копии/ворктри (`origin/main/`, `.tmp-check-origin/`), считая один маркер несколько раз.

Нужно: fallback не выходит за пределы одного репозитория — пропускать каталоги с `.git`; либо (предпочтительно) при `rels is None` возвращать `rc=2` «не измерено: root не git-корень».

## Критерии приёмки

- [x] Вложенная копия больше не считается: обход дерева **не заходит** в каталоги с `.git` (граница репозитория) — проверено кейсом selftest (2 файла с одним маркером, один из них внутри `origin/main/` с `.git` → **1**).
- [x] §5.4 в обе стороны: **норма** — git-корень, `rc=0`, `источник файлов: git ls-files (708 шт.)`, `ok: canon:receipt-v1 — ./04-architecture/ADL/adr-026.md`; **дефект** — `--root` вне git-корня → **`rc=2`** с `::error:: … НЕ ИЗМЕРЕНО — root не git-корень` (раньше в этом месте считались копии и выходило «3 раза»).
- [x] В квитанции печатается **чем** считали: `источник файлов: git ls-files` / `НЕ ИЗМЕРЕНО: root не git-корень` / `обход дерева (selftest-only)`.
- [x] `--selftest` — **1/0/2/1** (ждём 1/0/2/1): дубль → 1, один маркер → 0, **не git-корень → 2**, **вложенный `.git` не учитывается → 1**.
