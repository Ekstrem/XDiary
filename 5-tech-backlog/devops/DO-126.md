## Задача

1. Вход на VPS-1 и VPS-2 — только по SSH-ключу (`PasswordAuthentication no`, `PermitRootLogin no`).
2. Порт SSH — не 22, целевой **8237**.
3. Проверить статистику попыток входа (в т.ч. до отключения паролей) и отсутствие компрометации.
4. CI, скрипты и ранбуки — на новый порт (иначе деплой и смоки отваливаются).
5. Приватные ключи — только локально, не в репозитории.

## Сделано (проверено снаружи, не по конфигу)

### VPS-1 `31.192.111.168` (prod, вход `deploy`)

- `sshd -T`: `port 8237`, `passwordauthentication no`, `permitrootlogin no`, `pubkeyauthentication yes`.
- Слушает **только** 8237; `ufw`: только `8237/tcp`.
- Вход по ключу по 8237 — успешен; попытка пароля → `Permission denied (publickey)`.
- Причина, почему пароль был разрешён: drop-in `/etc/ssh/sshd_config.d/50-cloud-init.conf` (`PasswordAuthentication yes`) перебивал основной конфиг.
- Бэкап: `/root/ssh-backup/sshd_config.<ts>`, `sshd_config.d.<ts>`.

### VPS-2 `77.91.73.67` (dev, вход `ubuntu`)

- То же: `port 8237`, пароли `no`, root `no`; `ufw` — только `8237/tcp`; вход по ключу проверен.
- Причина: drop-in `00-custom-root.conf` (`PermitRootLogin yes`, `PasswordAuthentication yes`).
- `fail2ban`: **inactive** (не установлен) — рекомендация ниже.
