# DO-005: Секреты (.env) + podman rootless hardening

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** `04-architecture/vps-setup.md` (§2.2, §4.5, §4.6)
- **Зависимости:** DO-003

## Задача
- `/opt/xdiary/secrets/.env`: Garmin key, JWT secret, пароли БД — `chmod 600`, **не в git**.
- Переменные в контейнеры через `env_file` (не в `compose.yml`).
- podman rootless: `CAP_NET_BIND_SERVICE` или caddy/nginx на 443 → шлюз на 8080.
- `read_only: true` (где можно).

## Критерии приёмки
- [ ] `.env` отсутствует в git (проверить `git status` / `.gitignore`).
- [ ] Пароли БД не в `compose.yml` (только `env_file`).
- [ ] Контейнеры от непривилегированного `deploy`.
- [ ] JWT-секрет совпадает с `privacy` (HS256) и шлюзом.
