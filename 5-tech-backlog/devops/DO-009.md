# DO-009: CI для тестов тестировщика (`9-tests/`)

- **Статус:** Закрыта (DevOps: `ci-tests.yml` — `dotnet test` по `9-tests/**/*.IntegrationTests.csproj` на ubuntu-latest)
- **Приоритет:** P1
- **Источник:** TE-001/TE-002 (тесты в `9-tests/`), блокер тестировщика (chat/te.md)
- **Зависимости:** —

## Проблема
CI (`ci-*.yml`) запускает тесты только из `6-msa/*/src/*.IntegrationTests`. Тесты тестировщика лежат в `9-tests/` и в CI не попадают → TE-001..TE-006 нельзя проверить автоматически.

## Задача
Добавить workflow для `9-tests` (dotnet test по всем csproj в `9-tests`), запуск на push/PR.

## Критерии приёмки
- [ ] Workflow (например, `ci-tests.yml`) собирает и прогоняет `9-tests/**/*.csproj` на ubuntu-latest.
- [ ] Прогон `dotnet test` зелёный (или падения видны в CI).
- [ ] Не ломает существующие `ci-*.yml`.
