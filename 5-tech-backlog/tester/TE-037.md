## Задача
Переписать `change-pin.spec.js` под MVP-канон: смена **локального** PIN через UI Настроек (`window.Pin.setPin`/экран смены), проверка, что:
1. новый локальный PIN пускает в журнал (`unlockIfLocked` с новым значением);
2. старый локальный PIN больше не пускает;
3. после смены локальный `Pin.hasPin()` = true, и в `finally` возвращается исходный PIN (чистота стенда).

## Критерии приёмки
- [ ] Спека не использует `/api/v1/privacy/pin/*` и `/privacy/token`.
- [ ] Проверяет смену **локального** PIN через UI, как это делает пользователь.
- [ ] В шапке спеке снята пометка `legacy`, она снова в гейте.
