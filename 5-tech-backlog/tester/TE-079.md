# TE-079. Гейт на симметрию event-sourcing: писатель `ChangedValueObjectsJson` обязан иметь конвертер

- **Статус:** На проверке
- **Проверяет:** @TL
- **Чем проверяется:** `python 9-tests/scripts/check_e2e_eventsourcing_contract.py --selftest  (и прогон на `origin`)`
- **Роль:** @TE
- **Источник:** прогоны #1638/#1639 (`smoke-front`), дефект найден чтением кода в разделе 11 отчёта
  `9-tests/reports/front-e2e-run-765-triage.md`

## Проблема

`POST /journal/records/{id}/when` стабильно отдавал `404` даже на образе, где есть fallback в
`EnsureOwns`. Причина: в `BC-Journal` событие писалось без `$type`-дискриминанта —

```csharp
// JournalEventConsumer.cs:64 (origin на момент разбора)
ChangedValueObjectsJson = JsonSerializer.Serialize(domainEvent.ChangedValueObjects),
```

— и в `BC-Journal` не было `IValueObjectJsonConverter` (в `BC-Partners` он есть:
`PartnerEventConsumer.cs:47-50`). Поэтому `JournalCommandRepository.GetById` (`:15` → `LastOrDefault()`)
не мог реконструировать `IValueObject` и возвращал `null`; fallback в `EnsureOwns` тоже получал `null` →
`NotFound` → `404`. Read-модель при этом работала, поэтому журнал открывался, а любая модификация — нет.

## Что сделано (моя зона — измерение, а не правка сервисов)

Гейт `9-tests/scripts/check_e2e_eventsourcing_contract.py`:

- находит все файлы в `6-msa/**`, где есть `ChangedValueObjectsJson = JsonSerializer.Serialize(...)`;
- требует, чтобы в тех же 30 строках выше упоминался `IValueObjectJsonConverter` или `Converters.Add`;
- иначе `rc=1` с путём и номером строки;
- `KNOWN_GAPS` — только для асимметрии, **признанной владельцем зоны**; такие случаи печатаются в квитанции
  отдельным числом (`известных исключений: 1`), а не скрываются.

Первый же прогон гейта на `origin` показал ту самую асимметрию (журнал), то есть гейт **не пустой**:
`писателей 2 | без конвертера: 0 | известных исключений: 1`. `--selftest` **4/4** (Partners зелёный,
Journal красный, файл без событий не считается, текст квитанции).
