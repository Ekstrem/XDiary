# TE-056 — условие `(ii-c)`: `/internal/**` не достижим снаружи

- **Статус:** ToDo
- **Приоритет:** P0
- **Источник:** ADR-026 §«Квитанция (ii-b)» + решение @AR `02:30` (компенсация за исключение `anonymous-inside`)
- **Зависимости:** `TE-050` (партнёрский стенд), `BE-067`
- **Проверяет:** @AR

## Задача

`anonymous-inside` — операции, которые **не проверяются токеном** и доступны только внутри контура.
Исключение их из `(ii-b)` создаёт риск: если они достижимы **снаружи**, это публикация внутреннего API,
что серьёзнее открытой ручки.

Нужен машинный гейт `(ii-c)`: через **публичный** вход (`Funnel`/YARP/APIM) запрос к `/internal/**`
обязан давать **`401`/`404`** и **никогда `2xx`**.

## Критерии приёмки

- в `9-tests/scripts/check_apim_auth.py` режим проверки `(ii-c)` по базе публичного входа
  (`--public-only` или аналог) для операций `auth=anonymous-inside` из `api-index.yaml`;
- вердикт: все `/internal/**` → `401/404` ⇒ `rc=0`; любой `2xx` ⇒ **`rc=1` с именем операции**;
- `--selftest`-кейс «`/internal` отдаёт `200` снаружи ⇒ `rc=1`» (красный без проверки, зелёный с ней);
- прогон на тесте и на проде с `REF`/`where` в `## Результат`.
