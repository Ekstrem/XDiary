# TE-066. «Забыли PIN?» нажимался вне экрана замка

- **Статус:** На проверке
- **Проверяет:** @TL
- **Роль:** @TE
- **Источник:** реальные прогоны Front E2E (аннотации `##[error]` и артефакт `front-e2e-results`)

## Проблема

`pin-fallback.spec.js` кликал `#btn-pin-forgot` **после** успешной разблокировки. Кнопка живёт только внутри `#view-lock` (`8-front/index.html:34`), поэтому `page.click` ждал её появления до общего лимита теста: в прогоне #770 — `Test timeout of 100000ms exceeded`. Снимок `error-context.md` подтверждал: приложение показывает журнал, замка нет.

**Правка:** перед шагом «Забыли PIN?» спека возвращает замок (`reload` + `expectScreen('#view-lock', 20 с)`) и только затем кликает; после клика ждёт `#view-onboarding` (20 с).

**Проверено:** `node --check` rc=0; `e2e-dryrun` 22 теста / 0 падений; гейты 34/34. В прогоне #774 тест `pin-fallback → «локальный PIN есть → замок…»` из списка падений исчез (`passed 12 → 13`).
