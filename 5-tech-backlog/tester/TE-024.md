# TE-024: Есть ли онбординг/идентификация клиента?

- **Статус:** Открыта
- **Приоритет:** P1 (PO: «ощущение, что онбординга/идентификации нет»)
- **Источник:** PO 2026-11-03; ADR-018 (нет изоляции по пользователям — by design)
- **Зависимости:** —

## Задача
Проверить по коду и на живом dev-стенде, есть ли **онбординг клиента (идентификация)** — и что видит новый пользователь:

1. **Первый запуск на новом устройстве:** что показывается (экран PIN? device-токен?) и кто «я» в записях?
2. **Идентификация:** как приложение понимает, кто пользователь/партнёр — есть ли профиль «я» (имя, пол), приглашение партнёра, выбор «кто из пары сейчас пишет»?
3. **Сверка с ADR-018:** там зафиксировано «JWT/device-токен идентифицирует инстанс, а не юзера», `Partner` — доменные данные. Это осознанный дизайн или дыра в продукте?
4. **Что именно ломается:** сценарий «поставил приложение, одна пара, два устройства» — можно ли пройти без ручных костылей?

## Критерии приёмки
- [ ] Вердикт: онбординга нет / есть частично / есть — с указанием файлов/экранов.
- [ ] Если нет — шаги (что видит пользователь на новом устройстве) + лог/скрин.
- [ ] Передать @TL → @AR: это баг, продуктовая дыра или by design (ссылка на ADR-018).
