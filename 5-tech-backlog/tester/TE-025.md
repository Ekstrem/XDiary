# TE-025: E2E — онбординг «кто я» + опциональный PIN (Фаза 1)

- **Статус:** Открыта
- **Приоритет:** P1 (Фаза 1)
- **Источник:** AR-004 → P1 (@AR 2026-11-04 00:00); ADR-021
- **Зависимости:** FE-018, BE-028

## Задача
Живой E2E (`front-e2e`, dev):
1. Новый чистый контекст → онбординг «кто ты» → выбор/создание партнёра как «я» → журнал.
2. PIN **не задан** → всё работает (device-токен).
3. PIN задан → смена/снятие (регресс FE-009/FE-011).
4. «Я» сохраняется между перезагрузками (сервер, не локально).
