# TE-025: E2E — онбординг «кто я» + опциональный PIN (Фаза 1)

- **Статус:** Открыта
- **Приоритет:** P1 (Фаза 1)
- **Источник:** AR-004 → P1 (@AR 2026-11-04 00:00); ADR-021
- **Зависимости:** FE-018, BE-028

## Задача
Живой E2E (`front-e2e`, dev). **Новый scope** по пересмотренному ADR-021 (@TL 2026-11-04 04:45):
1. **Телефон → SMS OTP** → верификация → **JWT клиента** (JWT = пользователь, не инстанс).
2. **`link-partner`** — привязка партнёра-«я» к клиенту.
3. «Я» определяется по **`Partner.clientId`** (сервер), а не по `self`-флагу и не из localStorage.
4. «Я» переживает перезагрузку и новое устройство.
5. PIN остаётся **опциональным** — не блокирует вход.

## Критерии приёмки
- [ ] Телефон → OTP → JWT клиента → `link-partner` → «я» по `clientId`.
- [ ] «Я» после reload берётся с сервера.
- [ ] PIN опционален (вход без него работает).
- [ ] CI `front-e2e` зелёный.
- [ ] Уборка в `finally`.
