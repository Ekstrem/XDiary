# TE-007: E2E — аутентификация (логин → JWT → refresh)

- **Статус:** В работе
- **Приоритет:** P1
- **Источник:** ADR-008, FE-002, BE-010
- **Зависимости:** FE-002, BE-010, BE-014
- **Прогресс:** E2E-тесты в `9-tests/E2E/E2E.Tests` (login → access+refresh; аноним → 401; logout → 401), env-gated (`XDIARY_E2E_BASE_URL`).
- **Блокер:** (1) `POST /api/v1/privacy/token` (JWT-выдача) не реализован — ждёт **BE-014**; (2) нет доступа к стенду из среды тестировщика (нужен Tailscale/локальный стек).

## Задача
Сквозной сценарий: PWA → шлюз → privacy. Логин, получение access+refresh, refresh при истечении, logout.

## Критерии приёмки
- [ ] Логин → access + refresh токены.
- [ ] Refresh без потери сессии (при 401).
- [ ] Logout очищает токены; после — аноним отклоняется (401).
