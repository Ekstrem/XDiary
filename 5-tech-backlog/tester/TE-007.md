# TE-007: E2E — аутентификация (логин → JWT → refresh)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** ADR-008, FE-002, BE-010
- **Зависимости:** FE-002, BE-010

## Задача
Сквозной сценарий: PWA → шлюз → privacy. Логин, получение access+refresh, refresh при истечении, logout.

## Критерии приёмки
- [ ] Логин → access + refresh токены.
- [ ] Refresh без потери сессии (при 401).
- [ ] Logout очищает токены; после — аноним отклоняется (401).
