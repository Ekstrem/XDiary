# TE-014: E2E — создание записи журнала через визард

- **Статус:** Открыта
- **Приоритет:** P0 (ядро приложения не покрыто E2E)
- **Источник:** @FE 18:02 (не покрыто); PO 18:10 — «всё надо покрыть»
- **Зависимости:** —

## Задача
Живой E2E (`front-e2e`, реальный шлюз, PIN): открыть визард → выбрать партнёра → аксессуар/контрацепцию → сохранить запись → проверить через API, что запись появилась в журнале → удалить созданное в `finally`.

## Критерии приёмки
- [ ] Сценарий зелёный в CI (`front-e2e`).
- [ ] Созданное удаляется в `finally` (стенд не засоряется).
- [ ] Проверка через API, не по UI-тексту.
