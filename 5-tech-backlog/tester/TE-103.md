## Измерено локально (`dotnet 8.0.419`, сборка дважды)

```
dotnet build 6-msa/ApiGateway.Tests/ApiGateway.Tests/ApiGateway.Tests.csproj
→ rc=1   (воспроизведено 2/2)
GatewayRoutesTests.cs(12,91): error CS7036: Отсутствует аргумент, соответствующий требуемому параметру
GatewayRoutesTests.cs(20,93): error CS7036: то же
```

Причина: сигнатура изменилась — `6-msa/ApiGateway/Auth/GatewayRoutes.cs:12`:
`public static bool IsAnonymous(string method, string path)`, а тест зовёт `GatewayRoutes.IsAnonymous(path)`.

То есть `dotnet test` на этом проекте не доходит до тестов вовсе: падает **сборка**.

## Почему это не «мелочь в тесте»

Анонимность в шлюзе теперь зависит от **пары** «метод + путь» (ADR-026: анонимны только 4 маршрута, и `GET /clients`
с токеном — `405`). Тест, который проверяет один путь без метода, эту семантику выразить не может — он должен
проверять пары. Иначе следующая правка матрицы пройдёт незамеченной.
