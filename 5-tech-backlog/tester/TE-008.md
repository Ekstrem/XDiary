# TE-008: E2E — журнал (создание → чтение записи)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** FE-001, BE-002, BE-012, US-01..09
- **Зависимости:** FE-001, BE-002, BE-012

## Задача
Сквозной сценарий: логин → создание записи через визард (PWA → шлюз → journal) → чтение журнала и детали.

## Критерии приёмки
- [ ] Запись создаётся и видна в журнале.
- [ ] Деталь записи открывается (срез соматики).
- [ ] Падение любого звена даёт понятную ошибку.
