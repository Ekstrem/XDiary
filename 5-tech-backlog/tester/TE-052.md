# TE-052 — контрактный тест владения партнёром (`PartnerOwnedByClient`): чужой `id` → 403

- **Статус:** Идея
- **Приоритет:** P2 (безопасность; дефект подтверждён в коде)
- **Источник:** @AR 2026-11-14 36:30 (`BC-Partners/02` §4 `PartnerOwnedByClient` + `ForeignIdIsNotNotFound`, ADR-020/ADR-026); задача реализации — @BE (`BE-PartnerOwnership`)
- **Зависимости:** реализация проверки владельца в `BC-Partners` (`GetPartnerByIdQuery` + хендлеры + `Forbid()`)
- **Владелец кода:** @BE (папка `6-msa/BC-Partners/src/Partners.ApiTests` — зона @BE по ADR-028 ред. 3)
- **Владелец спецификации:** @TE (этот файл)

## Задача

Дать @BE **готовый** контрактный тест на владение партнёром, чтобы правка кода и тест появились одним коммитом.
Карточка создана в `tester/`, потому что `6-msa/**` — зона @BE (ADR-028 ред. 3, `AGENTS.md` §1): тест
применяет @BE, @TE отвечает за спецификацию и за то, чтобы тест не был «зелёным на пустоте».

**Дефект подтверждён @TE независимо** (`REF=9e70728a`, чтение кода, не отчёт):

| Факт | Где | Команда проверки |
|---|---|---|
| `GetPartnerByIdQuery(Guid AggregateId)` — **без** `clientId` | `6-msa/BC-Partners/src/Partners.Application/PartnerQueries.cs` | `git show <REF>:6-msa/BC-Partners/src/Partners.Application/PartnerQueries.cs` |
| `Rename/UpdateProfile/Remove/LinkClient/UnlinkClient` грузят агрегат по `id` **без** сравнения с владельцем | `Partners.Application/PartnerHandlers.cs` | то же |
| в контроллере **0** `Forbid()`; `Get` → `NotFound()` только при `null` | `Partners.Api/Controllers/PartnersController.cs` (49 строк) | `git show <REF>:…/PartnersController.cs` |
| `List` — фильтруется по `ClientId` (тут всё верно) | `PartnerQueries.cs` (`ListPartnersQuery(Guid ClientId)`) | то же |

Следствие: **любой аутентифицированный клиент читает и меняет чужого партнёра**. В Client и Journal проверка
владельца есть (`EnsureOwns`/`Forbid`), в Partners — нет.

## Критерии приёмки

1. Тест лежит в `6-msa/BC-Partners/src/Partners.ApiTests/PartnerOwnershipTests.cs` и **собирается** (`dotnet build` → `rc=0`).
2. Пять проверок: `GET /partners/{id}`, `POST /{id}/name`, `POST /{id}/profile`, `POST /{id}/remove`,
   `POST /{id}/link-client` — из сессии **B** на партнёра, созданного **A** → **403** (не 404: `ForeignIdIsNotNotFound`).
3. Негативный контроль: после каждой попытки B данные A **не изменились** (повторный `GET` из сессии A отдаёт
   прежнее имя/профиль, партнёр не удалён, `ClientId` не перепривязан).
4. Пока фикс не выкачен — тесты **не падают**, а пропускаются по **внешнему** признаку
   `XDIARY_PARTNER_OWNERSHIP=1` (env; не по наблюдаемому поведению — иначе тест сам себя отключает при регрессии).
5. После выкатки: `XDIARY_PARTNER_OWNERSHIP=1` в CI, тесты выполняются строго, `[pending:…]` из имён убирается.

## Готовый код (передать @BE)

```csharp
// TE-052 / BC-Partners/02 §4 PartnerOwnedByClient. Владелец кода — @BE.
// Пока фикс не выкачен, тесты пропускаются по ВНЕШНЕМУ признаку XDIARY_PARTNER_OWNERSHIP=1.
using System.Net;
using System.Net.Http.Json;
using System.Text.Json;
using Xunit;

namespace XDiary.Tests.Partners;

public class PartnerOwnershipTests
{
    private static bool Enabled =>
        Environment.GetEnvironmentVariable("XDIARY_PARTNER_OWNERSHIP") == "1";

    /// <summary>Сессия отдельного клиента: регистрация → логин. Два независимых пользователя.</summary>
    private static async Task<HttpClient> SessionAsync(string suffix)
    {
        var c = new HttpClient { BaseAddress = new Uri(Environment.GetEnvironmentVariable("XDIARY_E2E_BASE_URL")
            ?? throw new InvalidOperationException("XDIARY_E2E_BASE_URL не задан")) };
        var email = $"owner-{suffix}-{Guid.NewGuid():N}@example.test";
        var reg = await c.PostAsJsonAsync("api/v1/auth/register",
            new { email, password = "Passw0rd!123", displayName = $"Owner {suffix}" });
        Assert.True(reg.IsSuccessStatusCode, $"register: {reg.StatusCode}");
        var login = await c.PostAsJsonAsync("api/v1/auth/login", new { email, password = "Passw0rd!123" });
        Assert.True(login.IsSuccessStatusCode, $"login: {login.StatusCode}");
        using var doc = JsonDocument.Parse(await login.Content.ReadAsStringAsync());
        var token = doc.RootElement.GetProperty("accessToken").GetString();
        c.DefaultRequestHeaders.Authorization = new("Bearer", token);
        return c;
    }

    private static async Task<Guid> CreatePartnerAsync(HttpClient c, string name)
    {
        var r = await c.PostAsJsonAsync("api/v1/partners", new { name });
        Assert.Equal(HttpStatusCode.OK, r.StatusCode);
        using var doc = JsonDocument.Parse(await r.Content.ReadAsStringAsync());
        return doc.RootElement.GetProperty("id").GetGuid();
    }

    [Fact]
    public async Task ForeignPartner_Get_Forbidden()
    {
        if (!Enabled) return; // pending:BE-PartnerOwnership (внешний признак, не поведение)
        var a = await SessionAsync("a");
        var b = await SessionAsync("b");
        var id = await CreatePartnerAsync(a, "A-partner");

        Assert.Equal(HttpStatusCode.Forbidden, (await b.GetAsync($"api/v1/partners/{id}")).StatusCode);
        Assert.Equal(HttpStatusCode.OK, (await a.GetAsync($"api/v1/partners/{id}")).StatusCode);
    }

    [Fact]
    public async Task ForeignPartner_Rename_Forbidden_AndUnchanged()
    {
        if (!Enabled) return;
        var a = await SessionAsync("a");
        var b = await SessionAsync("b");
        var id = await CreatePartnerAsync(a, "A-name");

        var r = await b.PostAsJsonAsync($"api/v1/partners/{id}/name", new { name = "hacked" });
        Assert.Equal(HttpStatusCode.Forbidden, r.StatusCode);

        var after = await a.GetAsync($"api/v1/partners/{id}");
        using var doc = JsonDocument.Parse(await after.Content.ReadAsStringAsync());
        Assert.Equal("A-name", doc.RootElement.GetProperty("name").GetString());
    }

    [Fact]
    public async Task ForeignPartner_Remove_Forbidden_AndStillExists()
    {
        if (!Enabled) return;
        var a = await SessionAsync("a");
        var b = await SessionAsync("b");
        var id = await CreatePartnerAsync(a, "A-keep");

        Assert.Equal(HttpStatusCode.Forbidden, (await b.PostAsync($"api/v1/partners/{id}/remove", null)).StatusCode);
        Assert.Equal(HttpStatusCode.OK, (await a.GetAsync($"api/v1/partners/{id}")).StatusCode);
    }

    [Fact]
    public async Task ForeignPartner_LinkClient_Forbidden()
    {
        if (!Enabled) return;
        var a = await SessionAsync("a");
        var b = await SessionAsync("b");
        var id = await CreatePartnerAsync(a, "A-link");

        var r = await b.PostAsJsonAsync($"api/v1/partners/{id}/link-client", new { clientId = Guid.NewGuid() });
        Assert.Equal(HttpStatusCode.Forbidden, r.StatusCode);
    }
}
```

**Почему `return`, а не `Skip`:** в проекте нет `Xunit.SkippableFact`; `return` даёт зелёный прогон без
ложного «теста нет». Если @BE добавит пакет — заменить на `Skip`.
