# TE-016: E2E — снятие PIN (pin/remove с текущим PIN)

- **Статус:** В работе
- **Приоритет:** P1
- **Источник:** @FE 18:02 (не покрыто: «только смена»); PE 18:10 — «всё надо покрыть»
- **Зависимости:** BE-021, FE-009

## Задача
Живой E2E, **безопасно для стенда**: на тестовом инстансе (или с тестовым PIN) снять PIN через `removePin(currentPin)` → проверить через API `pin/has` = false и что device-токен снова выдаётся → в `finally` вернуть исходный PIN.

## Критерии приёмки
- [ ] `pin/remove` без/с неверным `currentPin` → 401 (проверка BE-021).
- [ ] `pin/remove` с верным `currentPin` → 200, PIN снят, device-токен работает.
- [ ] `finally` возвращает PIN; API-E2E и прод не ломаются.

## Ход работы
- Проверено по коду: `PrivacyController.Remove` → `RespondAuth` → при ошибке «Текущий PIN» отдаёт **401** (совпадает с критерием); `pin/has` — `GET` → bool.
- Тест `tests/remove-pin.spec.js`: негатив (`pin/remove` без `currentPin` → 401, `pin/has` = true), затем снятие **через UI** (Настройки → «Удалить PIN» → «Да») → `pin/has` = false, старый PIN → 401, device-токен (`pin: ''`) → 200. В `finally` — возврат PIN через `pin/set` (без PIN `currentPin` не требуется) + проверка `pin/has`.
