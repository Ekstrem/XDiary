## Факт (проверено по `origin`)

В `9-tests/scripts` — **10 `.py`** и **4 `.sh`**. У всех четырёх `.sh` **самопроверки нет**
(`selftest` = 0 вхождений):

| Файл | Строк | Двойник `.py` |
|---|---|---|
| `check-adr028-move.sh` | 286 | **`check_adr028_move.py`** (selftest 10/10) |
| `check-front-088.sh` | 66 | **`check_front_088.py`** (selftest 4/4) |
| `check-journal-scope.sh` | 90 | — (единственный) |
| `check-profile-canon.sh` | 96 | — (единственный) |

Итого: **2 дубля** (`.sh` + `.py` одного и того же смысла, разное написание: kebab vs snake)
и **2 одиночных** shell-гейта.

## Задача

1. **Дубли схлопнуть в один проверяемый:** `.sh` оставить **тонкой обёрткой** над `.py`
   (`exec python <name>.py "$@"`), либо удалить `.sh`, а вызовы в CI перевести на `.py`.
   Второй вариант предпочтительнее: одна логика — один файл.
2. **Одиночные shell-гейты** (`check-journal-scope.sh`, `check-profile-canon.sh`):
   либо перенести логику в `.py` с `--selftest` (минимум 2 кейса: норма → `rc=0`,
   дефект → `rc=1`), либо **объявить исключение** с причиной в `9-tests/README.md` —
   «shell, проверяет только текст/конфиг, самопроверка не требуется».
   Молчаливое отсутствие не допускается.

## Критерии приёмки

- в `9-tests/scripts` **не остаётся** пары «`.py` с selftest + `.sh` без» на один смысл;
- для каждого оставшегося `.sh` — либо `--selftest`, либо строка-исключение в README
  с причиной и датой;
- `ci-guards` вызывает только проверяемые формы (`--selftest` перед нормой);
- в `## Результат` — таблица «файл → решение (обёртка / удалён / исключение)».
