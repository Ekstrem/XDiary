# TE-060: shell-гейты в `9-tests/scripts` — дубли без самопроверки

- **Статус:** На проверке
- **Приоритет:** P2 (дубли гейтов; один из двух уже проверяемый)
- **Источник:** матрица @TE `2026-11-05 16:47` (14 скриптов) + перепроверка @TL по `origin`
- **Зависимости:** — · **Проверяет:** @TL

## Факт (проверено по `origin`)

В `9-tests/scripts` — **10 `.py`** и **4 `.sh`**. У всех четырёх `.sh` **самопроверки нет**
(`selftest` = 0 вхождений):

| Файл | Строк | Двойник `.py` |
|---|---|---|
| `check-adr028-move.sh` | 286 | **`check_adr028_move.py`** (selftest 10/10) |
| `check-front-088.sh` | 66 | **`check_front_088.py`** (selftest 4/4) |
| `check-journal-scope.sh` | 90 | — (единственный) |
| `check-profile-canon.sh` | 96 | — (единственный) |

Итого: **2 дубля** (`.sh` + `.py` одного и того же смысла, разное написание: kebab vs snake)
и **2 одиночных** shell-гейта.

## Задача

1. **Дубли схлопнуть в один проверяемый:** `.sh` оставить **тонкой обёрткой** над `.py`
   (`exec python <name>.py "$@"`), либо удалить `.sh`, а вызовы в CI перевести на `.py`.
   Второй вариант предпочтительнее: одна логика — один файл.
2. **Одиночные shell-гейты** (`check-journal-scope.sh`, `check-profile-canon.sh`):
   либо перенести логику в `.py` с `--selftest` (минимум 2 кейса: норма → `rc=0`,
   дефект → `rc=1`), либо **объявить исключение** с причиной в `9-tests/README.md` —
   «shell, проверяет только текст/конфиг, самопроверка не требуется».
   Молчаливое отсутствие не допускается.

## Критерии приёмки

- в `9-tests/scripts` **не остаётся** пары «`.py` с selftest + `.sh` без» на один смысл;
- для каждого оставшегося `.sh` — либо `--selftest`, либо строка-исключение в README
  с причиной и датой;
- `ci-guards` вызывает только проверяемые формы (`--selftest` перед нормой);
- в `## Результат` — таблица «файл → решение (обёртка / удалён / исключение)».

## Результат

| Файл | Решение |
|---|---|
| `check-adr028-move.sh` (286 → **9** строк) | **тонкая обёртка** `exec python check_adr028_move.py "$@"` |
| `check-front-088.sh` (66 → **9**) | **тонкая обёртка** `exec python check_front_088.py "$@"` |
| `check-journal-scope.sh` (90) | **исключение**, причина и дата — в `9-tests/README.md` |
| `check-profile-canon.sh` (96) | **исключение** по той же причине |
| `check_adr028_move.py` (271 → **288**) | добавлены `--selftest` (**3/3**), `--ref`, fail-fast `rc=2` на неизвестном флаге |

**Найдено при работе (исправлено):** у `check_adr028_move.py` самопроверки **не было вообще**
(`selftest` = 0 вхождений), а «10/10» в выводе — это **десять проверок нормы**. Хуже: `--selftest`
**молча прогонял норму** и возвращал `rc=0`. Матрица в `9-tests/README.md` утверждала «selftest 10/10» —
исправлено. Добавленная самопроверка: baseline-константы против `ref`, `rc=2` + `::error::` на
невалидном ref, `rc=2` + `::error::` на неизвестном флаге.

**Не проверено локально:** сами обёртки не запускались — в этой среде нет `bash`; их 9 строк
подтверждаются в CI (ubuntu) или @DO. Проверяемое проверено: `check_adr028_move.py --selftest` 3/3,
`check_front_088.py --selftest` 4/4.
