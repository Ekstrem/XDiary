## Ход работы
**Артефакты добавлены в общий helper (installBase, значит во всех спеках):**
- page.on('pageerror') — со стеком;
- page.on('console') с фильтром error;
- **page.on('response'): любой status >= 400** — «http 500 <url>»;
- **page.on('requestfailed')** — сетевые обрывы;
- **dumpViews(page)** — снимок всех #view-* с hidden/isible;
- snapshotStorage(page) — маскированный снимок localStorage (наличие + длины).
Всё уходит через ::error::/::notice::, то есть в **аннотации check-run**.

**Плюс:** screenshot: 'only-on-failure' уже был, добавил **	race: 'retain-on-failure'** — по трейсу видно точную последовательность действий.

**Для флейких (dd-partner, settings):** прогон с --repeat-each=5, чтобы была статистика N из M, а не один исход.
