# TE-003: Интеграционные тесты — соматика (somatic-series + daily-metrics)

- **Статус:** На проверке
- **Приоритет:** P1
- **Источник:** BC-SomaticSeries, BC-DailyMetrics, BE-005, BE-006
- **Зависимости:** BE-005, BE-006
- **Прогресс:** тесты в `9-tests/Somatic.Daily/SomaticDaily.IntegrationTests` — somatic (минутная гранулярность, отрицательные значения) + daily (стресс/пульс/HRV/сон, формат даты, отсутствие метрик у источника).
- **Блокер:** та же проблема интеграции `9-tests` в CI (см. TE-001).

## Задача
- **somatic-series:** минуточные точки + срез вокруг `startedAt`.
- **daily-metrics:** дневные сводки + тренды; отсутствие метрик, которых нет у источника.

## Критерии приёмки
- [ ] Тесты somatic-series (срез, минутная гранулярность).
- [ ] Тесты daily-metrics (тренды, отсутствие метрик у источника).
- [ ] `dotnet test` зелёный.
