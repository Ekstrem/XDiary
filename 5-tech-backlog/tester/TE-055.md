1. `remove-pin.spec.js`: убрать серверный блок (5 вызовов + 2 assert'а) — оставить проверки
   **локального** `window.Pin` (hasPin true → снятие через UI → hasPin false → восстановление).
   Историю `BE-021` сохранить комментарием со ссылкой на этот файл, а не мёртвыми запросами.
2. `pin-fallback.spec.js`: заменить признак применимости. Сейчас — `POST /privacy/token {pin:""}`;
   после этапа 3 нужен **внешний** признак, не зависящий от удалённого эндпоинта: например,
   `GET /api/v1/privacy/pin/has` (если останется) либо `XDIARY_STAND_HAS_PIN=1` (env, по образцу

   «на стенде PIN задан», и он не должен читаться из поведения UI.

4. Прогнать `pin-first-login`, `change-pin` — они локальные и должны остаться зелёными.
