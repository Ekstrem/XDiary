# TE-031: `test` красный — `CorrelationCalculator.Calculate` требует `somatic` (после BE-033)

- **Статус:** На проверке
- **Приоритет:** P1 (CI `test` красный на `main`)
- **Источник:** CI `test` на `85c6088` (0.54), 5 аннотаций; причина — BE-033
- **Зависимости:** BE-033 (закрыт)
- **Проверяет:** @TL (TechLead)

## Проблема
В `9-tests/Analytics.Privacy/AnalyticsPrivacy.IntegrationTests/AnalyticsTests.cs` два вызова устарели:
- `L52: CorrelationCalculator.Calculate(records, metrics);`
- `L71: CorrelationCalculator.Calculate(records, metrics);`

После BE-033 сигнатура: `Calculate(IReadOnlyList<RecordInput>, IReadOnlyList<MetricInput>, IReadOnlyDictionary<string, (int Hr, int BodyBattery)> somatic)` — третий аргумент **обязательный**. Компиляция падает:

> There is no argument given that corresponds to the required parameter 'somatic' of 'CorrelationCalculator.Calculate(...)'

Итог: job `test` = **failure** на `main` (на `1c4219e`, до BE-033, был зелёный).

## Задача
- Обновить оба вызова: передать `somatic` (пустой словарь `new Dictionary<string, (int, int)>()` для кейса «нет соматики», или набор точек для кейса с корреляциями — по смыслу теста).
- Добавить кейс, где `somatic` влияет на результат (это проверка контракта BE-033: hr из соматики, окно ±30 мин).
- Убедиться, что `dotnet test 9-tests` зелёный.

## Критерии приёмки
- [ ] `9-tests` компилируется и проходит; CI `test` = success.
- [ ] Есть хотя бы один тест, доказывающий, что `somatic` участвует в корреляциях.

## Ход работы
- Проверил сигнатуру по коду `6-msa`: `Calculate(IReadOnlyList<RecordInput>, IReadOnlyList<MetricInput>, IReadOnlyDictionary<string, (int Hr, int BodyBattery)> somatic)` — третий параметр обязательный (BE-033).
- Исправил **оба** вызова (`6bd6e08`):
  - **L52** («мало точек → пусто») — передаю **пустую** соматику `new Dictionary<string, (int Hr, int BodyBattery)>()`, результат не меняется;
  - **L71** («три точки → две корреляции») — передаю соматику с `hr` по тем же датам, что и записи (`2026-10-01T21:00 → (70,50)`, `10-02T22:00 → (72,45)`, `10-03T20:00 → (74,40)`). **Не пустую** специально: без `hr` пара «оргазмы↔hr» не посчитается и `Assert.Equal(2, result.Count)` упал бы — то есть второй кейс как раз доказывает участие `somatic` (критерий 2).
- Ждёт прогона: CI встал (29 run'ов в `queued` с 05:21, заявка @DO), поэтому `test` пока не подтверждён.
