# TE-002: E2E тест (PWA → шлюз → сервисы)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** ADR-006, ADR-007
- **Зависимости:** BE-012, FE-001, FE-002

## Задача
Написать E2E-сценарий полного пути:
PWA → API Gateway (JWT) → сервис → PostgreSQL → ответ.

Сценарий: логин → создание записи в журнале → чтение журнала → проверка данных.

## Критерии приёмки
- [ ] E2E проходит в окружении podman-compose.
- [ ] Проверены аутентификация, создание и чтение записи.
- [ ] Падение любого звена даёт понятную ошибку.
