## Задача
Живой E2E: создать элемент каталога → в архив (`archive`) → проверить, что скрыт из активного списка → восстановить (`restore`) → проверить, что вернулся → удалить в `finally`.

## Критерии приёмки
- [ ] Archive/restore проверены через API.
- [ ] `finally` удаляет элемент.
- [ ] CI `front-e2e` зелёный.

- Тест `tests/catalog-archive.spec.js`: игрушка создаётся через живой API, archive/restore — через UI, проверка — `GET /catalog/{id}.archived`, уборка — `POST /catalog/{id}/remove` в `finally`.
