## Задача

Сценарий уже написан; он проверяет **три утверждения из спеки**, а не мои ожидания:

1. **Форма сохраняется** — при недоступном API визард открывается. Сейчас не так: у `DB.getAllPartners()`
   нет `.catch` → `Promise.all` отвергается → `openWizard`/`reopenWizard` без обработчика → визард не
   открывается и ошибка не показана (`read-paths.md` §2, «хуже тихого»).
2. **Ошибка видна** — в визарде или тосте есть явный признак отказа; тихий `null`/`[]` этот пункт не проходит,
   потому что неотличим от «истории ещё нет» (§1 п.1).
3. **Нет ложной подстановки** — при отказе выбранной карточки партнёра по умолчанию нет.

Сеть отключается **после** логина (вход по PIN требует сети) и точечно — только MV журнала и партнёры;
партнёры/каталог из `IndexedDB` не блокируются, иначе проверялось бы не то.
