# TE-027: E2E — «это я» через clientId (починить сломанный self.spec.js)

- **Статус:** Открыта
- **Приоритет:** P1 (существующий спек красный после BE-028)
- **Источник:** BE-028 (self → `Partner.clientId`), `chat/tl.md`; новый CJ «идентификация»
- **Зависимости:** —

## Проблема
`9-tests/RnD/front-e2e/tests/self.spec.js` зовёт **удалённый** `POST /partners/{id}/self` (BE-028 заменил на `link-client`/`unlink-client` + `clientId`). Спек либо падает 404, либо проверяет несуществующий контракт.

## Задача
Переписать `self.spec.js` под актуальный контракт:
1. Создать партнёра → `POST /partners/{id}/link-client {clientId}` → в read-model `clientId` заполнен.
2. «Это я» в настройках подсвечивает партнёра по `clientId`.
3. `POST /partners/{id}/unlink-client` → «я» снят, `clientId = null`.
4. Регресс: старый `/self` больше не используется.

## Критерии приёмки
- [ ] Спек зелёный на dev, проверяет `link-client`/`unlink-client`/`clientId`.
- [ ] Уборка созданных данных в `finally`.
