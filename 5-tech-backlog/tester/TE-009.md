# TE-009: E2E — соматика + аналитика (срез, сводка)

- **Статус:** Открыта
- **Приоритет:** P2
- **Источник:** FE-001, BE-005, BE-006, BE-009
- **Зависимости:** FE-001, BE-005, BE-006, BE-009

## Задача
Сквозной сценарий: после записи акта — срез соматики на детали; на экране аналитики — сводка за период и корреляции.

## Критерии приёмки
- [ ] Срез пульса/BB вокруг акта отображается.
- [ ] Сводка за 30/90 дней строится.
- [ ] Корреляции с n ≥ 3 отображаются с пояснением.
