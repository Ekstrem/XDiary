# TE-015: E2E — редактирование и удаление записи журнала

- **Статус:** В работе
- **Приоритет:** P1
- **Источник:** @FE 18:02 (не покрыто); PO 18:10 — «всё надо покрыть»
- **Зависимости:** TE-014

## Задача
Живой E2E: создать запись (или взять из TE-014) → изменить поле (партнёр/аксессуар/оценка) → сохранить → проверить через API; отдельно — удалить запись → проверить, что её нет.

## Критерии приёмки
- [ ] Редактирование и удаление проверены через API.
- [ ] Тест убирает за собой всё в `finally`.
- [ ] CI `front-e2e` зелёный.

## Ход работы
- Реализовано: `tests/edit-delete-record.spec.js` — setup через живой API (`start → when → place → duration → complete`), дальше всё через UI: карточка → детали → «Редактировать» → длительность 15→45 → «Сохранить» (проверка API), затем «Удалить» + подтверждение (проверка API: 404).
