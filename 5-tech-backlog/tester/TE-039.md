# TE-039: `globalSetup` должен проверять **версию контракта** стенда, а не только `/health`

- **Статус:** ToDo
- **Приоритет:** P1 (третий инцидент одного класса за сутки; каждый стоил часов диагностики)
- **Источник:** @BE 2026-11-02 20:25 — «405 на `/clients/refresh` + `/verify` без `refreshToken` на dev = **образ ДО BE-041** (маршрута и поля в образе нет)»; до этого: образ `clients` без BE-038 (`AddJwtBearer` = 0) дал 16 красных спеков, ещё раньше — шлюз без `--add-host clients` дал 502
- **Зависимости:** TE-035 (retry готовности), DO-035 (разделение гейтов), BE-041 (refresh)
- **Проверяет:** @TL (TechLead)

## Проблема
`globalSetup` проверяет только `GET /health` = 200. Стенд при этом может быть **жив, но старой версии**: эндпоинта нет, поля нет, маршрута нет. Тогда красный прогон выглядит как регрессия продукта, хотя это дрейф стенда.

Три случая за сутки:
1. шлюз без `clients` в `/etc/hosts` → 502 на `/api/v1/clients`;
2. образ `clients` без BE-038 → `/clients/me` = 401, 16 красных спеков;
3. образ `clients` без BE-041 → `/clients/refresh` = 405, `/verify` без `refreshToken`.

## Задача
В `globalSetup` добавить **проверку контракта версии** (не «жив ли», а «какой версии»):
1. `GET /health` = 200 (есть).
2. **`POST /api/v1/clients/refresh`** с пустым/битым телом → ожидаем **401/400**, но **не 405** → иначе `[infra] stale-image: clients без BE-041`.
3. `POST /api/v1/clients` (+verify на dev с `TESTOTP`) → в ответе **обязательно `refreshToken`**; нет поля → `[infra] stale-image: verify без refresh`.
4. `GET /api/v1/clients/me` без токена → 401 **с** `WWW-Authenticate`; без заголовка → `[infra] stale-image: clients без BE-038`.
5. Любая из проверок красная → падение **в `globalSetup`** с меткой `[infra]`, без запуска спеков (экономит 9–14 минут и не маскирует продукт).

## Критерии приёмки
- [ ] Прогон на стенде со старым образом падает **в `globalSetup`** с текстом `[infra] stale-image: <чего нет>`.
- [ ] Прогон на актуальном стенде проходит `globalSetup` без задержек (все проверки — по одному запросу).
- [ ] В аннотации видно, **какого именно** контракта не хватает.
