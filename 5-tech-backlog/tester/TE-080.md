# TE-080. Мета-гейт: у каждого гейта обязана быть самопроверка

- **Статус:** На проверке
- **Проверяет:** @TL
- **Чем проверяется:** `python 9-tests/scripts/check_e2e_gate_hygiene.py --selftest  (и прогон: «нарушено: 0»)`
- **Роль:** @TE
- **Источник:** аудит собственных гейтов (37 шт.) после серии правок раундов 92–117

## Проблема

Гейт без `--selftest` — это «зелено, потому что ничего не проверялось». Правило проекта требует, чтобы
гейт был доказан **на дефекте** и на норме; проверка на дефекте живёт внутри самого гейта. До сих пор это
держалось на памяти: `_orphan_gates` в агрегаторе ловил только «файл есть, а в списке нет», но не
отсутствие самопроверки и не отсутствие квитанции.

## Что сделано

`9-tests/scripts/check_e2e_gate_hygiene.py` — статическая проверка (быстро, без запуска гейтов):

1. в файле есть разбор `--selftest` **и** функция `selftest()`;
2. файл печатает `квитанция` (иначе разбор прогона невозможен);
3. гейт подключён к `check_e2e_all.py`.

`--selftest` **5/5** (правильный гейт; без `--selftest`; без квитанции; не подключён; текст квитанции).

Дополнительно прогнал **все** `--selftest` на чистом worktree от `origin`:
`ok 37 | fail 0 | всего 37` — то есть самопроверки не только существуют, но и проходят.

## Критерии приёмки

- [x] `--selftest` — 5/5
- [x] на `origin` — «гейтов 36 | с самопроверкой 36 | нарушено: 0»
- [x] все 37 `--selftest` проходят (`ok 37 | fail 0`)
- [x] `check_e2e_all` — **38 гейтов**, все зелёные
- [x] гейт подключён к агрегатору (иначе `_orphan_gates` = rc=1)

## Результат

`9-tests/scripts/check_e2e_gate_hygiene.py` + запись в `check_e2e_all.py` + абзац в `9-tests/README.md`.
