# TE-001: Интеграционные тесты — journal (Core)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** BC-Journal, BE-002, edm-net
- **Зависимости:** BE-002

## Задача
Интеграционные тесты `journal` по паттерну **Command → Query → Assert**:
- полный жизненный цикл Record (`StartManualEntry → … → Complete`);
- инварианты: WhenRequired, DurationPositive, RatingRange;
  (**PartnerRequired — НЕ инвариант**: `partners[]` 0..N, пусто = соло — `03-ddd/BC-Journal/02-aggregate-canvas.md`);
- Query (журнал/деталь) не обращается к Event Store.

## Критерии приёмки
- [ ] Тест Command → Query → Assert для Record.
- [ ] Все инварианты агрегата покрыты.
- [ ] `dotnet test` зелёный.
