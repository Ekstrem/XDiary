# TE-001: Интеграционные тесты сервисов (Command → Query → Assert)

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** edm-net skill (чек-лист), ADR-014
- **Зависимости:** BE-001..BE-012

## Задача
Написать интеграционные тесты для каждого микросервиса по паттерну Command → Query → Assert:
- Реальные InMemory EventBus + Testcontainers (PostgreSQL).
- Полный жизненный цикл агрегата (create → read → assert).

## Критерии приёмки
- [ ] Тест на каждый сервис (10 шт.) проходит.
- [ ] `dotnet test` без моков инфраструктуры.
- [ ] Покрыты инварианты агрегатов (из секции 4 канвасов).
- [ ] CI гоняет тесты на каждом push.
