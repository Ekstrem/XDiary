# TE-006: Интеграционные тесты — portability + api-gateway

- **Статус:** На проверке
- **Приоритет:** P1
- **Источник:** BC-Portability, ADR-007, BE-011, BE-012
- **Зависимости:** BE-011, BE-012
- **Прогресс:** тесты в `9-tests/Portability.Gateway/PortabilityGateway.IntegrationTests` — portability (CSV round-trip, контракт 19 колонок, списки через `;`) + gateway (JWT HS256: валидный/просроченный/неверный ключ/мусор; аноним → отказ).
- **Примечание:** CI-интеграция `9-tests` — задача DevOps **DO-009**. Идемпотентность импорта по `id` в текущем агрегате Portability не реализована (нет дедупликации) — отмечено как gap.

## Задача
- **portability:** CSV экспорт/импорт (идемпотентность по `id`, round-trip без потерь).
- **api-gateway:** маршрутизация на 10 сервисов + JWT (аноним → 401, кроме `/api/v1/privacy/*` и `/health`).

## Критерии приёмки
- [ ] CSV round-trip без потерь (списки через `;`).
- [ ] Маршруты шлюза → сервисы; аноним → 401.
- [ ] `dotnet test` зелёный.
