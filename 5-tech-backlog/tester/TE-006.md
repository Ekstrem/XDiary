# TE-006: Интеграционные тесты — portability + api-gateway

- **Статус:** Открыта
- **Приоритет:** P1
- **Источник:** BC-Portability, ADR-007, BE-011, BE-012
- **Зависимости:** BE-011, BE-012

## Задача
- **portability:** CSV экспорт/импорт (идемпотентность по `id`, round-trip без потерь).
- **api-gateway:** маршрутизация на 10 сервисов + JWT (аноним → 401, кроме `/api/v1/privacy/*` и `/health`).

## Критерии приёмки
- [ ] CSV round-trip без потерь (списки через `;`).
- [ ] Маршруты шлюза → сервисы; аноним → 401.
- [ ] `dotnet test` зелёный.
