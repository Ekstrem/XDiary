## Задача
- **analytics:** read-only, сводка/корреляции (n ≥ 3), не трогает Domain/Event Store.
- **privacy:** PIN (PBKDF2-SHA256) + JWT (issue/verify, refresh, просроченный).

## Критерии приёмки
- [ ] analytics: только чтение, корреляции с n ≥ 3.
- [ ] privacy: JWT валидный/просроченный/невалидный.
- [ ] `dotnet test` зелёный.
