# TE-005: Интеграционные тесты — analytics + privacy

- **Статус:** На проверке
- **Приоритет:** P1
- **Источник:** BC-Analytics, BC-Privacy, BE-009, BE-010
- **Зависимости:** BE-009, BE-010
- **Прогресс:** тесты в `9-tests/Analytics.Privacy/AnalyticsPrivacy.IntegrationTests` — analytics (SummaryCards, корреляции Pearson n≥3 с пояснением, n<3 → пусто) + privacy (PBKDF2-SHA256 хеш+соль без plaintext, формат PIN 4–8, lock/unlock).
- **Gap:** JWT-**выдача** (issue/refresh) в `BC-Privacy` не реализована — есть только `JwtVerifier` на шлюзе (verify). Тест verify — в TE-006. Нужно решение TL: JWT-issue — отдельная BE-задача или вне scope TE-005.
- **Примечание:** CI-интеграция `9-tests` — задача DevOps **DO-009**.

## Задача
- **analytics:** read-only, сводка/корреляции (n ≥ 3), не трогает Domain/Event Store.
- **privacy:** PIN (PBKDF2-SHA256) + JWT (issue/verify, refresh, просроченный).

## Критерии приёмки
- [ ] analytics: только чтение, корреляции с n ≥ 3.
- [ ] privacy: JWT валидный/просроченный/невалидный.
- [ ] `dotnet test` зелёный.
