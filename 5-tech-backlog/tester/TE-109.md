# TE-109: тост с текстом причины не проверяется ни одной спекой — 0 утверждений на `#toast`

- **Статус:** Идея
- **Приоритет:** P2 (пользовательский фидбэк не покрыт; на `FE-046` это не влияет — там закрывали висение, а не видимость тоста)
- **Источник:** @AR `2026-11-13 02:20` — замер по `origin/main`: спек **26**, упоминаний тоста **10**, из них в утверждениях (`expect`/`toBeVisible`/`toHaveText`) — **0**, диагностических чтений — **2** (`api.js:790`, `:855`)
- **Зависимости:** нет (зона @TE: `9-tests/**`)
- **Проверяет:** @TL
- **Исполняет:** @TE

## Факт

При закрытии `FE-046` было доказано «90-секундного висения нет, спека доходит до ассертов зелёной», и **не**
доказано «тост виден и содержит текст причины»: утверждение 3 по критерию 3 принимает «экран **или**
видимую ошибку», а ошибку ловит текст экрана, не тост. Проверка `#toast` в утверждениях отсутствует
**ни до фикса, ни после** — это дыра покрытия, а не следствие правки таймаутов.

## Задача

1. Добавить утверждение: после действия, которое должно показать ошибку, `#toast` **видим** и содержит
   **текст причины** (`toBeVisible` + `toHaveText(/…/)`), а не только пустой/скрытый элемент.
2. Негативный контроль: убрать текст из тоста (или скрыть его классом `hidden`) → утверждение обязано
   покраснеть; без этого получится «утверждение, которое не может упасть» (`@AR` о дефект-плече).
3. Проверять на том же стенде, где идёт `front-e2e-repeat` (`serve.js` + dev-API), не подменяя продукт.

## Критерии приёмки

- [ ] в спеке есть утверждение на видимость и текст `#toast` (файл и строки названы в `## Результат`);
- [ ] негативный контроль: скрытый/пустой тост → спека красная (REF прогона + вывод);
- [ ] норма: на текущем стенде утверждение зелёное (REF прогона);
- [ ] `check_e2e_all` — без регрессий (43/43 на момент создания);

## Почему отдельная карточка, а не «побочный эффект»

`FE-046` закрывали по квитанции «висения нет» и по границе «тост не проверяется». Смешать это с правкой
таймаутов — значит снова закрыть карточку на том, что не проверялось (`@AR` `02:20`: «проверено ровно то,
что проверялось, а не то, что хотелось бы»).
