## 3. Ключевой замер: инвариант — «нарушителей 0», стабильность канала — отдельный факт

**Инвариант `(ii-a)`: `нарушителей = 0` во ВСЕХ прогонах** (за сессию — 10 прогонов, ни одного
нарушителя). Это и есть доказательство «APIM в пути».

**Стабильность канала — второй, отдельный факт, и его нельзя складывать с первым:**

| Серия | `rc=0` | `rc=2` (`неизвестно`) |
|---|---|---|
| до ретрая (6 прогонов) | 4 | **2** (`73/74`, `72/74`) |
| после ретрая `--retry-unknown 1` (4 прогона) | **3** | **1** (`73/74`) |

То есть ретрай **снижает** долю «не измерено», но **не устраняет**: сегодня один запрос из 76 дважды
подряд не ответил, и `rc=2` остался — это **правильный** ответ, а не дефект гейта.

**Правило (@AR, `round-checklist.md` §3.6): повтор разрешён только с провенансом.** В квитанции
должно печататься `unknown_retried: N`; если после повтора `unknown` остался — `rc` остаётся `2`.
Сейчас **провенанса в квитанции нет** (`unknown_retried` — 0 вхождений) ⇒ требование не выполнено,
и это записано как замечание @TE.

**Что ставить в отчёт:** `(ii-a)` — **защищено 73–74 из 74, `нарушителей 0`**, `rc=0` в 3 из 4 прогонов
после ретрая (`rc=2` — транзиентная недоступность одного запроса). `(ii-c)` — **PASS 2/2**. Знаменатель
**76 из 80** (4 анонимных). `via=gravitee` на всех зачтённых.

## 6. Уроки итерации — семь форм «зелёного, который ничего не доказывает»

| Форма | Пример |
|---|---|
| зелёный на пустом | `--root 6-msa` → «в норме» при 0 файлов |
| зелёный на любом тексте | спека с regex `не удалось\|ошибк` |
| зелёный без красного контроля | `check_front_specs_base` без `--selftest` |
| зелёный, но не подключён | `check_adr028_move`, `check_read_paths` (до правки) |
| зелёный при неверном счёте | `0 проектов` = «0 с нарушениями» |
| зелёный на непроверенном правиле | `check_test_isolation` не проверял правило группы |
| зелёный «по наличию» | backup `done` шесть дней при обрезанном дампе |
| **зелёный на другой версии кода** | замер `POST` → 200/count=0 сделан на **B** (11:14), вердикт применён к **A** (после 11:33) |
| **зелёный, потому что проверять нечего** | граница «канона» `2026-11-08` **в будущем** относительно дат коммитов ⇒ `check_adr` печатает «проверено 0, старых пропущено 33», `rc=0`; при снятии грандфазеринга — **18 нарушений** |
