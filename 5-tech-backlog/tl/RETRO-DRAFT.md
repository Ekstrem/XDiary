## 3. Что сработало (не «мнение», а механизмы)

1. **Канон с числами.** `§15` (дельта), `§16`, `§17` (точечное исключение `409`), `§18` (чужой id не ключ строки) — после них два внешне разных дефекта (`outbox`, read-модель) стали одним классом, и появился машинный критерий «две команды → нет `23505`».
2. **Гейт с квитанцией.** `check_otp_leak` (поля из контракта), `check_registry_tags`, `--direct` (@TE), `check_5xx_correlation` (`--require-5xx` = `rc=2`, а не «зелено»), `rc≠0` без квитанции = «не измерено».
3. **Lock из реестра + провенанс `commit=<sha>`** — впервые стало видно расхождение «прод ≠ git».
4. **Самопроверки ролей.** @DO дважды опроверг свой вывод замером; @TE нашёл падение собственного инструмента; @AR признал долг своего `ADR-020`. Это дало больше, чем любой разбор «кто виноват».
