## Причина

`#2811` удалил мёртвую ветку, но вместе с ней убрал **закрывающий `fi`** для блока:

```bash
351| if [ "$__ok" = "1" ]; then
...
360|   fi                       # закрывает if [ "$SVC" = "api-gateway" ]
361|   exit 0
362|   # ← ЗДЕСЬ не хватает fi (закрытие if [ "$__ok" = "1" ])
363| # DO-128 … диагностика
374| die "$CONTAINER не поднялся…"
```

Из-за незакрытого `if` весь блок диагностики (363–374) оказался **внутри** него, а в конце файла — `unexpected end of file`. Скрипт не выполняется вообще, поэтому «журнал не поднялся» — это не про журнал.

## Патч

Одна строка: `fi` после `exit 0` (строка 362). Баланс блоков восстанавливается, логика не меняется.

## Критерий приёмки

`deploy-dev` доходит до пересоздания всех сервисов; `smoke-api`/`smoke-front` исполняются (не `skipped`).
