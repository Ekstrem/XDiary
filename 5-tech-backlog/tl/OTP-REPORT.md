# Отчёт: возврат служебных полей в ответе `POST /api/v1/clients` (BE-090)

Составлен @TL `2026-11-06`. Владелец просил: **как нашли, что именно утекло, что изменилось.**
Термин «утечка» — мой, и я его больше не использую: по сути это **дефект возврата служебных полей в ответе API**.
Для модели «один пользователь» практический риск ограничен; отчёт фиксирует, что именно было и что стало.

## 1. Что именно возвращалось

`POST /api/v1/clients` — **анонимная** операция регистрации (`[AllowAnonymous]`), единственная, которую можно вызвать без токена.

Старый код (`6-msa/BC-Client/src/Client.Api/Controllers/ClientsController.cs`):

```csharp
public async Task<IActionResult> Register([FromBody] RegisterClientCommand c, CancellationToken ct)
    => Respond(await _mediator.Send(c, ct));     // ← отдавал ВЕСЬ конверт результата вместе с моделью
```

В теле ответа оказывались:

| Поле | Что это | Почему важно |
|---|---|---|
| `root.otpCode` | **одноразовый код входа (6 цифр)** | это и есть учётные данные: код + номер = вход |
| `root.otpAttempts` | счётчик попыток | подсказка атакующему, сколько осталось |
| `root.otpExpiresAt` | срок действия кода | по контракту разрешён, безопасен |
| `root.phone`, `root.verified` | номер, признак подтверждения | безвредно |
| `correlationToken`, `commandName`, `subjectName`, `version`, `invariants` | внутренний конверт DF | служебные поля, наружу не нужны |

## 2. Как это можно было использовать (3 запроса, без пароля)

```
1) POST /api/v1/clients                {"phone":"+79…"}   → 200 + {"id", "root":{… "otpCode":"123456"}}
2) POST /api/v1/clients/{id}/verify    {"code":"123456"}  → 200 + accessToken (JWT)
3) GET  /api/v1/journal/records        Authorization: Bearer …  → полный доступ к дневнику
```

Единственное условие эксплуатации — **знать номер телефона**. Пароля нет, второго фактора нет.
То есть для этого конкретного аккаунта номер телефона был эквивалентен паролю.

## 4. Что изменилось (проверяемо)

### Код (`0dd2b57e`)

```csharp
public async Task<IActionResult> Register([FromBody] RegisterClientCommand c, CancellationToken ct)
{
    var result = await _mediator.Send(c, ct);
    if (!result.IsSuccess()) return BadRequest(result.ErrorMessage());
    var m = result.Model();
    // BE-090: whitelist-проекция — otpCode/otpAttempts НЕ отдаются (иначе перехват аккаунта по номеру).
    return Ok(new { id = m.Id, version = m.Version, phone = m.Root.Phone, otpExpiresAt = m.OtpExpiresAt, verified = m.Verified });
}
```

### Прод (проверено дважды, последний раз `23:34`)

```
POST /api/v1/clients  →  200
{"id":"10124840-…","version":1793997283732,"phone":"+7999…","otpExpiresAt":"2026-11-06T20:39:43Z","verified":false}

поля тела: id, otpExpiresAt, phone, verified, version
otpCode: нет · otpAttempts: нет · root: нет · correlationToken: нет · invariants: нет
```

### Аудит и гейты

- `7-deploy/images.lock`: `client single-766e59e commit=766e59e` — строка получена **генератором** `--from-registry --write`, не рукой (провенанс есть).
- `DO-110`: выкатка вне общего lock записана как **осознанное исключение** (что выкачено, кем разрешено, что осталось).
- `check_otp_leak.py`: белый список полей читается **из контракта** (`api-index.yaml`, `Client.Register`, код 200), плюс «поле вне контракта = утечка формы»; прод `rc=0`, `--selftest 14/14`.

## 6. Что я сделал неправильно в этой истории

1. Называл это «утечкой P0» без оговорки, что при одном пользователе риск ограничен — владелец об этом сказал раньше, чем я это учёл.
2. Мои пробы создали на проде **несколько тестовых клиентов** (`+7999…`, 4–5 штук) — их стоит удалить или оставить осознанно.
3. Предлагал ручную правку `images.lock` — @AR верно указал, что это третий источник дрейфа; правильно — запись исключения в карточке + lock из реестра.

## 7. Вывод в одну строку

Служебные поля (`otpCode`, `otpAttempts`, внутренний конверт) больше **не возвращаются**; на проде образ `single-766e59e`;
проверка автоматизирована и привязана к контракту. Единственное, что осталось по этой линии и не решается кодом, — **канал доставки OTP**, и это решение владельца.
