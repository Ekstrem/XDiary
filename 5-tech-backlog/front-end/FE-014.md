# FE-014: Убрать клиентский скан «последний партнёр/места» → Query API (техдолг AR-005)

- **Статус:** На проверке
- **Приоритет:** P1 (AR-005 → P1: решение перф-проблемы визарда, @AR 2026-11-03 11:40)
- **Источник:** AR-005 (`chat/ar.md` 2026-11-03 04:30)
- **Зависимости:** BE-024 (Query API)

## Проблема
`8-front/js/app.js` вычисляет `lastPartnerName`, `historyPlaces`, `fillDatalist` сканом всех записей на клиенте. По EDM/DF это должно приходить из read-model/Query API (AR-005).

## Задача
- Заменить клиентский скан на вызовы Query API (BE-024).
- Поднять `APP_VERSION`/`CACHE` (правило `8-front/AGENTS.md`).

## Критерии приёмки
- [x] Подсказки/последний партнёр/места приходят из API.
- [x] Клиентский скан удалён.
- [x] Версия забампана (`0.38`/`v38`); CI — прогон @TE.

## Результат
- `8-front/js/api.js`: `journal.recent()` → `GET /api/v1/journal/recent` (RecentDefaultsView), `journal.places()` → `GET /api/v1/journal/places`.
- `8-front/js/app.js`: `lastPartnerName`/`historyPlaces` удалены; `openWizard` берёт `recent.lastPartner.name` / `recent.lastPlace`; `stepPlace` — `data.places`; даталист партнёров — из partners + `recent.lastPartner` (без скана записей).
- Версия `0.38`/`v38`.
