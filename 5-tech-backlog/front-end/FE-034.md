# FE-034: P2 — нечитаемый текст на экране ввода номера (контраст и размер шрифта)

- **Статус:** На проверке
- **В работе с:** 2026-11-08
- **Приоритет:** P2 (первый экран продукта; читаемость ниже нормы)
- **Источник:** владелец 2026-11-08 ~16:45: «на первом экране ввода номера шрифт почти не читаемый — попроси поправить»
- **Зависимости:** FE-032 (PIN-тупик), FE-033 (экран «Кто ты?»)
- **Проверяет:** @TL (TechLead)

## Проблема
На экране «Твой номер телефона» поясняющий текст («На него придёт код подтверждения. Номер нужен, чтобы различать пользователей.») и подписи отрисованы мелким серым на тёмном фоне — контраст ниже читаемого; сам ввод тоже мелкий для мобильного.

## Задача (зона @FE, `8-front/`)
1. **Контраст:** поясняющий текст и подписи — не ниже **4.5:1** к фону (WCAG AA для обычного текста); заменить приглушённый серый на более светлый.
2. **Размер:** текст полей и пояснений — **≥ 16 px** (мобильный стандарт; меньше — и нечитаемо, и iOS зумит при фокусе).
3. **Поле ввода:** явный контраст значения и placeholder; курсор/рамка фокуса видимы на тёмной теме.
4. Проверить тот же стиль на шаге ввода кода (те же классы) — чтобы не починить только первый экран.

## Критерии приёмки
- [ ] Пояснение и подписи читаются на телефоне без прищуривания (проверено владельцем на прод-сборке).
- [ ] Контраст текста ≥ 4.5:1 (можно указать измеренные значения в задаче).
- [ ] Размер шрифта полей ≥ 16 px; шаг ввода кода выглядит так же.

## Результат

`0.76`/`v76` (`2adb7b7b`):
- Корневая причина: `input[type="tel"]` **не входил** в селектор стилей → поле телефона с дефолтным мелким шрифтом без фона карточки. Добавлен.
- Плейсхолдер `#6d657e` (~3:1) → `var(--muted)` (≥ 4.5:1); `.field label` и `.muted` → **16 px** (`line-height: 1.45`); видимый фокус (`border-color` + `box-shadow` + `:focus-visible outline`).
- Классы общие — шаг ввода кода получает то же оформление.
