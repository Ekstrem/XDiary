# FE-038: Онбординг «Кто вы?» (имя + пол) вместо «создай партнёра»; «я» уходит в профиль — ADR-024

- **Статус:** В работе
- **В работе с:** 2026-11-10
- **Приоритет:** P1 (первый шаг после входа; после ретро)
- **Источник:** ADR-024 + владелец: «на онбординге я опять должен добавлять партнёра вместо того, чтобы написать просто имя и пол» (AR-011), «я вижу себя в партнёрах — тут должны быть мои партнёры, но не я» (AR-012)
- **Зависимости:** BE-054 (профиль клиента + deprecated-шим link-partner), FE-036 (заставка вместо PIN), FE-033 (обратная связь на экране)
- **Проверяет:** @TL (TechLead), продуктовая приёмка — @PO

## Задача (зона @FE, `8-front/`)
1. **Экран «Кто вы?»** после подтверждения кода: поле **имя***, выбор **пол** — `male`/`female` (значения решены владельцем 16:54, ADR-024 §3; `other` нет), фото — опционально. Кнопка «Продолжить» активна только при заполненных обязательных полях.
2. **Никакого создания партнёра на онбординге:** партнёр добавляется **позже** отдельным действием на вкладке «Партнёры» (существующий `+ Добавить`).
3. **Вкладка «Партнёры» показывает только других людей** (после E7/BE-054 «я» там нет по построению); если список пуст — текст «Добавьте партнёра» + кнопка.
4. **Профиль:** раздел «Профиль» (аватар в шапке или в «Настройках») — редактирование имени/пола/фото; повторный онбординг не показывается.
5. **Совместимость:** у клиента без профиля (владелец сейчас) онбординг показывается один раз и сохраняет профиль; повторный вход — сразу журнал.

## Критерии приёмки
- [ ] После кода виден экран «Кто вы?» с именем и полом; **партнёра создавать не нужно**.
- [ ] После сохранения профиля → журнал; при следующем входе онбординг не повторяется.
- [ ] На вкладке «Партнёры» владелец **не видит себя**.
- [ ] Проверено владельцем на прод-сборке (скриншоты в задаче).
