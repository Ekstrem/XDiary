# FE-038: Онбординг «Кто вы?» (имя + пол) вместо «создай партнёра»; «я» уходит в профиль — ADR-024

- **Статус:** На проверке
- **В работе с:** 2026-11-10
- **Приоритет:** P1 (первый шаг после входа; после ретро)
- **Источник:** ADR-024 + владелец: «на онбординге я опять должен добавлять партнёра вместо того, чтобы написать просто имя и пол» (AR-011), «я вижу себя в партнёрах — тут должны быть мои партнёры, но не я» (AR-012)
- **Зависимости:** BE-054 (профиль клиента + deprecated-шим link-partner), FE-036 (заставка вместо PIN), FE-033 (обратная связь на экране)
- **Проверяет:** @TL (TechLead), продуктовая приёмка — владелец (вместо @PO: он в архиве на итерацию техдолга) — артефакт: `8-front/js/app.js`, версия `0.88` / `xdiary-v88`

## Задача (зона @FE, `8-front/`)
1. **Экран «Кто вы?»** после подтверждения кода: поле **имя***, выбор **пол** — `male`/`female` (значения решены владельцем 16:54, ADR-024 §3; `other` нет), фото — опционально. Кнопка «Продолжить» активна только при заполненных обязательных полях.
2. **Никакого создания партнёра на онбординге:** партнёр добавляется **позже** отдельным действием на вкладке «Партнёры» (существующий `+ Добавить`).
3. **Вкладка «Партнёры» показывает только других людей** (после E7/BE-054 «я» там нет по построению); если список пуст — текст «Добавьте партнёра» + кнопка.
4. **Профиль:** раздел «Профиль» (аватар в шапке или в «Настройках») — редактирование имени/пола/фото; повторный онбординг не показывается.
5. **Совместимость:** у клиента без профиля (владелец сейчас) онбординг показывается один раз и сохраняет профиль; повторный вход — сразу журнал.

## Критерии приёмки
- [ ] После кода виден экран «Кто вы?» с именем и полом; **партнёра создавать не нужно**.
- [ ] После сохранения профиля → журнал; при следующем входе онбординг не повторяется.
- [ ] На вкладке «Партнёры» владелец **не видит себя**.
- [ ] Проверено владельцем на прод-сборке (скриншоты в задаче).

### Вердикт @TL 2026-11-10 20:15 — **принято — онбординг стал профилем клиента**

- Результат описывает смену смысла: онбординг = **профиль клиента** («кто вы»: имя + пол), а не «создай партнёра»; «я» уходит в профиль. Выпущено в `0.88`, сейчас фронт `0.104` — то есть изменение прожило 16 версий.
- Проверил, что онбординг в коде есть (`onboarding` — 7 вхождений в `8-front`). Это же изменение снимало продуктовую путаницу «я vs партнёр», из-за которой визард ждал партнёра (`FE-014`).

## Результат

Выпущено в `0.88`. Онбординг = профиль клиента, а не создание партнёра:

- экран «Кто вы?»: `#onb-name` (имя*, обязательное), `#onb-gender-male` / `#onb-gender-female` (пол — только `male`/`female`, по канону `BE-063`), фото опционально; кнопка `#btn-onb-profile` активна при заполненных обязательных;
- сохранение — `POST /api/v1/clients/me/profile` (`{DisplayName, Gender, PhotoUrl?}`), ответы `200`/`400`/`401`; ошибка видна в `#onb-profile-error`;
- успех → журнал; **партнёр не создаётся**, `link-partner`/`unlink-partner` не вызываются (deprecated no-op, удалены из `app.js`), `linkedPartnerId` не читается — поэтому «я» не попадает в «Партнёры»;
- «Профиль» — отдельный раздел настроек, онбординг показывается один раз (после успешного `profile` не возвращается).

Проверка: `PASS: 3/3` по `check-front-088.sh` (артефакт @TE), `node --check` rc=0; версия `0.88` ↔ `xdiary-v88`; @TL подтвердил контракт по `origin` (2026-11-04 22:43) и выпуск в `0.88`.

Критерии 1–3 выполнены кодом; **критерий 4 (проверено владельцем на прод-сборке со скриншотами) остаётся открытым** — он не может быть закрыт мной и является условием закрытия карточки.
