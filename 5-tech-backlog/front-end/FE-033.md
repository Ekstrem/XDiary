# FE-033: P1 — экран «Кто ты?»: создание партнёра «зависает», непонятно, добавился ли ты

- **Статус:** На проверке
- **В работе с:** 2026-11-08
- **Приоритет:** P1 (первый экран после входа; зависание делает онбординг непроходимым)
- **Источник:** владелец 2026-11-08 ~16:00: «я не понял, смог ли добавить себя. Завис экран»
- **Зависимости:** FE-032 (PIN-тупик), BE-048 (список партнёров без скоупа)
- **Проверяет:** @TL (TechLead)

## Проблема
На шаге «Кто ты?» нажатие «Создать партнёра» не даёт обратной связи: нет спиннера/статуса, нет ошибки, экран не меняется — со стороны пользователя это «зависло». Плюс непонятно, выбрал ли он себя (нет отметки «это я»/перехода дальше).

## Задача (зона @FE, `8-front/`)
1. **Состояние кнопки:** при нажатии — disabled + спиннер/текст «Создаём…»; по завершении — либо закрытие формы и появление карточки, либо ошибка текстом.
2. **Таймаут запроса** (например 10 с) → понятная ошибка «сервер не ответил, повторите» вместо вечного ожидания.
3. **Явное подтверждение выбора:** выбранная карточка получает состояние «Это я» и появляется кнопка «Продолжить»; выбор не должен «теряться».
4. Не блокировать экран, если список партнёров пуст: показывать «Создать партнёра» и подсказку.

## Критерии приёмки
- [ ] Нажатие «Создать партнёра» всегда даёт результат: карточка появилась **или** текстовая ошибка (не тишина).
- [ ] Есть видимый индикатор выполнения и таймаут.
- [ ] После выбора себя видно, что выбор сделан, и есть путь дальше.
- [ ] Проверено на прод-сборке владельцем.

## Результат

`0.77`/`v77` (`3a924c48`):

- Карточки подписаны **«Это я: <имя>»**; на экране — только свои (фильтр на бэкенде по `sub`).
