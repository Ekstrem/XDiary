# FE-017: Корреляции — Pearson считается на клиенте → `correlations` MV

- **Статус:** Закрыта
- **Приоритет:** P1 (директива PO: агрегаты на MV)
- **Источник:** @FE `chat/fe.md` 2026-11-03 14:00 (аудит `8-front`); BE-026
- **Зависимости:** BE-026 (`correlations` MV)
- **Проверяет:** @TL (TechLead)

## Проблема
`renderCorrelations` (`8-front/js/app.js`) считает Pearson-корреляции на клиенте (`pearson`, `records.map`, `arr.map`). По BE-026 `correlations` — MV от событий; клиент должен только рендерить готовое.

## Задача
- Убрать `pearson`/расчёты из `renderCorrelations`, брать готовые корреляции из Query API (BE-026).
- Поднять `APP_VERSION`/`CACHE`.

## Критерии приёмки
- [x] Клиент не считает корреляции (функция `pearson` удалена).
- [x] Вкладка «Корреляции» работает от API (`GET /api/v1/analytics/correlations`).
- [x] Версия `0.53`/`v53` забампана; CI — прогон @TE.

## Результат
- `8-front/js/api.js`: блок `analytics` — `summary`, `correlations`, `tops`, `distribution`.
- `8-front/js/app.js`: `pearson()` удалён; `renderCorrelations` рендерит `{label, coefficient, n, explanation}` из `/analytics/correlations` (пусто → «Недостаточно данных», ошибка → текст ошибки).
- Версия `0.53`/`v53`. MV донаполняется BE-033 — до него ответ может быть пустым/с малым `n`.
