# FE-040: Индикатор загрузки для тяжёлых экранов (тренды, экспорт)

- **Статус:** ToDo
- **Приоритет:** P2 (появляется вместе с бюджетом латентности DO-060)
- **Источник:** владелец 2026-11-10: для тяжёлых запросов «отдельный бюджет 3 c с индикатором загрузки — более чем приемлемо»; DO-060 (бюджет p95 для тяжёлых ≤ 3000 мс)
- **Зависимости:** DO-060 (бюджеты), FE-035 (версия в ошибках — уже сделано)
- **Проверяет:** @TL

## Задача (зона @FE, `8-front/`)

1. Для экранов, где запрос заведомо тяжёлый (**тренды/аналитика**, **экспорт**, **портируемость**): показывать **индикатор загрузки** сразу (< 300 мс после действия), а не пустой экран — «считаем…» + отмена, если операция долгая.
2. Не блокировать интерфейс целиком: остальные вкладки остаются доступными.
3. Если запрос не уложился в **3 с** — показать честный текст «дольше обычного» и кнопку «повторить» (без бесконечного спиннера).
4. Длительность запроса **не выдумывать**: брать из ответа/заголовка, если сервер отдаёт `Server-Timing`; иначе — измерять на клиенте и показывать только текст, без цифр.

## Критерии приёмки

- [ ] Индикатор появляется < 300 мс после нажатия и исчезает при ответе (успех/ошибка).
- [ ] При ответе > 3 с появляется текст «дольше обычного» + «повторить».
- [ ] На быстром ответе (< 1 с) индикатор не «мигает».
- [ ] Проверено на медленном стенде (искусственная задержка @DO) и на нормальном.
