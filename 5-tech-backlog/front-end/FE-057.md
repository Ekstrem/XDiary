## Задача
1. **Настройки → Соматика (Garmin):** добавить кнопку/диалог **«Подключить Garmin»** — поля ввода: `ApiKey`, `OauthToken`, `TokenExpiry` → `POST /api/v1/garmin/connect` (токен уходит на бэкенд, в браузере не хранится).
2. **Журнал → кнопка «Из Garmin»:** должна запускать **синк через шлюз** (`POST /api/v1/garmin/sync` / `fetch-activities`) и подтягивать занятия/соматику с сервера, **а не** открывать CSV-диалог. CSV-импорт оставить как запасной путь (отдельная кнопка «Импорт CSV Garmin…», как сейчас).
3. Показать состояние подключения: подключён/истёк токен (`GET /api/v1/garmin/state`, `ReauthOnExpiry`) + статус-бар синка (`G-06`).

## Критерии приёмки
- В настройках есть диалог подключения Garmin с тремя полями; после сохранения — `GET /state` показывает подключение.
- «Из Garmin» на журнале вызывает шлюз (в сети виден `/garmin/sync`, не `file input`), данные появляются в списке.
- CSV-импорт сохранён отдельной кнопкой и работает (регрессии нет).
- Истёкший токен даёт понятное сообщение, а не пустой экран.
