# FE-024: Убрать из UI выбор сервера — фронт смотрит только на прод

- **Статус:** Открыта
- **Приоритет:** P1 (через это поле можно уехать на dev и потерять PIN; решение владельца)
- **Источник:** владелец 2026-11-05: «во фронте не должно быть строки для подключения — только прод»
- **Зависимости:** DO-024 (E2E затирает PIN), AR-008

## Проблема
В Настройках есть блок «Сервер (API)»: `index.html:148-153` — `<input id="api-base">` («Адрес шлюза»). Значение пишется в `localStorage['xdiary.apiBase']` и **переживает обновления приложения**.

Последствия:
1. Пользователь (владелец) может случайно остаться на dev-адресе (`xdiary-vps2…`) — и тогда **его PIN живёт на dev**, где E2E/деплой ставит `1234` (инцидент 2026-11-05: «PIN сбросился до 1234»).
2. Адрес бэкенда — не пользовательская настройка: он один и задаётся конфигурацией сборки/деплоя.

## Задача
1. **Убрать из UI** блок «Сервер (API)» (`index.html` L148-153) и сохранение из настроек в `app.js`.
2. `api.js`: базовый адрес — **прод** (`DEFAULT_BASE = https://xdiary-vps1.taile0b6ee.ts.net`), `setBase` из UI убрать.
3. **Не ломать E2E:** он задаёт стенд через `page.addInitScript` → `localStorage['xdiary.apiBase']` (`9-tests/RnD/front-e2e/tests/api.js:11-13`). Сделать override **только для тестов**: читать `xdiary.apiBase` лишь при `window.__XDIARY_E2E__ === true`; @TE добавит этот флаг в init-script.
4. **Иначе игнорировать и вычищать** старый ключ: если `xdiary.apiBase` есть, но флага E2E нет — удалить ключ и идти на прод. Это лечит профили, уже «застрявшие» на dev.
5. В Настройках показать **только информационно** (readonly): «Сервер: xdiary-vps1…», чтобы при разборе было видно, куда идут запросы.
6. Поднять версию.

## Критерии приёмки
- [ ] В UI нет поля ввода адреса API; в Настройках — readonly-строка.
- [ ] Новый профиль всегда идёт на прод, без возможности переключить из UI.
- [ ] Профиль со старым `xdiary.apiBase` (dev) после обновления **сам** уходит на прод (ключ вычищается).
- [ ] E2E-прогон по-прежнему может ходить на `XDIARY_E2E_BASE_URL` (через `window.__XDIARY_E2E__`).
- [ ] `settings`-спек и `onboarding`/`pin-first-login` зелёные.
