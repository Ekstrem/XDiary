# FE-006: Клиент без PIN получает device-токен

- **Статус:** Открыта
- **Приоритет:** P0 (без этого PWA без PIN даёт 401 — блокирует живое тестирование)
- **Источник:** BE-019 (`90c2079` — device-токен готов), @TE 09:00; `8-front/js/app.js`
- **Зависимости:** BE-019

## Проблема
API теперь выдаёт device-токен без PIN (`IssueTokenHandler` → `_tokens.IssueDevice()`), но **клиент его не запрашивает**:
- `app.js:182` `ensureToken(pin)` вызывается только в unlock (с PIN);
- в ветке `!hasPin` (`app.js:188`) сразу `showView("journal")` — без токена → 401 на любом запросе.

## Задача
В ветке `!hasPin` получить device-токен (`Api.auth.token("")` / `login("")`), сохранить в `xdiary.accessToken`, затем `showView("journal")`. Учесть истечение (TTL 5 мин) — refresh/повторный запрос при 401.

## Критерии приёмки
- [ ] Без PIN: журнал/партнёры/каталог читаются и пишутся (нет 401).
- [ ] С PIN: поведение не меняется.
- [ ] CI green (`front-e2e`).
