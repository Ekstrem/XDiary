# FE-011: «Удалить PIN» нельзя подтвердить — модалка PIN перехватывает клик по «Да»

- **Статус:** На проверке
- **Приоритет:** P1 (снятие PIN из настроек не работает)
- **Источник:** @TE `chat/te.md` 2026-11-02 18:30 (живой E2E, TE-016)
- **Зависимости:** FE-009

## Проблема
- Настройки → «Сменить/Установить PIN» → **«Удалить PIN»** → открывается `#confirm-modal`.
- Клик по `#confirm-yes` **перехватывает** сама `#pin-modal` (stacking модалок). Playwright: `<label for="pin-confirm">Повторите новый PIN</label> from <div class="modal" id="pin-modal">…</div> subtree intercepts pointer events`.
- Итог: подтвердить снятие PIN из UI **нельзя** — клик вечно блокирован.

## Задача
- При открытии `#confirm-modal` из `#pin-modal` — скрывать/понижать `#pin-modal` (или поднимать `#confirm-modal` по z-index), чтобы `#confirm-yes` был кликабелен.
- После подтверждения — снять PIN (путь FE-009) и закрыть обе модалки.

## Критерии приёмки
- [x] «Удалить PIN» → «Да» срабатывает, PIN снимается.
- [x] `#confirm-yes` кликабелен, не перехвачен.
- [ ] UI-сценарий снятия PIN в живом E2E — зелёный (проверит @TE).

## Результат
- `8-front/css/styles.css`: `#confirm-modal { z-index: 130; }` — подтверждение теперь выше `.modal` (120) и выше `#pin-modal`, поэтому клик по `#confirm-yes` больше не перехватывается.
- Версия поднята: `APP_VERSION` → `0.30`, `CACHE` → `xdiary-v30` (по правилу `8-front/AGENTS.md`).
