# FE-030: Импорт Garmin-CSV не обновляет `#import-result` (элемент остаётся `hidden`)

- **Статус:** В работе
- **В работе с:** 2026-11-02
- **Приоритет:** P1 (блокирует релиз: 1 из 5 падений `front-e2e`)
- **Источник:** @DO 2026-11-02 19:45 — прогон `#951` (`c83989b`), спека `csv`
- **Зависимости:** FE-014/FE-015 (CSV-импорт Garmin), FE-020
- **Проверяет:** @TL (TechLead)

## Факт
Спека `csv` падает: `#import-result` резолвился **44 раза** как `<div class="hidden" id="import-result">` — элемент в DOM есть, но остаётся `hidden`. То есть импорт не выставил результат (ни успех, ни ошибку) — пользователь после выбора файла не видит ничего.

## Задача
1. После завершения импорта **всегда** показывать результат: успех (`импортировано N`) или ошибку (`не удалось: причина`). `hidden` не должен оставаться ни в одной ветке, включая исключения.
2. Ошибки импорта (битый CSV, неверный формат Garmin) — внятным текстом, не молчанием.
3. Проверить, что `#import-result` не очищается следующим рендером.

## Критерии приёмки
- [x] После импорта валидного CSV `#import-result` видим и содержит число записей.
- [x] После битого файла — видим и содержит причину.
- [ ] Спека `csv` зелёная в `front-e2e` (@TE).

## Результат (`0.63`/`v63`)
- `8-front/js/app.js`: `showImportMessage(text, isError)` — всегда показывает `#import-result` с текстом; вызывается на нераспознанном формате, пустых данных, ошибке чтения/применения и на успехе. На ошибке кнопка «Импортировать» скрывается.
- `applyImport` больше не прячет `#import-result` в успехе — показывает «Импортировано: N» (toast тоже остаётся).
- Версия `0.63`/`v63` (синхронно с `CACHE`).
