# FE-002: Аутентификация JWT на фронте

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** ADR-008, US-11
- **Зависимости:** BE-010, BE-012

## Задача
Подключить аутентификацию на фронте:
- Логин → получение JWT (access + refresh).
- Хранение токенов, отправка `Authorization: Bearer` на шлюз.
- Refresh при истечении access.
- Локальный PIN остаётся как доп. слой блокировки приложения.

## Критерии приёмки
- [ ] Все запросы к API идут с JWT.
- [ ] При 401 — перевыпуск по refresh (без потери сессии).
- [ ] PIN (PBKDF2) работает локально как раньше.
- [ ] Logout очищает токены.
