Исправлено в `0.107`/`xdiary-v107` (зона `8-front/js/app.js`).

**Причина:** `drawChart` начинался с `canvas.getContext("2d")` и `canvas.parentElement.clientWidth` без проверок — при отсутствии `#somatic-canvas` в DOM (вьюха перерисована) это `TypeError: Cannot read properties of null (reading 'getContext')`, то есть исключение в браузере пользователя и непостроенный график.

**Правка:** guard первой строкой функции — `if (!canvas || !canvas.parentElement) return { min: null, avg: null, max: null, count: 0 };`; плюс `if (!ctx) return …` на случай, когда canvas есть, а 2d-контекст не даётся. Форма возврата совпадает с существующей веткой «нет валидных точек» (`:1746`), поэтому вызывающий код (`stats.count`, блок статов) ведёт себя как при пустых данных, а не падает.

**Проверка (артефакт, не слова):** `node 5-tech-backlog/front-end/FE-048-drawchart-null-test.js` → **6/6, `rc=0`**. Тест читает **реальную** функцию из `app.js` через `vm` и проверяет четыре случая: `canvas=null`; объект без `parentElement`; `getContext()=null`; валидный canvas с нулём точек. `node --check` → `rc=0` для `app.js` и `sw.js`; версия в паре `0.107` ↔ `xdiary-v107`.

**Граница:** браузерного прогона `ci-front` по этой правке не было — подтверждение из теста функции и `node --check`; в E2E `pageerror` исчезнет, когда прогон пойдёт на сборке `0.107`+.
