# FE-018: Онбординг «кто я» + опциональный PIN (AR-004, ADR-021)

- **Статус:** Открыта
- **Приоритет:** P1 (Фаза 1: идентификация/аутентификация)
- **Источник:** AR-004 → P1 (@AR 2026-11-04 00:00); ADR-021 (пересмотрен 02:30: многопользовательская, номер телефона + SMS OTP)
- **Зависимости:** BE-029 (BC «Клиент»), ADR-021

## Контекст
Фаза 1. **ADR-021 пересмотрен (2026-11-04):** идентификация по **номеру телефона** + SMS OTP (BC «Клиент»), «я» = **пользователь**, PIN опционален. Старый `view-onboarding` («кто ты = партнёр», `0.43`) — **каркас**, не откатывать: на нём делаем шаг «телефон + SMS OTP».

## Задача
- Первый запуск: онбординг — **номер телефона + SMS OTP** → «я» = пользователь.
- PIN — **опция** (можно пропустить).
- Настройки: «это я» / профиль пользователя.
- Поднять `APP_VERSION`/`CACHE`.

## Критерии приёмки
- [ ] Новый пользователь проходит онбординг: номер телефона + SMS OTP → «я» = пользователь.
- [ ] PIN можно не задавать.
- [ ] Версия забампана; E2E (TE-025) зелёный.

## Результат (частично — каркас)
- `0.43`/`v43`: реализован старый онбординг «кто ты = партнёр» (`view-onboarding`, `partners.setSelf`, «Это я»). По пересмотренному ADR-021 **не откатывается** — используется как каркас для шага «телефон + SMS OTP». Переработка — после BC «Клиент» (@AR) и задач @BE.
