# FE-018: Онбординг «кто я» + опциональный PIN (AR-004, ADR-021)

- **Статус:** На проверке
- **Приоритет:** P1 (Фаза 1: идентификация/аутентификация)
- **Источник:** AR-004 → P1 (@AR 2026-11-04 00:00); ADR-021 (Предложено)
- **Зависимости:** BE-028, ADR-021

## Контекст
Фаза 1. Сейчас «я» = устройство (`myGender` локально), онбординга нет (TE-024). По ADR-021 «я» = партнёр, онбординг + опциональный PIN.

## Задача
- Первый запуск: экран онбординга «кто ты» — создать/выбрать партнёра как «я» (`self`).
- PIN — **опция** (можно пропустить).
- Настройки: «это я» (сменить/снять), без обязательного PIN.
- Поднять `APP_VERSION`/`CACHE`.

## Критерии приёмки
- [x] Новый пользователь проходит онбординг, «я» = партнёр.
- [x] PIN можно не задавать.
- [x] Версия забампана (`0.43`/`v43`); E2E (TE-025) — прогон @TE.

## Результат
- `8-front/index.html`: view `view-onboarding` («Кто ты?» — partner-grid + «Создать партнёра» + «Пропустить») + секция «Это я» в настройках («Сменить «я»» / «Снять «я»»).
- `8-front/js/api.js`: `partners.setSelf(id, self)` → `POST /partners/{id}/self`.
- `8-front/js/repository.js`: `mapPartner` пробрасывает `self`.
- `8-front/js/app.js`: `afterAuth()` после токена — если `self` не выбран → онбординг, иначе журнал; `openOnboarding()`/`renderSelfStatus()`; онбординг **не требует PIN** (опционален); «Сменить/Снять «я»» в настройках.
- Версия `0.43`/`v43`.
