## Задача

`read-paths.md` §3 п.1: **молчаливый `catch` запрещён** — при недоступном read-path форма должна
показать ошибку, а не подставить данные. Спека `wizard-offline.spec.js` проверяет три инварианта:
(а) визард **открывается**; (б) ошибка **видна** в `#view-wizard`/`#toast`;
(в) **нет ложной подстановки** (`.partner-card.selected` = 0).

## Критерии приёмки

- в `8-front/js/repository.js` (и вызывающем коде) нет `catch`-блоков, гасящих ошибку read-path без
  пользовательского сигнала: `git grep -n 'catch' -- 8-front/js/repository.js` — каждый блок либо
  пробрасывает, либо ставит состояние ошибки, видимое в UI;
- при `XDIARY_READPATH_OFFLINE=1` визард открывается, ошибка видна, подстановки нет (проверяет @TE);
- `node --check` по изменённым файлам + строка статуса в чат;
- версия фронта поднята, если поведение меняется для пользователя (`APP_VERSION` ↔ `CACHE`).
