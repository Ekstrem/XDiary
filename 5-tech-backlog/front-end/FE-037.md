# FE-037: Нет кнопки добавления из Garmin

- **Статус:** В работе
- **Приоритет:** P2 (функция заявлена, но недоступна из интерфейса; влияет на «всё в одном месте»)
- **В работе с:** 2026-11-10
- **Источник:** владелец 2026-11-09 03:5x: «не вижу кнопки добавления из гарминов»
- **Зависимости:** BC-GarminGateway (сервис существует), BE-0xx (импорт), FE-036 (старт приложения)
- **Проверяет:** @TL (TechLead)

## Проблема
В интерфейсе нет способа инициировать импорт из Garmin (и Apple Health), хотя сервисы `garmin-gateway` / `apple-health-gateway` в стеке есть. Владелец ожидал кнопку «добавить из Garmin» — например, в «Трендах» или «Журнале».

## Задача
1. **Проверить, что готово на бэке:** какой контракт импорта есть у `garmin-gateway` (синхронизация? ручной импорт файла? OAuth?), и что реально работает на проде (вызвать маршрут, прислать ответ).
2. **Найти место в UI** по продукту: секция «Тренды» (или «Настройки → Интеграции») → кнопка «Подключить Garmin» / «Импортировать из Garmin».
3. **Состояние и обратная связь:** «Не подключено» → инструкция подключения; «Подключено» → «Последняя синхронизация: …»; ошибка — текстом, не молчанием.
4. Если импорт на бэке не реализован — **не рисовать кнопку-обманку**: вместо неё завести задачу на @BE и написать в UI честно «скоро».

## Критерии приёмки
- [ ] В UI есть точка входа для Garmin, и она либо работает до результата, либо честно помечена как недоступная.
- [ ] Владелец видит, где это находится (скриншот).
- [ ] Если нужен бэкенд — задача @BE заведена и связана.

## Ответ владельца (2026-11-10, продуктовый вопрос закрыт)

**Точка входа — «Настройки → Интеграции»** (не «Тренды»).

**Реализация:** в разделе настроек — блок «Интеграции» с пунктом **Garmin**; пока импорт на бэке не готов (инк. 3, G-01) — кнопка **неактивна** с честной пометкой «скоро», без обманки «подключить». Когда `BC-GarminGateway` отдаст импорт — включаем кнопку, экран остаётся там же.
