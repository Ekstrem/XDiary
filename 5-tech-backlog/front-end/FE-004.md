# FE-004: Убрать легаси «Автосинхронизация (прокси на ПК)» из PWA

- **Статус:** Открыта
- **Приоритет:** P2
- **Источник:** дефект PWA (тестер, `chat/te.md`), `8-front`
- **Зависимости:** FE-001

## Проблема
В новом фронте (`8-front/`, экран «Настройки») остался блок «Автосинхронизация (прокси на ПК)» — легаси старого приложения. Сейчас данные идут через API-шлюз (и `ApiGateway`), локальный прокси не нужен.

## Задача
Убрать блок «Автосинхронизация (прокси на ПК)» и связанный UI-код из `8-front/`. Garmin-импорт (CSV/файл) оставить — он идёт через локальный парсинг/API.

## Критерии приёмки
- [ ] В настройках нет блока «прокси на ПК».
- [ ] Garmin-импорт работает (CSV-файл через UI).
- [ ] CI green.
