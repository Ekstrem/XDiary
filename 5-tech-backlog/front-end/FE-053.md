# FE-053: `renderSomatic` бросает `TypeError` при отсутствии `#somatic-stats` в DOM

- **Статус:** На проверке
- **Приоритет:** **P1** (необработанное исключение в прогоне фронта: `TypeError: Cannot set properties of null (setting 'textContent') at app.js:1806`; спеки вьюхи соматики/настроек падают или врут про «пусто»)
- **Источник:** `front-e2e` run **`43842550626`** (`role/fe`, head `d774ed34a`, `0.118`-pre), аннотация `{"title":"browser pageerror","error":"TypeError: Cannot set properties of null (setting 'textContent')\n    at http://127.0.0.1:4173/js/app.js:1806:23"}`
- **Зависимости:** нет (правка в `8-front/js/app.js`)
- **Проверяет:** @TL
- **На проверке с:** 2026-11-16
- **Артефакт:** `8-front/js/app.js` (`renderSomatic`, guard `if (!s) return;`), версия `0.118` / `xdiary-v118`; тест `5-tech-backlog/front-end/FE-053-somatic-null-test.js`

## Задача (зона @FE, `8-front/`)

`renderSomatic()` читал `var s = $("somatic-stats")` и писал в него `s.textContent` **без проверки на null** — ровно тот класс, который уже закрывали в `FE-048` для `canvas`: если вьюха перерисована / элемента нет в DOM, браузер бросает `TypeError` и весь рендер соматики обрывается (пользователь видит пустую вьюху без объяснения).

**Правка:** после получения элемента добавлен guard `if (!s) return;` — рендер прекращается молча, но без исключения и без полусломанного DOM.

## Критерии приёмки

- [x] Без `#somatic-stats` в DOM нет ни синхронного исключения, ни `unhandledRejection`;
- [x] С `#somatic-stats` нормальный путь работает (поле обновляется);
- [x] Runtime-тест на **реальной** функции: `node 5-tech-backlog/front-end/FE-053-somatic-null-test.js` → **5/5, rc=0**;
- [x] **Негативный контроль:** тот же код без guard даёт отказ (проверка ловит регресс);
- [x] `node --check` rc=0; версия в паре `0.118` ↔ `xdiary-v118`.

## Результат

**Сделано в `0.118`/`xdiary-v118`.** В `renderSomatic()` после `var s = $("somatic-stats")` добавлен `if (!s) return;` — при отсутствии элемента функция больше не пишет в `null.textContent` и не валит промис-цепочку. Это тот же дефект-класс, что `FE-048` (canvas), но для блока статистики: `FE-048` закрыл `drawChart`, а `somatic-stats` остался незащищённым.

**Квитанция (runtime, не грепом):** `node 5-tech-backlog/front-end/FE-053-somatic-null-test.js` → **5/5, `rc=0`**: тест **исполняет настоящую `renderSomatic`** из `app.js` в `vm` со стабами DOM/`Api` и ловит **`unhandledRejection`** (ошибка возникает внутри `.then`, поэтому `try/catch` её не видит — это отдельная ловушка, которую тест обходит намеренно). Негативный контроль: без `if (!s) return;` тот же сценарий даёт **1 отказ** → тест падает.

**Граница:** исправлен фронт; причина появления «пустых» экранов `somatic` в прогоне (в том же логе — `http 429` на `/api/v1/clients`) — стенд/rate-limit, зона @DO.
