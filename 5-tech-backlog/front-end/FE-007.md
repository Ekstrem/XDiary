# FE-007: На стенде с PIN — показывать ввод PIN вместо 401

- **Статус:** Открыта
- **Приоритет:** P1 (новое устройство без локального PIN видит 401 на «Сохранить»)
- **Источник:** @TE 12:00 — живой `front-e2e` поймал дефект (`13edb99`); FE-006 закрыл только стенд без PIN
- **Зависимости:** FE-006, BE-019

## Проблема
На стенде PIN задан; клиент без локального PIN:
`lock()` → `!hasPin` → `Api.auth.login("")` → **401** (сервер ждёт PIN) → токена нет → «Сохранить» даёт 401 — ровно то, что видит пользователь на новом устройстве.
FE-006 (`login("")` → журнал) покрывает только стенд **без PIN**.

## Задача
Если `login("")` вернул 401 — **показать экран ввода PIN** (lock), а не открывать журнал. После ввода: `login(pin)` → журнал. Ошибку `login("")` не глотать.

## Критерии приёмки
- [ ] На стенде с PIN новое устройство видит экран PIN (не журнал с 401).
- [ ] После ввода PIN журнал/партнёры/каталог работают.
- [ ] Живой E2E (PIN-стенд) зелёный; сценарий `no-pin` — на стенде без PIN.
