# FE-001: Перевести PWA с IndexedDB на API (journal / partners / catalog)

- **Статус:** Открыта
- **Приоритет:** P0
- **Источник:** ADR-006, US-01..09, `03-ddd/BC-Journal`
- **Зависимости:** BE-002, BE-003, BE-004, BE-012

## Задача
Перевести фронтенд с локального IndexedDB на бэкенд через шлюз:
- Записи (журнал): создать/редактировать/удалить через `POST/PUT/DELETE /api/v1/journal/...`.
- Чтение журнала и детали через `GET /api/v1/...`.
- Партнёры и каталог — через API.

## Критерии приёмки
- [ ] Формы визарда шлют команды в бэк (не пишут в IndexedDB).
- [ ] Журнал/деталь читаются из query-API.
- [ ] Офлайн-режим: при недоступности API — понятное сообщение.
- [ ] DTO совпадают с Command/Query API (`03-ddd/BC-Journal/03/04-*-api.md`).
