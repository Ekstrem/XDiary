# ADR-005: Event Bus

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Команда публикует доменное событие в IEventBus; потребители (Projectors, Saga) читают из шины.

## Решение (варианты)
- **InMemory** — `AddEventBusInMemory`. Для одного процесса (Single/BudgetCqrs).
- **Postgres Outbox** — `AddEventBusPostgres`. Транзакционная публикация без внешнего брокера.
- **Kafka** — для Ceqrs/масштаба; избыточно для двух пользователей.
