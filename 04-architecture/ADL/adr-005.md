# ADR-005: Event Bus

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 002, 009

## Контекст
Команда публикует доменное событие в `IEventBus`; потребители (Projectors, Saga, Outbound Handler) читают из шины.

## Решение
**Postgres Outbox** (`AddEventBusPostgres`) — транзакционная публикация событий без внешнего брокера; для локальной разработки — **InMemory**.

**Обоснование:** надёжность (событие и состояние в одной транзакции), нет зависимости от Kafka при двух пользователях.

## Последствия
- **Плюсы:** простота, согласованность с Postgres.
- **Риски:** при переходе на Ceqrs/несколько сервисов — вынести шину в Kafka (будущий ADR).

## Проверки
- Согласовано с ADR-002 (BudgetCqrs — шина в процессе), ADR-009 (Postgres на ВМ-2).
- Кросс-ссылка: события агрегатов из `03-ddd/*/02-aggregate-canvas.md` (RecordCreated, SomaticImported, …).
