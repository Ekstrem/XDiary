# ADR-009: Развёртывание на двух ВМ

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Следующий этап — две виртуальные машины: одна с Docker (приложения), другая с Postgres (данные). Нужно зафиксировать раскладку компонентов.

## Решение (варианты)
- **ВМ-1 (Docker):** .NET-сервисы + шлюз + прокси Garmin.
- **ВМ-2 (Postgres):** Command DB (event store) + Read DB (ReadModel) + Outbox (если выбран).
- Сеть: ВМ-1 ↔ ВМ-2 по внутренней сети; PWA (телефон) → ВМ-1 (шлюз) по HTTPS.

## Последствия
Заполнить после принятия (сетевые доступы, бэкапы Postgres, мониторинг состояния ВМ).
