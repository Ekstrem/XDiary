# ADR-009: Развёртывание на двух ВМ

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001, 003, 004, 010
- **Бэклог:** кросс-кат (развёртывание на двух ВМ)

## Контекст
Следующий этап — две виртуальные машины: одна с Docker (приложения), другая с Postgres (данные).

## Решение
- **ВМ-1 (Docker):** `journal-svc`, `somatics-svc`, `analytics-svc`, шлюз (YARP + identity), Garmin-ACL (внутри somatics-svc).
- **ВМ-2 (Postgres):** единый кластер с БД: event store, ReadModel-схема, outbox.
- **Сеть:** PWA (телефон) → ВМ-1 (шлюз) по HTTPS; ВМ-1 ↔ ВМ-2 по внутренней сети (Postgres 5432).

## Последствия
- **Плюсы:** разделение вычислений и данных, проще бэкапить Postgres.
- **Требование:** файрвол/сеть между ВМ, TLS на шлюзе.

## Проверки
- Согласовано с ADR-003/004 (Postgres на ВМ-2), ADR-010 (Compose на ВМ-1).
- Кросс-ссылка: сервисы = ADR-001 (3 шт.).
