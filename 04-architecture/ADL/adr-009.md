# ADR-009: Развёртывание на двух ВМ

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001, 003, 004, 010
- **Бэклог:** кросс-кат (развёртывание на двух ВМ)

## Контекст
Следующий этап — две виртуальные машины: одна с Docker (приложения), другая с Postgres (данные).

## Решение
- **ВМ-1 (Docker):** 10 микросервисов (`journal`, `partners`, `catalog`, `somatic-series`, `daily-metrics`, `garmin-gateway`, `apple-health-gateway`, `analytics`, `privacy`, `portability`) + шлюз (YARP + identity).
- **ВМ-2 (Postgres):** кластер; по одной БД на сервис (event store + read вместе, профиль Single — без отдельной схемы ReadModel).
- **Сеть:** PWA (телефон) → ВМ-1 (шлюз) по HTTPS; ВМ-1 ↔ ВМ-2 по внутренней сети (Postgres 5432).

## Последствия
- **Плюсы:** разделение вычислений и данных, проще бэкапить Postgres.
- **Требование:** файрвол/сеть между ВМ, TLS на шлюзе.

## Проверки
- Согласовано с ADR-002 (Single), ADR-003/004 (Postgres), ADR-010 (Compose на ВМ-1).
- Кросс-ссылка: сервисы = ADR-001 (10 шт.).
