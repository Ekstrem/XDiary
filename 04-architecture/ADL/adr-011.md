# ADR-011: Миграция данных из IndexedDB/CSV

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001, 003

## Контекст
Текущие данные (журнал, каталог, партнёры, соматика) лежат в IndexedDB и выгружаются в CSV. При переходе на бэк их нужно перенести, не потеряв историю.

## Решение
**CSV как мост** — выгрузить всё в CSV (текущий `downloadCsv`), затем идемпотентно импортировать в бэк через команды (upsert по `id`). Соматика/сон/стресс импортируются отдельными CSV.

**Обоснование:** CSV уже есть как формат переноса (`app/js/app.js`: `recordsToCsv`, `csvToRecords`, `handleImportAnyFile`).

## Последствия
- **Плюсы:** использует существующий формат, без потерь id.
- **Риски:** нужно сохранить связи (`garminId`, `startedAt`, массивы через `;`).

## Проверки
- Кросс-ссылка на код: CSV-заголовки `CSV_HEADERS` в `app/js/app.js`; колонки `contraceptives`, `orgasm_*_type`, `garmin`.
- Согласовано с ADR-001 (импорт в journal/somatics), ADR-003 (команды → события).
