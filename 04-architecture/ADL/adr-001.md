# ADR-001: Разбиение на микросервисы

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Сейчас — монолитная PWA (IndexedDB + локальный Python-прокси для Garmin). Цель — микросервисы на .NET (EDM/CEQRS). В `03-ddd` выделено 8 ограниченных контекстов: Журнал, Партнёры, Каталог, Соматика (минутные точки), Дневные метрики, Аналитика, Приватность, Переносимость данных.

## Решение (варианты)
- **A. Модульный монолит** — один сервис, 8 модулей; декомпозиция отложена.
- **B. Сервис на контекст** — 8 микросервисов (избыточно для двух пользователей).
- **C. Сервис на доменную группу** — например: «Журнал+Партнёры+Каталог» (запись), «Соматика+Дневные метрики+Аналитика» (данные), «Приватность» (доступ), «Переносимость» (утилита).

## Последствия
Заполнить после принятия (влияние на командование/транзакции, межсервисные связи, сложность эксплуатации).
