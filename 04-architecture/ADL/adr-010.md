# ADR-010: Оркестрация контейнеров

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 009

## Контекст
Нужно решить, чем поднимать контейнеры на одной ВМ.

## Решение
**Docker Compose** — один `compose.yml` со всеми сервисами и зависимостями.

**Обоснование:** одна ВМ, два пользователя — Kubernetes (k3s) избыточен.

## Последствия
- **Плюсы:** простота, воспроизводимость, низкий порог входа.
- **Риски:** ограниченные возможности самовосстановления (приемлемо для текущего масштаба).

## Проверки
- Согласовано с ADR-009 (ВМ-1).
- Кросс-ссылка: состав сервисов = ADR-001.
