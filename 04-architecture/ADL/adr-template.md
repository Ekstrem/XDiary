## 0. ПЕРЕД РЕШЕНИЕМ — три команды, без них ADR не пишется

> Появилось после двух моих ошибок 2026-11-14: ADR-029 дублировал ADR-003/005 + `edm-verification.md`, а ADR-028
> не имел ни карточки, ни вопроса владельца. Причина одна — **писал из памяти/переписки, а не из документов**.

```bash
# Работает и в bash, и в PowerShell — используем git grep (git есть везде), не grep.
# 1) Решение уже принято? (ключевые слова темы, а не название ADR)
git grep -n -i -e "<термин>" -e "<синоним>" -- 04-architecture/ADL 04-architecture/edm-verification.md 03-ddd/TECHDEBT.md
#    нашлось → ADR НЕ пишем: работаем по нему либо делаем «уточняет ADR-XXX» с явной ссылкой

# 2) Отклонение кода уже описано? (EDM-аудит / реестр техдолга)
git grep -n -i -e "<термин>" -- 04-architecture/edm-verification.md 03-ddd/TECHDEBT.md
#    нашлось → это gap в КОДЕ: задача исполнителю (@BE/@DO), а не ADR

# 3) Источник решения существует?
git grep -n -e "AR-" -e "BE-" -e "DO-" -- 5-tech-backlog | grep -i "<термин>"
#    пусто → сначала карточка (Идея/На проработке) или прямой вопрос владельца, потом ADR
```

**Проверено на живом примере (2026-11-14), что команды ловят дубликат:** для темы «доставка событий» шаги 1–2 дают
`ADR-003`, `ADR-005`, `edm-verification.md` — то есть ADR-029 не надо было писать; а шаг 3 по той же теме даёт
**пусто** (карточки не было).

**Правило-итог:** если (1) пусто **и** (2) пусто **и** (3) есть — ADR пишется. Иначе — не пишется.
Не «переписка ролей» и не «я заметил в коде»: это не источник.
