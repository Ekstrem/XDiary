# ADR-015: TLS и доступ к PWA без доменного имени

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 006, 008, 009
- **Бэклог:** DO-004 (TLS/доступ), AR-001 (задача архитектору)

## Контекст
У заказчика **нет доменных имён**. Let's Encrypt (HTTP-01) требует домен → без него валидный TLS-сертификат не выпустить. Ограничение PWA: Service Worker и secure-context API требуют **HTTPS или localhost**. Приложение приватное (пара, 2 устройства).

## Решение

## Решение
**Tailscale (VPN) + MagicDNS + `tailscale cert` (Let's Encrypt)**:

- Телефоны пары и VPS-1 вступают в один **tailnet** (частная VPN-сеть).
- Доступ — по **MagicDNS-имени** (`xdiary.vps1.ts.net`), публичный 443 **не открывается**.
- TLS — `tailscale cert xdiary.vps1.ts.net` выдаёт **валидный Let's Encrypt-сертификат** (DNS-01, автопродление).
- Шлюз (YARP/Kestrel или caddy) терминирует HTTPS этим сертификатом.

## Обоснование
- **Валидный сертификат → secure context → Service Worker работает** (главное требование PWA).
- **Нет публичного доступа** (приватность пары) — в отличие от публичного DDNS.
- **Ноль доменов**: Tailscale бесплатно даёт имя и сертификат (до 3 пользователей).

## Альтернативы (отклонены)
- **A/D — self-signed (не доверенный):** нет secure context → Service Worker не поднимется; предупреждение в браузере; ручное закрепление отпечатка — хрупко.
- **B — только VPN без TLS:** доступ по `http://IP` по-прежнему HTTP → не secure context → PWA не работает.
- **C — публичный DDNS (duckdns/nip.io) + Let's Encrypt:** валидный TLS, но сервис публично доступен → риск приватности.

## Последствия
- Клиент Tailscale на телефонах (App Store) и на VPS-1.
- VPS-2 остаётся недоступной извне (только приватная сеть VPS-1↔VPS-2).
- Для управления SSH можно тоже пропустить через Tailscale (или белый IP).
- Требуется **авторизация**: вход в Tailscale-аккаунт (на телефонах пары и VPS) + включение MagicDNS / HTTPS Certificates в админке.

## Проверки
- PWA: HTTPS с валидным сертификатом (secure context) — Service Worker регистрируется.
- Инструкция DevOps: `vps-setup.md` §2.3 обновлена (Tailscale).
