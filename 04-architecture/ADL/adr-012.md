# ADR-012: Интеграция носимых устройств (Garmin / Apple Watch)

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001
- **Бэклог:** Инк 3 (G-01..G-05, AW-01); Инк 7 (GA-01..GA-03 автоперенос)

## Контекст
Источники соматики — носимые устройства: **Garmin** (Personal API, без CORS) и **Apple Watch / Apple Health** (только ручной экспорт из «Здоровье», HealthKit из браузера недоступен). Соматика хранится в едином формате независимо от источника. Сейчас данные тянутся в CSV через Python-прокси.

## Решение
**Anti-Corruption Layer внутри `somatics-svc`** — инкапсулирует оба источника:
- **Garmin:** Personal API (ключ, OAuth-токен, кэш 23 ч).
- **Apple Health:** импорт ручного экспорта `export.xml`/CSV (пульс, HRV, сон, пульс покоя).

Отдаёт нормализованные DTO в единый формат. Метрики, которых нет у источника, просто отсутствуют (Body Battery и «стресс» — специфика Garmin).

## Последствия
- **Плюсы:** изоляция моделей производителей, единый формат соматики.
- **Риски:** хранение ключа Garmin `.env`; парсинг `export.xml`; рейт-лимиты Garmin.

## Проверки
- Бэклог: AW-01 (Apple Watch), G-01 (выбор источника Garmin/Apple Health), G-02 (единый формат).
- Кросс-ссылка на DDD: `03-ddd/BC-SomaticSeries` и `BC-DailyMetrics` (роль Gateway, ACL к источникам).
