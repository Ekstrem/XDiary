# ADR-012: Интеграция Garmin

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001
- **Бэклог:** Инк 3 (G-01..G-05 соматика); Инк 7 (GA-01..GA-03 автоперенос)

## Контекст
Garmin не отдаёт CORS; сейчас данные тянутся в локальные CSV через Python-прокси (`tools/garmin_proxy.py`), приложение читает локально. В целевой архитектуре — сервис `somatics-svc`.

## Решение
**Anti-Corruption Layer внутри `somatics-svc`** — инкапсулирует Garmin Personal API (ключ, OAuth-токен, кэш), отдаёт нормализованные DTO. Прокси как отдельный внешний процесс убираем.

**Обоснование:** ACL — часть сервиса-шлюза (Somatics); один владелец интеграции с Garmin.

## Последствия
- **Плюсы:** изоляция модели Garmin, единое место синка.
- **Риски:** хранение ключа `.env`, расписание синка, рейт-лимиты Garmin.

## Проверки
- Кросс-ссылка: текущий ACL — `tools/garmin_sync.py` + `tools/garmin_proxy.py` (эндпоинты `/local/*`, кэш токена 23 ч).
- Кросс-ссылка на DDD: `03-ddd/BC-SomaticSeries` и `BC-DailyMetrics` (роль Gateway, ACL к Garmin).
