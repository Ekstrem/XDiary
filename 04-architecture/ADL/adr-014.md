# ADR-014: Наблюдаемость

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Нужно видеть, что происходит в сервисах (ошибки, события, производительность) при минимальных вложениях.

## Решение (варианты)
- **Структурированные логи (Serilog)** + консоль/файл — минимально.
- **OpenTelemetry** — трассировка команд → событий → проекций.
- **Prometheus + Grafana** — метрики (избыточно для двух пользователей).

## Последствия
Заполнить после принятия (объём данных, хранение логов, алерты).
