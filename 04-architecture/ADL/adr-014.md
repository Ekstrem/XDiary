# ADR-014: Наблюдаемость

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001
- **Бэклог:** кросс-кат (наблюдаемость)

## Контекст
Нужно видеть ошибки, события и производительность сервисов при минимальных вложениях.

## Решение
**Структурированные логи (Serilog)** + **OpenTelemetry** (трассировка «команда → событие → проекция»). Prometheus/Grafana — позже, при необходимости.

**Обоснование:** для двух пользователей достаточно логов и трассировки; метрики — следующий шаг.

## Последствия
- **Плюсы:** видимость цепочки CEQRS, быстрый разбор ошибок.
- **Риски:** объём логов — настроить уровни/ротацию.

## Проверки
- Кросс-ссылка: трассировка покрывает цепочку из edm-net (Controller → MediatR → Aggregate → EventBus → Projector).
- Согласовано с ADR-001 (3 сервиса).
