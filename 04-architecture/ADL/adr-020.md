# ADR-020: CD pipeline (prod/dev)

- **Статус:** Принято
- **Дата:** 2026-11-02
- **Связанные ADR:** 019 (prod/dev), 010 (compose), 013 (контракты API)
- **Бэклог:** DO-015

## Контекст
Деплой работает **pull-based** (cron на VPS, без SSH-секретов). Фиксируем фактическую схему CD (as-is).

## Среды
- **prod** = VPS-1 (`31.192.111.168`) — rootless podman + `heal-network.sh` (таймер 1 мин, баг rootlessport).
- **dev** = VPS-2 (`77.91.73.67`) — root podman (стабильнее, heal не нужен).

## Решение (pull-based cron)
1. **CI (push/PR в `main`):** `ci-*.yml` (11 шт.) → GHCR `ghcr.io/ekstrem/xdiary-<svc>`: теги `:single` (мутаб.), `:latest` (мутаб.), `:single-<SHA>` (иммутаб.).
2. **Deploy dev (авто):** cron 15 мин на VPS-2 → `update.sh` → pull `:single` → `deploy.sh` (recreate 12 контейнеров) при смене хэша.
3. **Smoke/E2E dev (авто, против dev `XDIARY_E2E_BASE_URL=https://xdiary-vps2.taile0b6ee.ts.net`):** blocking — `/health` 200 + API-E2E 9/9 + ключевые UI; неблокирующие — остальное.
4. **Deploy prod (гейт):** `podman-auto-update.timer` 15 мин на VPS-1 → `update.sh`, но гейт `sudo test -f /etc/xdiary/prod-release`; без флага — `skip`. Флаг удаляется после деплоя (one-shot). **Релиз** = `sudo touch /etc/xdiary/prod-release` (или вручную `update.sh single-<SHA>`).
5. **Post-deploy:** stats / guard / sync.

## Инфраструктура (обе среды)
podman 3.4.4 + сеть `xdiary` (CNI 0.4.0, `10.89.9.0/24`) + **12 контейнеров** (10 сервисов + шлюз + PostgreSQL 16 co-located). Tailscale-хост + Funnel (443) + caddy (TLS `tailscale cert`) → `127.0.0.1:8080`. Бэкап: `pg_dumpall` VPS-1 → VPS-2 (cron 02:30).

## Ключевые решения
- **Pull-based:** VPS сами тянут образы (cron/timer); SSH-секреты и Environments не нужны.
- **Гейт prod:** флаг `/etc/xdiary/prod-release` (one-shot), не тег/approval.
- **E2E/smoke — только против dev** (`XDIARY_E2E_BASE_URL` = dev); **prod никогда не тест-таргет**.

## Последствия
- dev обновляется автоматически; prod — только по флагу (явный контроль релиза).

## Проверки
- Merge в `main` → dev обновлён (cron), E2E зелёный.
- `touch /etc/xdiary/prod-release` → prod обновлён ≤15 мин, `/health` 200.
