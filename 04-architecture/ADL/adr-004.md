# ADR-004: Read Store

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Query деплоймент читает из Read Store (Materialized Views), никогда из Domain/Event Store.

## Решение (варианты)
- **PostgreSQL (схема ReadModel)** — `AddReadStorePostgres`, schema `ReadModel`. Одна СУБД на всё (проще для двух ВМ).
- **ScyllaDB** — для высоких нагрузок (Ceqrs), избыточно здесь.

## Последствия
Заполнить после принятия (индексы под каждый Query-эндпоинт, консистентность проекций).
