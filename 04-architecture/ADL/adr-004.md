# ADR-004: Read Store

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 002, 003, 009

## Контекст
Query деплоймент читает из Read Store (Materialized Views), никогда из Domain/Event Store.

## Решение
**PostgreSQL (схема `ReadModel`)** — `AddReadStorePostgres`.

**Обоснование:** одна СУБД (вместе с event store); для двух пользователей ScyllaDB избыточна.

## Последствия
- **Плюсы:** единая БД, простая эксплуатация.
- **Требование:** индексы под каждый Query-эндпоинт (см. `03-ddd/*/05-materialized-views.md`).

## Проверки
- Кросс-ссылка на DDD: таблицы ReadModel = проекции из `03-ddd/*/05-materialized-views.md` (например `records`, `weekly`, `sleep`, `somatic`).
- Согласовано с ADR-002/003.
