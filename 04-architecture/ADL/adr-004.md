# ADR-004: Read Store

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 002, 003, 009
- **Бэклог:** кросс-кат (Read Store)

## Контекст
Query деплоймент читает из Read Store (Materialized Views), никогда из Domain/Event Store.

## Решение
**Та же БД (без отдельной схемы ReadModel)** — профиль Single: Command DB и Read DB в одной PostgreSQL. ReadModel-таблицы лежат рядом с event store.

**Обоснование:** минимальный профиль Single — одна БД на сервис, без разделения схем.

## Последствия
- **Плюсы:** одна БД на сервис, простая эксплуатация.
- **Требование:** индексы под каждый Query-эндпоинт (см. `03-ddd/*/05-materialized-views.md`).

## Проверки
- Таблица профилей edm-net: Single → Read DB = «та же БД».
- Согласовано с ADR-002 (Single), ADR-003 (PostgreSQL).
