# ADR-007: API Gateway / BFF

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Вопрос: нужен ли шлюз между PWA и микросервисами. Шлюз решает: аутентификацию, агрегацию данных с нескольких сервисов, единый вход (CORS/HTTPS), версионирование.

## Решение (варианты)
- **Без шлюза** — PWA обращается к каждому сервису напрямую (проще, но N точек входа).
- **API Gateway** (например YARP/Ocelot) — единая точка входа, маршрутизация.
- **BFF (Backend for Frontend)** — тонкий шлюз, агрегирующий данные под конкретный UI.

## Последствия
Заполнить после принятия (кто делает агрегацию «сводки аналитики», как общая аутентификация).
