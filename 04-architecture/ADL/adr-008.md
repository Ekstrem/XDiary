# ADR-008: Аутентификация и авторизация

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Сейчас приватность — локальный PIN (PBKDF2) на устройстве. С появлением бэка встаёт вопрос защиты API и переноса модели доступа (контекст «Приватность и доступ»).

## Решение (варианты)
- **PIN остаётся локально** — бэк не хранит учётные данные; пара устройств доверяет общей точке входа (локальная сеть).
- **JWT/OAuth** — серверная аутентификация, токены, refresh (нужно хранить пользователей).
- **Shared secret / ключ устройства** — простой токен для приватного API пары.

## Последствия
Заполнить после принятия (угрозы: локальная сеть vs публичный хостинг; хранение секретов).
