# ADR-006: Связь фронта (PWA) с бэком

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Сейчас фронт — статическая PWA (HTML/CSS/JS, IndexedDB), без бэкенда. В целевой архитектуре появляется .NET-бэк. Нужно решить, как PWA общается с сервисами.

## Решение (варианты)
- **REST + JSON** — простые команды/запросы (`POST/GET /api/v1/...`), соответствует Command/Query API из edm-net.
- **GraphQL** — гибкая выборка, но избыточно для малого числа экранов.
- **Прямой доступ vs шлюз** — см. ADR-007.

## Последствия
Заполнить после принятия (CORS, HTTPS, согласование DTO с фронтом).
