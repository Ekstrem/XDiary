# ADR-006: Связь фронта (PWA) с бэком

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 007, 013
- **Бэклог:** Инк 2 (PWA, US-10); US-01..09 (журнал через API)

## Контекст
Фронт — статическая PWA (HTML/CSS/JS). Появляется .NET-бэк. Нужно решить, как PWA общается с сервисами.

## Решение
**REST + JSON** — команды и запросы по `/api/v1/...` (соответствует Command API и Query API из edm-net). Без GraphQL (избыточно для малого числа экранов).

**Обоснование:** прямой перенос существующих Command/Query API из `03-ddd/*/03-command-api.md` и `04-query-api.md` в REST-эндпоинты.

## Последствия
- **Плюсы:** простота, соответствие CEQRS-модели.
- **Требование:** CORS и HTTPS на шлюзе (ADR-007); контракты через OpenAPI (ADR-013).

## Проверки
- Кросс-ссылка: эндпоинты соответствуют `03-ddd/*/03-command-api.md` (CreateRecord → `POST /api/v1/journal/records`) и `04-query-api.md` (JournalView → `GET /api/v1/journal/records`).
- Согласовано с ADR-007 (шлюз), ADR-013 (версионирование).
