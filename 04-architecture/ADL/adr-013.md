# ADR-013: Версионирование API и контракты

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
Фронт (PWA) и бэк будут развиваться независимо. Нужны контракты и правила совместимости.

## Решение (варианты)
- **URL-версионирование** — `/api/v1/...`, новые версии — `/api/v2`.
- **OpenAPI** — единственный источник правды для DTO (генерация клиента).
- **Обратная совместимость** — аддитивные изменения, без ломающих.

## Последствия
Заполнить после принятия (кто владеет контрактом, как тестируется совместимость).
