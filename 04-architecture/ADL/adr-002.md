# ADR-002: Профиль деплоймента CEQRS

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
EDM предлагает 4 профиля (см. edm-net): Single (1 процесс), BudgetCqrs (1 процесс, отдельная схема ReadModel), Cqrs (2: Cmd+Qry), Ceqrs (3: Cmd+Evt+Qry). Для двух пользователей и минимальной нагрузки.

## Решение (варианты)
- **Single** — всё в одном процессе, одна БД, InMemory EventBus. Самый простой.
- **BudgetCqrs** — один процесс, Command DB + Read DB в одной Postgres (схема ReadModel). Разделение записи/чтения без лишних процессов.

## Последствия
Заполнить после принятия (стоимость запуска, путь эволюции к Cqrs/Ceqrs).
