# ADR-002: Профиль деплоймента CEQRS

- **Статус:** Принято
- **Дата:** 2026-10-29
- **Связанные ADR:** 001, 003, 004, 005
- **Бэклог:** кросс-кат (деплоймент CEQRS)

## Контекст
EDM предлагает 4 профиля: Single, BudgetCqrs, Cqrs, Ceqrs. Два пользователя, минимальная нагрузка.

## Решение
**Single** — самый минимальный профиль:

| Параметр | Значение |
|---|---|
| Деплоймент | 1 (All: Cmd + Evt + Qry в одном процессе) |
| Command DB | PostgreSQL (Event Sourcing) |
| Read DB | та же БД (без отдельной схемы ReadModel) |
| EventBus | InMemory |

Каждый микросервис — 1 процесс, своя PostgreSQL, InMemory-шина.

## Последствия
- **Плюсы:** минимальная сложность, лёгкий запуск и отладка.
- **Путь эволюции:** Single → BudgetCqrs → Cqrs → Ceqrs (при росте нагрузки).

## Проверки
- Таблица профилей из edm-net (DigiTFactory deployment profiles).
- Согласовано с ADR-003 (PostgreSQL), ADR-004 (та же БД), ADR-005 (InMemory).
