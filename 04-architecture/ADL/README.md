# ADL — Architecture Decision Log (XDiary)

Реестр архитектурных решений (ADR). Каждая ADR — отдельный файл в этой папке.

**Методология:** EDM (Event-Driven Microservices) на .NET — DDD, Event Sourcing, CEQRS, фреймворк `DigiTFactory.Libraries`.
**Базовые условия:** два пользователя, минимальная нагрузка; следующий этап — две ВМ (одна с Docker, другая с Postgres).

## Статусы
- **Предложено** (Proposed) — решение обсуждается, варианты собраны.
- **Принято** (Accepted) — решение зафиксировано.
- **Отклонено** (Rejected) — вариант отвергнут.
- **Заменено** (Superseded) — заменено более новым ADR.

## Сводная картина (после принятия ADR-001..014)
- **3 микросервиса** (journal / somatics / analytics) по профилю **BudgetCqrs** на .NET 8.
- Хранилище: **единая PostgreSQL** (event store + ReadModel + outbox) на отдельной ВМ.
- Фронт (PWA) → **API Gateway (YARP)** по REST `/api/v1`, аутентификация **JWT**.
- Развёртывание: **Docker Compose** (ВМ-1) + **Postgres** (ВМ-2).
- Миграция существующих данных — через **CSV** (идемпотентно по id).
