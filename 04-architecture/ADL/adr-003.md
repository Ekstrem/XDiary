# ADR-003: Command Store (Event Store)

- **Статус:** Предложено
- **Дата:** 2026-10-29

## Контекст
EDM: команда → шина → Command DB Projector (SaveEventAsync). Event Sourcing требует event store. На отдельной ВМ планируется Postgres.

## Решение (варианты)
- **PostgreSQL (Event Sourcing)** — `AddEventStorePostgres`, стратегия `FullEventSourcing`. Согласуется с планом «ВМ с Postgres».
- **MongoDB** — при профиле Cqrs/Ceqrs (Cmd DB = Mongo), но добавляет вторую СУБД.

## Последствия
Заполнить после принятия (снапшоты, объём событий, совместимость с профилем из ADR-002).
